NIVEL 7 · LECCIÓN 2

Guardar de verdad: JSON y localStorage 💾

🎯 HOY VAS A LOGRAR…

Que tus datos sobrevivan a la recarga de la página usando localStorage (el cajón del navegador) y JSON (la forma de empacar objetos como texto). Al final tendrás una nota que NO se borra. 📝

🧠 EL CONCEPTO

Primero, el problemón. Todas las variables que has creado en tu vida viven en la memoria RAM, que es como escribir en el vaho del espejo del baño 🪞: clarísimo mientras dura… y ¡puf!, se borra. Compruébalo tú: dale varios clics al botón de abajo y luego presiona ▶ Ejecutar otra vez (eso es como recargar la página):

<!DOCTYPE html>
<html>
<body style="font-family: sans-serif; text-align: center; background: #f4f4ff;">
  <h2>Tacos comidos 🌮: <span id="cuenta">0</span></h2>
  <button id="boton" style="font-size: 18px; padding: 8px 18px;">¡Comer taco!</button>
  <script>
    let tacos = 0;   // vive en una variable… o sea, en la memoria RAM
    document.getElementById("boton").onclick = function () {
      tacos = tacos + 1;
      document.getElementById("cuenta").textContent = tacos;
    };
  </script>
</body>
</html>

😱 ¿Viste? Comiste 10 tacos y al "recargar"… cero tacos. Así, tal cual, se perdería el puntaje de tu juego, el nivel de tu jugador, TODO. La solución tiene dos piezas:

localStorage es el cajón del buró que cada navegador tiene para cada sitio web: lo que guardas ahí sigue existiendo aunque recargues, cierres la pestaña o apagues la compu. Pero el cajón tiene una regla rara: solo acepta TEXTO. Por eso existe JSON: el papel burbuja 📦 que convierte tus objetos en texto (JSON.stringify = empacar) y el texto de vuelta en objetos (JSON.parse = desempacar).

La página se recarga una y otra vez 🔄… y el cajón localStorage NI se inmuta: tu "🌮 7" sigue guardado adentro.

El cajón se usa con dos órdenes súper simples:

localStorage.setItem("tacos", "7");   // guardar: (etiqueta, texto)
let dato = localStorage.getItem("tacos");   // leer: te da "7"… ¡o null si no hay nada!

Y el empacado JSON, con otras dos:

let ficha = { nombre: "Kai", vidas: 3 };
let texto = JSON.stringify(ficha);   // 📦 empacar  → '{"nombre":"Kai","vidas":3}'
let copia = JSON.parse(texto);       // 📂 desempacar → el objeto de vuelta, vivo

👀 MÍRALO FUNCIONAR

El mismo contador de tacos, pero ahora inmortal 🛡️. Come varios tacos, presiona ▶ Ejecutar para "recargar"… ¡y siguen ahí! Lee los comentarios: el truco son 2 momentos: al abrir (leer el cajón) y al cambiar (guardar en el cajón):

<!DOCTYPE html>
<html>
<body style="font-family: sans-serif; text-align: center; background: #f4f4ff;">
  <h2>Tacos guardados 🌮: <span id="cuenta">?</span></h2>
  <button id="boton" style="font-size: 18px; padding: 8px 18px;">¡Comer taco!</button>
  <button id="borrar" style="font-size: 18px; padding: 8px 18px;">🗑️ Reiniciar contador</button>
  <script>
    // ---- MOMENTO 1: al abrir la página, revisa el cajón ----
    let guardado = localStorage.getItem("tacos");
    let tacos = 0;
    if (guardado !== null) {
      tacos = JSON.parse(guardado);   // 📂 desempacar el texto → número
    }
    document.getElementById("cuenta").textContent = tacos;

    // ---- MOMENTO 2: cada vez que cambia, guarda en el cajón ----
    document.getElementById("boton").onclick = function () {
      tacos = tacos + 1;
      document.getElementById("cuenta").textContent = tacos;
      localStorage.setItem("tacos", JSON.stringify(tacos));   // 📦 empacar y guardar
    };

    // Bonus: vaciar el cajón
    document.getElementById("borrar").onclick = function () {
      localStorage.removeItem("tacos");
      tacos = 0;
      document.getElementById("cuenta").textContent = tacos;
    };
  </script>
</body>
</html>

🌐 Nota rápida: los ejemplos de localStorage funcionan cuando el sitio se abre por internet o con Live Server. Si abres el archivo con doble clic (la barra dice file://), el navegador puede negarse a guardar. Si "no te guarda", esa es la razón, no tu código. 😉

PISTA 1 El TODO 2 es UNA línea: localStorage.setItem("mi-nota", caja.value); — etiqueta del cajón primero, lo que guardas después.
PISTA 2 Para el TODO 1: guarda lo leído en una variable y pregunta con un if: let guardada = localStorage.getItem("mi-nota"); y luego if (guardada !== null) { … }. Adentro, pásala a caja.value.
SOLUCIÓN EXPLICADA 
// TODO 1: al abrir, revisar el cajón
let guardada = localStorage.getItem("mi-nota");
if (guardada !== null) {
  caja.value = guardada;       // había nota: ¡a la caja!
}

// TODO 2: dentro del onclick del botón
localStorage.setItem("mi-nota", caja.value);
¿Por qué aquí no usamos JSON? Porque la nota YA es texto, y el cajón acepta texto directo. JSON entra al quite cuando quieres guardar números, objetos o listas — como la ficha {nombre, vidas} de la lección pasada. 📦

❓ MINI-QUIZ

1. Recargas la página. ¿Qué le pasa a una variable let puntos = 900;?

La RAM es el vaho del espejo 🪞: rapidísima pero olvidadiza. Si quieres que un dato sobreviva, tienes que guardarlo tú en el cajón (localStorage).

2. ¿Para qué sirve JSON.stringify(ficha)?

📦 stringify = empacar (objeto → texto). 📂 parse = desempacar (texto → objeto). Si los confundes, recuerda: "string" significa texto, y stringify lo VUELVE texto.

3. ¿Qué te devuelve localStorage.getItem("x") si nunca guardaste nada con esa etiqueta?

null es la forma del cajón de decir "ese compartimento está vacío". Por eso siempre preguntamos if (dato !== null) antes de usarlo.
