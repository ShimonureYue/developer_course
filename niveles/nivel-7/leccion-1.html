NIVEL 7 · LECCIÓN 1

Objetos: fichas de personaje 🃏

🎯 HOY VAS A LOGRAR…

Guardar TODOS los datos de un personaje en un solo objeto (una ficha con datos etiquetados), leerlos y cambiarlos con el punto ., y armar tu primera base de datos: una lista de objetos con jugadores y puntajes.

🧠 EL CONCEPTO

Hasta hoy, para guardar los datos de un personaje usabas variables sueltas: nombre, vidas, poder… Funciona con UN personaje. Pero, ¿y si tu juego tiene 8 jugadores? ¿Vas a crear nombre1, nombre2, vidas1, vidas2…? 😵 Se vuelve un relajo. Para eso existen los objetos.

Un objeto es como una carta de colección (tipo lotería o cartas TCG): una sola tarjeta que trae TODOS los datos de tu personaje, y cada dato tiene su etiqueta: nombre, vidas, poder…

La carta se llama jugador y cada campo tiene su etiqueta. Para leer un campo usas el punto: jugador.vidas te da el 3. ✨

Las reglas del juego son 3, ¡y ya!:

  • Crear la ficha: llaves { } y adentro pares etiqueta: valor separados por comas.
  • Leer un dato: nombre de la ficha + punto + etiqueta → jugador.poder.
  • Cambiar un dato: igual que una variable → jugador.vidas = 2. Incluso puedes agregar etiquetas nuevas cuando quieras.

Y aquí viene lo bueno 😏: si metes varias fichas dentro de una lista (un arreglo, como los que ya conoces), acabas de inventar… ¡tu primera base de datos! Una colección ordenada de fichas que puedes recorrer con for. Así guarda TikTok a sus usuarios y Roblox a sus jugadores (bueno, con unos truquitos extra que verás en la lección 3 😉).

PISTA 1 Mira el diagrama de la carta 🃏: un objeto se crea con llaves y pares etiqueta: valor separados por comas: let capitan = { nombre: "Luna", juego: "Snake", puntos: 500 };
PISTA 2 Para el TODO 4: el arreglo se hace con corchetes y adentro van las fichas: let equipo = [ {…}, {…}, {…} ]; — y dentro del for, cada ficha es equipo[i], así que su nombre es equipo[i].nombre.
SOLUCIÓN EXPLICADA 
let capitan = { nombre: "Luna", juego: "Snake", puntos: 500 };

console.log(capitan.nombre + " juega " + capitan.juego);

capitan.puntos = capitan.puntos + 100;   // ganó el torneo 🏆
console.log("Puntos del capi:", capitan.puntos);

let equipo = [
  { nombre: "Luna", puntos: 600 },
  { nombre: "Mateo", puntos: 450 },
  { nombre: "Sofi", puntos: 720 }
];

for (let i = 0; i < equipo.length; i++) {
  console.log(equipo[i].nombre + ": " + equipo[i].puntos);
}
Fíjate en el patrón estrella: equipo[i].puntos se lee de izquierda a derecha: "de la lista equipo, toma la ficha i, y de esa ficha, el dato puntos". Ese patrón lo vas a usar TODO el resto del curso. 💪

❓ MINI-QUIZ

1. Tienes let jugador = { nombre: "Kai", vidas: 3 }. ¿Cómo lees sus vidas?

Primero la ficha, luego el punto, luego la etiqueta: jugador.vidas. El punto significa "de esta ficha, dame este dato".

2. ¿Qué obtienes con jugadores[0].nombre?

Se lee por partes: jugadores[0] es la primera ficha (¡las listas empiezan en 0!) y .nombre saca su dato "nombre". Mezclar listas y objetos no solo se puede: es la base de las bases de datos. 🗃️

3. ¿Por qué un arreglo de objetos es "tu primera base de datos"?

Eso es exactamente una base de datos: muchas fichas (registros) con los mismos campos. Ojo: todavía vive en la memoria y se borra al recargar… ese problemón lo resolvemos en la siguiente lección. 😱
