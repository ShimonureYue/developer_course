NIVEL 7 · LECCIÓN 4 · 👑 JEFE

Jefe: tabla de récords para tu Gato 👑🏆

🎯 EL JEFE DE ESTE NIVEL

Conectar TODO el nivel: tu Gato del nivel 6 va a pedir los nombres de los jugadores, guardar sus victorias en un arreglo de objetos [{nombre, victorias}], empacarlo con JSON en localStorage, y mostrar un TOP 5 ordenado que sobrevive a la recarga. Como los récords de las maquinitas de verdad. 🕹️

🧠 EL PLAN DE BATALLA

Un jefe no se vence a lo loco: se vence con plan. El viaje de cada victoria tiene 5 estaciones, y TODAS las aprendiste ya en este nivel:

Es como el salón de la fama de las maquinitas 🕹️: ganas, la máquina te pide tus iniciales, guarda tu marca en su memoria… y aunque la desconecten, al día siguiente tu nombre sigue brillando en la pantalla de HIGH SCORES.

Cada victoria viaja: objeto → JSON.stringify 📦 → localStorage 💾. Y al abrir la página, el viaje de regreso: getItem → JSON.parse 📂 → ordenar → pintar el TOP 5.

Las 5 estaciones, en código:

  1. Los nombres: prompt("¿Quién juega con la X?") — una ventanita que pregunta y devuelve lo que escriban.
  2. La ficha: cada jugador es un objeto { nombre: "Kai", victorias: 2 } dentro de una lista (lección 1 🃏).
  3. Guardar: localStorage.setItem("gato-records", JSON.stringify(lista)) (lección 2 💾).
  4. Leer: JSON.parse(localStorage.getItem("gato-records")) — y si viene null, empezamos con lista vacía []. (En el código verás esa lectura envuelta en un try / catch: un seguro por si lo guardado no se puede desempacar.)
  5. El TOP 5: ordenar la lista de mayor a menor y quedarnos con 5. Dos herramientas nuevas chiquitas: lista.sort(function (a, b) { return b.victorias - a.victorias; }) ordena comparando fichas por pares (si el resultado es positivo, b va primero), y lista.slice(0, 5) corta una copia con los primeros 5. ✂️
🆕 Cosas nuevas que verás en este código (este Gato viene ya armado y está escrito con un estilo un poquito distinto al tuyo del nivel 6; que no te espante, hace lo mismo):
  • var es el hermano mayor de let: también crea una variable. Es la forma antigua y la vas a ver en muchísimo código de internet; aquí puedes leer cada var como si dijera let.
  • condición ? a : b es un if / else chiquito en una sola línea: "si la condición es cierta, vale a; si no, vale b". Por ejemplo, turno = turno === "X" ? "O" : "X"; se lee: "¿el turno es X? entonces ahora es O; si no, X".
  • boton.onclick = function () { … }; es otra manera de escribir boton.addEventListener("click", function () { … });: "cuando le den clic, ejecuta esto".
  • if (algo) return; sin llaves: cuando el if solo tiene UNA instrucción, las llaves se pueden omitir. Aquí significa "si pasa esto, salte de la función ya".

    // ---------- ESTACIÓN 1: los nombres ----------
    var nombreX = prompt("¿Quién juega con la X?") || "Jugador X";
    var nombreO = prompt("¿Quién juega con la O?") || "Jugador O";

    // ---------- El Gato (misma lógica que el tuyo del nivel 6) ----------
    var tablero = ["", "", "", "", "", "", "", "", ""];
    var turno = "X";
    var terminado = false;

    var COMBOS = [
      [0, 1, 2], [3, 4, 5], [6, 7, 8],   // filas
      [0, 3, 6], [1, 4, 7], [2, 5, 8],   // columnas
      [0, 4, 8], [2, 4, 6]               // diagonales
    ];

    var zonaTablero = document.getElementById("tablero");
    var estado = document.getElementById("estado");

    function pintarTablero() {
      zonaTablero.innerHTML = "";
      // OJO: aquí va "let i" a propósito (como en tu Gato del nivel 6):
      // así cada botón recuerda SU propio número de casilla.
      for (let i = 0; i < 9; i++) {
        var celda = document.createElement("button");
        celda.className = "celda";
        celda.textContent = tablero[i];
        celda.onclick = function () { jugarEn(i); };
        zonaTablero.appendChild(celda);
      }
    }

    function jugarEn(i) {
      if (terminado || tablero[i] !== "") return;
      tablero[i] = turno;
      var ganador = checarGanador();
      if (ganador) {
        terminado = true;
        var nombre = ganador === "X" ? nombreX : nombreO;
        estado.textContent = "🎉 ¡Ganó " + nombre + "!";
        sumarVictoria(nombre);        // 💾 ¡aquí entra el nivel 7!
      } else if (tableroLleno()) {
        terminado = true;
        estado.textContent = "😺 ¡Empate! (gato)";
      } else {
        turno = turno === "X" ? "O" : "X";
        estado.textContent = "Turno de " + (turno === "X" ? nombreX : nombreO) + " (" + turno + ")";
      }
      pintarTablero();
    }

    function checarGanador() {
      for (var i = 0; i < COMBOS.length; i++) {
        var combo = COMBOS[i];
        if (tablero[combo[0]] !== "" &&
            tablero[combo[0]] === tablero[combo[1]] &&
            tablero[combo[1]] === tablero[combo[2]]) {
          return tablero[combo[0]];
        }
      }
      return null;
    }

    function tableroLleno() {
      for (var i = 0; i < 9; i++) {
        if (tablero[i] === "") return false;
      }
      return true;
    }

    // ---------- ESTACIONES 2 a 5: los récords 💾 ----------

    // Leer la lista del cajón (o empezar con lista vacía)
    function cargarRecords() {
      var crudo = localStorage.getItem("gato-records");
      if (crudo === null) return [];      // primera vez: nadie ha ganado

      // try/catch = "intenta esto; si truena, haz lo otro". Si en el cajón
      // quedó algo que NO es JSON (por ejemplo, si un día guardaste la lista
      // sin JSON.stringify), JSON.parse truena… y en vez de que se rompa
      // todo el juego, empezamos con lista vacía.
      try {
        return JSON.parse(crudo) || [];   // 📂 desempacar texto → lista de fichas
      } catch (error) {
        return [];
      }
    }

    // Empacar la lista y guardarla en el cajón
    function guardarRecords(lista) {
      localStorage.setItem("gato-records", JSON.stringify(lista));  // 📦
    }

    // Sumar una victoria a la ficha del ganador (o crearle ficha nueva)
    function sumarVictoria(nombre) {
      var lista = cargarRecords();
      var ficha = null;
      for (var i = 0; i < lista.length; i++) {
        if (lista[i].nombre === nombre) ficha = lista[i];   // ¡ya existía!
      }
      if (ficha === null) {
        ficha = { nombre: nombre, victorias: 0 };   // jugador nuevo
        lista.push(ficha);
      }
      ficha.victorias = ficha.victorias + 1;
      guardarRecords(lista);
      pintarRecords();
    }

    // Ordenar de mayor a menor, cortar el TOP 5 y pintarlo
    function pintarRecords() {
      var lista = cargarRecords();
      lista.sort(function (a, b) { return b.victorias - a.victorias; });
      var top5 = lista.slice(0, 5);
      var cuerpo = document.getElementById("records");
      cuerpo.innerHTML = "";
      for (var i = 0; i < top5.length; i++) {
        var fila = document.createElement("tr");
        agregarCelda(fila, i + 1);
        agregarCelda(fila, top5[i].nombre);
        agregarCelda(fila, top5[i].victorias);
        cuerpo.appendChild(fila);
      }
    }

    // Crea una celda <td> con un texto y la mete en la fila.
    // Usa textContent (no innerHTML): así el nombre SIEMPRE se pinta como
    // texto, aunque alguien escriba etiquetas HTML como "nombre" 😏
    function agregarCelda(fila, texto) {
      var celda = document.createElement("td");
      celda.textContent = texto;
      fila.appendChild(celda);
    }

    document.getElementById("reiniciar").onclick = function () {
      tablero = ["", "", "", "", "", "", "", "", ""];
      turno = "X";
      terminado = false;
      estado.textContent = "Turno de " + nombreX + " (X)";
      pintarTablero();
    };

    // ---------- Arranque ----------
    estado.textContent = "Turno de " + nombreX + " (X)";
    pintarTablero();
    pintarRecords();   // ¡los récords viejos aparecen desde el segundo cero!
  </script>
</body>

SOLUCIÓN EXPLICADA 
function cargarRecords() {
  var crudo = localStorage.getItem("gato-records");
  if (crudo === null) return [];   // cajón vacío → lista vacía
  try {
    return JSON.parse(crudo) || [];  // 📂 desempacar
  } catch (error) {
    return [];                     // lo guardado no era JSON → lista vacía
  }
}

function guardarRecords(lista) {
  localStorage.setItem("gato-records", JSON.stringify(lista)); // 📦
}

function sumarVictoria(nombre) {
  var lista = cargarRecords();
  var ficha = null;
  for (var i = 0; i < lista.length; i++) {
    if (lista[i].nombre === nombre) ficha = lista[i];
  }
  if (ficha === null) {                       // jugador nuevo
    ficha = { nombre: nombre, victorias: 0 };
    lista.push(ficha);
  }
  ficha.victorias = ficha.victorias + 1;      // ¡+1 victoria!
  guardarRecords(lista);
  pintarRecords();
}

function pintarRecords() {
  var lista = cargarRecords();
  lista.sort(function (a, b) { return b.victorias - a.victorias; });
  var top5 = lista.slice(0, 5);
  var cuerpo = document.getElementById("records");
  cuerpo.innerHTML = "";
  for (var i = 0; i < top5.length; i++) {
    var fila = document.createElement("tr");
    agregarCelda(fila, i + 1);               // el lugar
    agregarCelda(fila, top5[i].nombre);      // quién
    agregarCelda(fila, top5[i].victorias);   // cuántas
    cuerpo.appendChild(fila);
  }
}
El try / catch de cargarRecords es un seguro: "intenta desempacar; si truena, regresa lista vacía". Sin él, un solo guardado mal hecho dejaría tu juego roto en cada recarga. Y agregarCelda pinta con textContent, así un nombre tramposo con etiquetas HTML se ve como simple texto. Detalle fino del sort: le pasas una función que compara DOS fichas. b.victorias - a.victorias ordena de mayor a menor (si lo volteas a a - b, queda de menor a mayor). Y como ficha apunta a la MISMA ficha que está dentro de la lista, sumarle a ficha.victorias también la cambia dentro de la lista. Magia de los objetos. ✨

❓ MINI-QUIZ

1. ¿Por qué empacamos la lista con JSON.stringify antes de guardarla?

El cajón solo acepta texto. stringify convierte [{nombre: "Kai", victorias: 3}] en un texto guardable, y parse lo revive al leerlo. 📦📂

2. ¿Qué hace lista.sort(function (a, b) { return b.victorias - a.victorias; })?

sort compara fichas por pares con tu función: b.victorias - a.victorias pone primero a quien tenga más. Volteado (a - b) quedaría de menor a mayor.

3. ¿Para qué sirve lista.slice(0, 5)?

slice(0, 5) = "córtame del elemento 0 al 4" (el 5 ya no entra). Y es una COPIA: la lista original queda intacta en el cajón. ✂️
