NIVEL 0 · LECCIÓN 3

Tu partida guardada 💾🎮

🎯 HOY VAS A LOGRAR…

Dominar tu plataforma: cómo funcionan el XP, las medallas y los rangos, dónde se guarda tu progreso, y cómo llevarte tu partida a otra computadora como todo un gamer. 🕹️

🧠 EL CONCEPTO

Code Quest funciona como tu videojuego favorito: cada cosa que logras te da XP (puntos de experiencia). Completar una lección da 50 XP (los jefes 👑 dan 100), dominar un mini-quiz da 20 XP, y hasta las casillas del checklist dan XP. Con el XP subes de rango:

RangoXP necesario
🥚 Novato0 (aquí empiezas)
🐣 Aprendiz400
😎 Hacker1200
🧑‍💻 Desarrollador2200
🏆 GAME DEV3200 (el rango máximo)

Además, al terminar TODAS las lecciones de un nivel ganas su medalla 🏅 (la de este nivel es 🛠️ Equipo listo) y en el mapa 🗺️ ves qué niveles llevas completados. Todo tu avance vive en tu partida guardada.

Tu progreso se guarda como en las consolas de antes: en la memoria de ESTA computadora, no en internet. El navegador tiene un cajoncito llamado localStorage (memoria local) donde Code Quest apunta tu XP y tus medallas. Es como la memory card 🗂️ de una consola: si juegas en OTRA compu, esa memory card no está ahí… a menos que te la lleves tú. 😉

Tu partida entra a la memoria del navegador cada vez que logras algo. En el Nivel 7 vas a aprender a usar esta misma magia (localStorage) en TUS propios juegos. 🤯

Dos consecuencias importantes de que se guarde en TU computadora:

  • ✅ No necesitas cuenta ni contraseña: abre el curso y ahí está tu avance.
  • ⚠️ Si cambias de computadora (o borras los datos del navegador), tu partida no te sigue sola. Para eso existe el botón 💾 descargar partida. 👇

👀 MÍRALO FUNCIONAR

Levanta la vista: arriba de esta página está tu tablero de gamer 🕹️. Identifica cada pieza:

  1. 🥚 Tu rango actual — junto al logo. Ahorita seguro dice "Novato". Disfrútalo: nadie se queda de huevo para siempre. 😄
  2. La barra de XP — se va llenando con cada logro y te dice cuánto falta para el siguiente rango. Cuando ganas XP aparece un aviso verde abajo (así 👉 ).
  3. Los enlaces del menú — 🗺️ Mapa (tu vista general), 👾 Arcade (los juegos que construirás), 📚 Recursos y 💾 Mi progreso.

La página 💾 Mi progreso es tu centro de control: ahí ves tus medallas, tu XP total y los tres botones clave:

  • 💾 Guardar partida: descarga un archivito (mi-partida-codequest.json) con TODO tu avance. Es tu memory card portátil.
  • 📂 Cargar partida: en otra Mac, abres el curso, vas a Mi progreso, eliges tu archivo… y tu XP, medallas y lecciones aparecen como por arte de magia. 🪄
  • 🔁 Reiniciar: borra todo para empezar de cero (¡usa Guardar antes, por si te arrepientes!).

Y un secreto del mapa: el botón "▶ Continuar" de la página de inicio siempre sabe cuál es tu siguiente lección pendiente. Cierra todo hoy, vuelve mañana, presiona Continuar y caes exactamente donde ibas. Como el "Continue" de las maquinitas, pero sin echarle monedas. 🪙😄

Ah, y súper importante: aquí nada se bloquea 🔓. Puedes regresar a cualquier lección terminada para repasarla cuando tengas dudas, o asomarte a niveles futuros por curiosidad. El XP de cada lección y quiz se gana una sola vez, pero repasar es gratis e infinito.

✏️ TU TURNO: RESPALDA TU PARTIDA

Misión de hoy: hacer tu primer respaldo, como los pros.

  1. Abre 💾 Mi progreso (se abre en esta misma pestaña; puedes volver aquí con la flecha ◀ del navegador).
  2. Presiona 💾 Guardar partida. Se descargará mi-partida-codequest.json a tu carpeta Descargas.
  3. Encuentra el archivo en Finder → Descargas y ábrelo con doble clic (o clic derecho → Abrir con → TextEdit). Échale un ojo: ¡ese texto ES tu partida! ¿Alcanzas a ver tu número de xp y las lecciones en true? 🕵️
  4. Guarda ese archivo en un lugar seguro (Documentos, una USB, tu Drive…). Ahora tu progreso puede viajar contigo a cualquier Mac.
PISTA 1 ¿No encuentras el botón? En la página Mi progreso, baja un poco: los botones de guardar, cargar y reiniciar están juntos. El de reiniciar NO lo toques hoy (y si lo tocas, te pregunta antes de borrar, uf 😮‍💨).
PISTA 2 ¿No aparece el archivo? Revisa el botón de descargas de Chrome (arriba a la derecha ⬇️) o abre Finder → Descargas y ordena por "Fecha de adición" para ver lo más reciente primero.
SOLUCIÓN EXPLICADA El camino completo: Mi progreso → 💾 Guardar partida → Finder → Descargas → mi-partida-codequest.json. Por dentro, el archivo se ve más o menos así: 
{
  "version": 1,
  "xp": 130,
  "lecciones": { "n0-l1": true, "n0-l2": true },
  "quizzes": { "n0-l1": true },
  "checklist": { "n0-chrome": true, "n0-vscode": true }
}
Ese formato se llama JSON y lo aprenderás en el Nivel 7. Para cargarlo en otra Mac: abre el curso allá → Mi progreso → 📂 Cargar partida → elige este archivo → ¡pum! 💥 Tu XP y medallas de vuelta.

❓ MINI-QUIZ

1. ¿Dónde se guarda tu progreso de Code Quest?

Tu partida vive en el localStorage: el cajoncito de memoria del navegador de TU compu. Como una memory card 💾 — por eso no aparece solita en otra máquina.

2. Mañana te toca trabajar en OTRA Mac. ¿Cómo te llevas tu avance?

¡Eso! El archivo mi-partida-codequest.json es tu memory card portátil: guárdalo, llévalo y cárgalo en la otra Mac desde la página 💾 Mi progreso.

3. Terminaste una lección pero te quedó una duda. ¿Puedes volver a verla?

Repasa todo lo que quieras 🔓. El XP se gana una sola vez, pero volver a una lección cuando tienes dudas es EXACTAMENTE lo que hacen los buenos programadores.
