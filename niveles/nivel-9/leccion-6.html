🧠 EL CONCEPTO: LOS ESTADOS DEL JUEGO

¿Qué le falta a tu juego de la Lección 5 para sentirse "de verdad"? Piensa en cualquier juego que ames: no te avienta a la acción de golpe. Hay un menú, luego juegas, a veces pausas, y al morir hay una pantalla de game over con tu puntuación… y la opción de revancha. Cada una de esas "escenas" es un estado.

Los estados de un juego son como los actos de una obra de teatro 🎭: una variable (estado) dice qué acto está en escena — "inicio", "jugando" o "gameover" — y el game loop, como director, solo deja actuar a las funciones de ESE acto. ENTER cambia de acto; P congela la escena.

Tres estados, una variable. El game loop pregunta if (estado === "jugando") para mover el mundo, y dibujar() pinta la pantalla del estado actual.

🧩 Las piezas nuevas del jefe (todas las conoces por dentro)

  • 🎬 Estados: var estado = "inicio"; y el game loop solo actualiza el mundo if (estado === "jugando" && !pausa). Las pantallas de inicio y game over se DIBUJAN en el mismo canvas con fillText — no hay magia, son textos sobre el espacio.
  • ⏸ Pausa: un boolean. La tecla P lo voltea: pausa = !pausa; — cuando es true, el mundo se congela pero se sigue dibujando (por eso ves todo quieto y el letrero encima).
  • 🏆 Récord: Nivel 7 al rescate: localStorage.getItem("invaders-record") al arrancar, y si puntos > record al morir → setItem. Tu récord sobrevive aunque cierres el navegador.
  • 🖊️ La firma: var AUTOR = "Tu Nombre"; aparece en la pantalla de inicio. Los créditos importan: TÚ hiciste este juego.
  • ✨ Estrellas de fondo: 40 puntitos que caen y reaparecen arriba. Cero física, puro sabor espacial. (Bonus de jefe: el detalle que nadie pide y todos notan.)

    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // ============================================================
    //  1) LOS DATOS  (la tabla de diseño, hecha código)
    // ============================================================
    var AUTOR = "Tu Nombre";     // 🖊️ ¡fírmalo! Sale en la pantalla de inicio

    // El acto que está en escena: "inicio", "jugando" o "gameover"
    var estado = "inicio";
    var pausa = false;           // ⏸ la tecla P lo voltea

    // 🏆 El récord vive en localStorage. getItem devuelve TEXTO (o null la
    // primera vez): parseInt lo vuelve número y, si sale algo raro,
    // el "|| 0" lo deja en cero.
    var record = parseInt(localStorage.getItem("invaders-record"), 10) || 0;
    var nuevoRecord = false;     // ¿esta partida rompió el récord?

    // 🚀 La nave: UNA ficha con x, y, ancho, alto y velocidad
    var nave = {
      x: 210,            // su esquina IZQUIERDA (210 + 30 = 240: al centro)
      y: 470,
      ancho: 60,
      alto: 20,
      velocidad: 6       // píxeles que avanza en cada cuadro
    };

    // 🔸 Las balas: un arreglo que empieza vacío (se llena al disparar)
    var balas = [];

    // 👾 Los invasores: otro arreglo. Lo llena crearInvasores()
    var invasores = [];
    var velocidadInvasores = 0.5;   // píxeles que marchan en cada cuadro
    var direccion = 1;              // 1 = hacia la derecha, -1 = hacia la izquierda

    // 💥 Los puntos y las explosiones (cada una: { x, y, tiempo })
    var puntos = 0;
    var explosiones = [];

    // ❤️ Las vidas, la oleada y las balas de ELLOS
    var vidas = 3;
    var oleada = 1;
    var balasEnemigas = [];

    // ✨ 40 estrellas de fondo, cada una en un lugar al azar
    var estrellas = [];
    for (var n = 0; n < 40; n++) {
      estrellas.push({
        x: Math.random() * canvas.width,
        y: Math.random() * canvas.height,
        velocidad: 0.3 + Math.random() * 1.2
      });
    }

    // ============================================================
    //  2) EL SONIDO  (tu sintetizador de 8 bits)
    // ============================================================
    var audio = null;    // el sintetizador: se crea con el primer beep

    // OJO: los navegadores solo dejan sonar DESPUÉS de que el jugador toca
    // una tecla. Por eso beep() solo se usa cuando la partida ya empezó.
    function beep(frecuencia, duracion) {
      if (!window.AudioContext) return;            // navegador sin sonido: jugamos mudos
      if (!audio) audio = new AudioContext();      // el sintetizador (solo 1 vez)
      if (audio.state === "suspended") audio.resume();   // por si estaba dormido
      var onda = audio.createOscillator();         // el generador de la onda
      var volumen = audio.createGain();            // la perilla de volumen
      onda.type = "square";                        // cuadrada = 8 bits 🕹️
      onda.frequency.value = frecuencia;           // Hz: agudo ↑ o grave ↓
      volumen.gain.value = 0.05;                   // bajito 👂
      onda.connect(volumen);                       // onda → volumen →
      volumen.connect(audio.destination);          // → tus bocinas
      onda.start();
      onda.stop(audio.currentTime + duracion);     // se apaga solo
    }

    // ============================================================
    //  3) LOS CAMBIOS DE ESTADO Y EL TECLADO
    // ============================================================
    // ENTER → arranca una partida nueva: todo vuelve a su valor inicial
    function empezarJuego() {
      puntos = 0;
      vidas = 3;
      oleada = 1;
      velocidadInvasores = 0.5;
      direccion = 1;
      balas = [];
      balasEnemigas = [];
      explosiones = [];
      nave.x = 210;
      crearInvasores();
      nuevoRecord = false;
      pausa = false;
      estado = "jugando";
    }

    // Sin vidas → cambia el acto y, si toca, guarda el récord
    function terminarJuego() {
      estado = "gameover";
      if (puntos > record) {
        record = puntos;
        nuevoRecord = true;
        localStorage.setItem("invaders-record", String(record));   // 💾 setItem guarda texto
      }
    }

    // El tablero de teclas: apunta cuáles están presionadas AHORA.
    // keydown apunta true, keyup apunta false, y el game loop lo consulta.
    var teclas = {};

    document.addEventListener("keydown", function (e) {
      teclas[e.key] = true;

      // ENTER cambia de acto: del inicio (o del game over) a jugar
      if (e.key === "Enter" && !e.repeat && estado !== "jugando") {
        empezarJuego();
      }
      // P voltea la pausa (solo tiene sentido mientras juegas)
      if ((e.key === "p" || e.key === "P") && !e.repeat && estado === "jugando") {
        pausa = !pausa;
      }

      // ESPACIO dispara. !e.repeat quiere decir "solo si la tecla es NUEVA":
      // si la dejas apretada, el teclado la repite solito (manguera de balas 🚿)
      if (e.key === " " && !e.repeat && estado === "jugando" && !pausa) {
        disparar();
      }

      // Que las flechas y ESPACIO no muevan la página mientras juegas
      if (e.key === " " || e.key === "ArrowLeft" || e.key === "ArrowRight" ||
          e.key === "ArrowUp" || e.key === "ArrowDown") {
        e.preventDefault();
      }
    });

    document.addEventListener("keyup", function (e) {
      teclas[e.key] = false;
    });

    // Si la ventana pierde el foco (te fuiste a otra pestaña), soltamos todas
    // las teclas: así la nave no se queda caminando sola
    window.addEventListener("blur", function () {
      teclas = {};
    });

    // ============================================================
    //  4) LAS REGLAS DEL MUNDO
    // ============================================================
    function moverNave() {
      if (teclas["ArrowLeft"]) {
        nave.x = nave.x - nave.velocidad;   // ← resta: hacia la izquierda
      }
      if (teclas["ArrowRight"]) {
        nave.x = nave.x + nave.velocidad;   // → suma: hacia la derecha
      }
      // Pared izquierda: si se pasó de 0, la regresamos a 0
      if (nave.x < 0) nave.x = 0;
      // Pared derecha: su esquina izquierda no puede pasar de
      // canvas.width - nave.ancho (si no, se saldría media nave)
      if (nave.x > canvas.width - nave.ancho) {
        nave.x = canvas.width - nave.ancho;
      }
    }

    // ESPACIO → nace una bala nueva en la punta del cañón
    function disparar() {
      balas.push({
        x: nave.x + nave.ancho / 2 - 3,   // centrada (la bala mide 6 de ancho)
        y: nave.y - 14,                   // justo arriba de la nave
        ancho: 6,
        alto: 14,
        velocidad: 8
      });
      beep(880, 0.08);                    // ¡piu!
    }

    function moverBalas() {
      // 1) TODAS las balas suben un poquito en cada cuadro
      for (var i = 0; i < balas.length; i++) {
        balas[i].y = balas[i].y - balas[i].velocidad;
      }
      // 2) 🧹 El barrido: me quedo SOLO con las que siguen visibles
      balas = balas.filter(function (bala) {
        return bala.y + bala.alto > 0;
      });
    }

    // La formación: 4 filas × 8 columnas con ciclos anidados
    function crearInvasores() {
      invasores = [];
      for (var fila = 0; fila < 4; fila++) {          // filas: 0,1,2,3
        for (var columna = 0; columna < 8; columna++) { // columnas: 0…7
          invasores.push({
            x: 40 + columna * 50,   // cada columna, 50px más a la derecha
            y: 50 + fila * 45,      // cada fila, 45px más abajo
            ancho: 34,
            alto: 26,
            vivo: true
          });
        }
      }
    }

    // La marcha en bloque: el truco de la banderita 🚩
    function moverInvasores() {
      var tocanBorde = false;    // la banderita empieza abajo

      // 1) Todos avanzan hacia el mismo lado
      for (var i = 0; i < invasores.length; i++) {
        var inv = invasores[i];
        inv.x = inv.x + velocidadInvasores * direccion;
        // 2) ¿ALGUNO de los vivos tocó la pared? Se levanta la banderita
        if (inv.vivo && (inv.x < 0 || inv.x + inv.ancho > canvas.width)) {
          tocanBorde = true;
        }
      }

      // 3) Si la banderita se levantó: TODOS bajan 18 píxeles y media vuelta
      if (tocanBorde) {
        for (var j = 0; j < invasores.length; j++) {
          invasores[j].y = invasores[j].y + 18;
        }
        direccion = direccion * -1;
      }
    }

    // Si algún invasor llega a la altura de la nave: pierdes una vida y la
    // formación vuelve a empezar desde arriba
    function revisarLlegada() {
      var llegaron = false;
      for (var i = 0; i < invasores.length; i++) {
        var inv = invasores[i];
        if (inv.vivo && inv.y + inv.alto >= nave.y) llegaron = true;
      }
      if (llegaron) {
        perderVida();
        crearInvasores();
      }
    }

    // El detector de choques (AABB): ¿se tocan los rectángulos a y b?
    function chocan(a, b) {
      // Las 4 formas de estar SEGUROS de que NO se tocan:
      var aEstaALaIzquierda = a.x + a.ancho < b.x;
      var aEstaALaDerecha   = a.x > b.x + b.ancho;
      var aEstaArriba       = a.y + a.alto < b.y;
      var aEstaAbajo        = a.y > b.y + b.alto;

      // ¿Alguna escapatoria? → no chocan
      if (aEstaALaIzquierda || aEstaALaDerecha || aEstaArriba || aEstaAbajo) {
        return false;
      }
      // Sin escapatoria → se superponen
      return true;
    }

    // Cada bala contra cada invasor (¡ciclos anidados otra vez!)
    function revisarChoques() {
      for (var i = 0; i < balas.length; i++) {
        for (var j = 0; j < invasores.length; j++) {
          var inv = invasores[j];
          if (inv.vivo && chocan(balas[i], inv)) {
            inv.vivo = false;        // 💀 este ya no se dibuja ni estorba
            balas[i].y = -100;       // la bala se va lejos: el filter la barrerá
            puntos = puntos + 10;
            explosiones.push({ x: inv.x, y: inv.y, tiempo: 18 });
            beep(220, 0.15);         // ¡boom!
          }
        }
      }
    }

    // Cada explosión dura 18 cuadros: restar-y-barrer (el patrón de las balas)
    function apagarExplosiones() {
      for (var i = 0; i < explosiones.length; i++) {
        explosiones[i].tiempo = explosiones[i].tiempo - 1;
      }
      explosiones = explosiones.filter(function (ex) {
        return ex.tiempo > 0;
      });
    }

    // De vez en cuando, un invasor vivo elegido al azar suelta una bala
    function contraatacar() {
      var vivos = invasores.filter(function (inv) { return inv.vivo; });
      if (vivos.length === 0) return;   // nadie vivo, nadie dispara

      if (Math.random() < 0.01 + oleada * 0.004) {   // de vez en cuando…
        // 1) tirador al azar entre los vivos 🎲
        var tirador = vivos[Math.floor(Math.random() * vivos.length)];
        // 2) su bala nace justo debajo de él y CAE (velocidad positiva)
        balasEnemigas.push({
          x: tirador.x + tirador.ancho / 2 - 3,
          y: tirador.y + tirador.alto,
          ancho: 6,
          alto: 14,
          velocidad: 3
        });
      }
    }

    // Mover-y-barrer, tercera vez: estas balas CAEN (se suma a la y)
    function moverBalasEnemigas() {
      for (var i = 0; i < balasEnemigas.length; i++) {
        balasEnemigas[i].y = balasEnemigas[i].y + balasEnemigas[i].velocidad;
      }
      balasEnemigas = balasEnemigas.filter(function (bala) {
        return bala.y < canvas.height;
      });
    }

    // ¿Alguna bala enemiga le dio a tu nave? La MISMA chocan() de siempre
    function revisarImpactos() {
      var teDieron = false;
      for (var i = 0; i < balasEnemigas.length; i++) {
        if (chocan(balasEnemigas[i], nave)) teDieron = true;
      }
      if (teDieron) perderVida();
    }

    function perderVida() {
      vidas = vidas - 1;
      balasEnemigas = [];        // se limpia el aire: un respiro para ti
      beep(110, 0.4);            // ouch…
      if (vidas <= 0) terminarJuego();         // 💀 GAME OVER
    }

    // ¿Limpiaste la pantalla? some() pregunta "¿ALGUNO cumple esto?"
    // y responde true o false
    function revisarOleada() {
      var quedanVivos = invasores.some(function (inv) { return inv.vivo; });
      if (!quedanVivos) {
        oleada = oleada + 1;
        velocidadInvasores = velocidadInvasores + 0.5;   // 🌊 cada oleada, más rápido
        balasEnemigas = [];
        crearInvasores();
        beep(523, 0.2);          // ¡oleada nueva!
      }
    }

    // Las estrellas caen y, al salir por abajo, reaparecen arriba
    function moverEstrellas() {
      for (var i = 0; i < estrellas.length; i++) {
        estrellas[i].y = estrellas[i].y + estrellas[i].velocidad;
        if (estrellas[i].y > canvas.height) {
          estrellas[i].y = 0;
          estrellas[i].x = Math.random() * canvas.width;
        }
      }
    }

    // El director: solo deja actuar a las funciones del acto en escena
    function actualizar() {
      if (!pausa) moverEstrellas();   // el fondo se mueve en cualquier pantalla

      if (estado === "jugando" && !pausa) {
        moverNave();
        moverBalas();
        moverInvasores();
        moverBalasEnemigas();
        contraatacar();
        revisarChoques();
        revisarImpactos();
        revisarLlegada();
        revisarOleada();
        apagarExplosiones();
      }
    }

    // ============================================================
    //  5) EL DIBUJO  (y al final, el game loop)
    // ============================================================
    function dibujarEstrellas() {
      ctx.fillStyle = "#6b6b9a";
      for (var i = 0; i < estrellas.length; i++) {
        ctx.fillRect(estrellas[i].x, estrellas[i].y, 2, 2);
      }
    }

    function dibujarNave() {
      ctx.fillStyle = "#00e5ff";
      ctx.fillRect(nave.x, nave.y + 8, nave.ancho, nave.alto - 8);    // el cuerpo
      ctx.fillRect(nave.x + nave.ancho / 2 - 5, nave.y, 10, 8);       // el cañón
    }

    function dibujarBalas() {
      ctx.fillStyle = "#ffe95c";
      for (var i = 0; i < balas.length; i++) {
        ctx.fillRect(balas[i].x, balas[i].y, balas[i].ancho, balas[i].alto);
      }
    }

    // Pixel-art con puros fillRect: cuerpo, dos antenitas y dos ojos
    function dibujarInvasores() {
      for (var i = 0; i < invasores.length; i++) {
        var inv = invasores[i];
        if (inv.vivo) {            // los muertos ya no se dibujan
          ctx.fillStyle = "#ff4dd8";
          ctx.fillRect(inv.x, inv.y + 6, inv.ancho, inv.alto - 6);    // cuerpo
          ctx.fillRect(inv.x + 4, inv.y, 4, 6);                       // antena izquierda
          ctx.fillRect(inv.x + inv.ancho - 8, inv.y, 4, 6);           // antena derecha
          ctx.fillStyle = "#0a0a1f";
          ctx.fillRect(inv.x + 8, inv.y + 12, 5, 5);                  // ojo izquierdo
          ctx.fillRect(inv.x + inv.ancho - 13, inv.y + 12, 5, 5);     // ojo derecho
        }
      }
    }

    function dibujarExplosiones() {
      ctx.font = "24px sans-serif";
      for (var i = 0; i < explosiones.length; i++) {
        var ex = explosiones[i];
        ctx.fillText("💥", ex.x + 2, ex.y + 22);
      }
    }

    function dibujarBalasEnemigas() {
      ctx.fillStyle = "#ff4dd8";
      for (var i = 0; i < balasEnemigas.length; i++) {
        var bala = balasEnemigas[i];
        ctx.fillRect(bala.x, bala.y, bala.ancho, bala.alto);
      }
    }

    function dibujarMarcador() {
      ctx.fillStyle = "#eaeaf5";
      ctx.font = "16px monospace";
      ctx.fillText("PUNTOS: " + puntos, 12, 26);
      ctx.fillText("OLEADA " + oleada, 200, 26);
      // Un corazón por cada vida, arriba a la derecha
      for (var i = 0; i < vidas; i++) {
        ctx.fillText("❤️", 400 + i * 24, 26);
      }
      ctx.fillStyle = "#a3a3c8";
      ctx.font = "13px monospace";
      ctx.fillText("🏆 RÉCORD: " + record, 12, 510);
      ctx.fillText("P = pausa", 396, 510);
    }

    // Un letrero centrado en la pantalla, con una línea chica debajo
    function dibujarLetrero(titulo, color, detalle) {
      ctx.textAlign = "center";
      ctx.fillStyle = color;
      ctx.font = "bold 34px monospace";
      ctx.fillText(titulo, canvas.width / 2, 300);
      ctx.fillStyle = "#eaeaf5";
      ctx.font = "16px monospace";
      ctx.fillText(detalle, canvas.width / 2, 335);
      ctx.textAlign = "left";    // regresar el pincel a la normalidad
    }

    // Las pantallas son puro fillText sobre el espacio
    function dibujarInicio() {
      ctx.textAlign = "center";
      ctx.fillStyle = "#39ff8e";
      ctx.font = "bold 40px monospace";
      ctx.fillText("SPACE INVADERS", canvas.width / 2, 170);
      ctx.fillStyle = "#ff4dd8";
      ctx.font = "18px monospace";
      ctx.fillText("un juego de " + AUTOR, canvas.width / 2, 205);
      ctx.fillStyle = "#eaeaf5";
      ctx.font = "bold 20px monospace";
      ctx.fillText("ENTER para empezar", canvas.width / 2, 290);
      ctx.fillStyle = "#a3a3c8";
      ctx.font = "14px monospace";
      ctx.fillText("← → moverte · ESPACIO disparar · P pausa", canvas.width / 2, 325);
      ctx.fillText("🏆 Récord: " + record, canvas.width / 2, 380);
      ctx.textAlign = "left";    // regresar el pincel a la normalidad
    }

    function dibujarGameOver() {
      // Una cortina oscura encima del mundo, y el letrero
      ctx.fillStyle = "rgba(5, 5, 15, 0.75)";
      ctx.fillRect(0, 0, canvas.width, canvas.height);
      ctx.textAlign = "center";
      ctx.fillStyle = "#ff5c7a";
      ctx.font = "bold 40px monospace";
      ctx.fillText("GAME OVER", canvas.width / 2, 220);
      ctx.fillStyle = "#eaeaf5";
      ctx.font = "18px monospace";
      ctx.fillText("Puntos: " + puntos + "   🏆 Récord: " + record, canvas.width / 2, 262);
      if (nuevoRecord) {
        ctx.fillStyle = "#ffe95c";
        ctx.fillText("¡NUEVO RÉCORD! 🏆", canvas.width / 2, 296);
      }
      ctx.fillStyle = "#eaeaf5";
      ctx.fillText("ENTER para la revancha", canvas.width / 2, 345);
      ctx.textAlign = "left";
    }

    function dibujar() {
      // La goma 🧽: borrar todo y pintar de nuevo
      ctx.fillStyle = "#0a0a1f";
      ctx.fillRect(0, 0, canvas.width, canvas.height);

      dibujarEstrellas();

      // Cada acto pinta su propia pantalla
      if (estado === "inicio") {
        dibujarInicio();
      } else {
        dibujarInvasores();
        dibujarBalas();
        dibujarBalasEnemigas();
        dibujarNave();
        dibujarExplosiones();
        dibujarMarcador();
        if (pausa) dibujarLetrero("⏸ PAUSA", "#ffe95c", "P para continuar");
        if (estado === "gameover") dibujarGameOver();
      }
    }

    // ============================================================
    //  EL GAME LOOP: actualizar → dibujar → repetir
    // ============================================================
    // requestAnimationFrame nos llama cada vez que la pantalla se repinta y
    // nos pasa la HORA en milisegundos. Casi todas las pantallas repintan 60
    // veces por segundo, pero las "gamer" repintan 120 o más: ahí tu juego
    // correría al doble de velocidad. 😵 El remedio: el mundo avanza en
    // PASOS de 1/60 de segundo, y en cada repintado damos solo los pasos
    // que caben en el tiempo que pasó (casi siempre 1; a veces 0 o 2).
    var PASO = 1000 / 60;     // lo que dura un paso, en milisegundos
    var horaAnterior = 0;     // hasta qué hora ya avanzó el mundo

    function cuadro(hora) {
      var pasos = Math.round((hora - horaAnterior) / PASO);
      horaAnterior = horaAnterior + pasos * PASO;
      if (pasos > 5) {        // el arranque, o la pestaña estuvo dormida:
        pasos = 1;            // no intentamos recuperar el tiempo perdido
        horaAnterior = hora;
      }

      for (var i = 0; i < pasos; i++) {
        actualizar();
      }
      dibujar();
      requestAnimationFrame(cuadro);   // "llámame en el siguiente repintado"
    }

    requestAnimationFrame(cuadro);   // ¡enciende el motor!
  </script>
</body>

      onda.connect(volumen);                       // onda → volumen →
      volumen.connect(audio.destination);          // → tus bocinas

    // El detector de choques (AABB): ¿se tocan los rectángulos a y b?
    function chocan(a, b) {
      // Las 4 formas de estar SEGUROS de que NO se tocan:
      var aEstaALaIzquierda = a.x + a.ancho < b.x;
      var aEstaALaDerecha   = a.x > b.x + b.ancho;
      var aEstaArriba       = a.y + a.alto < b.y;
      var aEstaAbajo        = a.y > b.y + b.alto;

      // ¿Alguna escapatoria? → no chocan
      if (aEstaALaIzquierda || aEstaALaDerecha || aEstaArriba || aEstaAbajo) {
        return false;
      }
      // Sin escapatoria → se superponen
      return true;
    }

    // ============================================================
    //  EL GAME LOOP: actualizar → dibujar → repetir
    // ============================================================
    // requestAnimationFrame nos llama cada vez que la pantalla se repinta y
    // nos pasa la HORA en milisegundos. Casi todas las pantallas repintan 60
    // veces por segundo, pero las "gamer" repintan 120 o más: ahí tu juego
    // correría al doble de velocidad. 😵 El remedio: el mundo avanza en
    // PASOS de 1/60 de segundo, y en cada repintado damos solo los pasos
    // que caben en el tiempo que pasó (casi siempre 1; a veces 0 o 2).
    var PASO = 1000 / 60;     // lo que dura un paso, en milisegundos
    var horaAnterior = 0;     // hasta qué hora ya avanzó el mundo

    function cuadro(hora) {
      var pasos = Math.round((hora - horaAnterior) / PASO);
      horaAnterior = horaAnterior + pasos * PASO;
      if (pasos > 5) {        // el arranque, o la pestaña estuvo dormida:
        pasos = 1;            // no intentamos recuperar el tiempo perdido
        horaAnterior = hora;
      }

      for (var i = 0; i < pasos; i++) {
        actualizar();
      }
      dibujar();
      requestAnimationFrame(cuadro);   // "llámame en el siguiente repintado"
    }

    requestAnimationFrame(cuadro);   // ¡enciende el motor!
  </script>
</body>

🔥 RETOS DE JEFE (OPCIONALES, PARA LEYENDAS)

Tu juego está completo… pero un game dev nunca deja de iterar. Tres mejoras clásicas del Space Invaders original, ordenadas de menor a mayor dificultad:

  • 🛡️ Escudos: 4 bloques verdes entre tú y la invasión. Cada uno es un objeto {x, y, ancho, alto, vida: 4} en un arreglo. Las balas (tuyas Y enemigas) les restan vida con chocan(); en 0, desaparecen. Dibújalos más transparentes conforme pierden vida.
  • 🛸 Nave nodriza: cada tanto (azar, como el contraataque) cruza una nave por arriba de la pantalla: {x: -60, y: 30, ancho: 50, alto: 20, velocidad: 2}. Si le das: +50 puntos y un beep(1200, 0.3) especial. Si cruza completa, se va — el clásico "¿la sigo o me concentro?".
  • ⚡ Power-ups: al morir, algunos invasores (10% de azar) sueltan una cápsula que cae. Si la atrapas con la nave: 10 segundos de disparo doble (cuenta cuadros: 600). Necesitarás otro arreglo, otro chocan… puras piezas que ya dominas.

❓ MINI-QUIZ (el último del proyecto 🥁)

1. ¿Cómo logra el juego mostrar "pantallas" diferentes (menú, juego, game over) en un solo canvas?

Una variable + ifs = máquina de estados 🎬. Los juegos profesionales usan exactamente esta idea (con más estados: menús, niveles, cinemáticas…).

2. ¿Por qué el récord sigue ahí aunque cierres el navegador y regreses mañana?

Las variables mueren al cerrar la página; localStorage sobrevive. Por eso ahí guardamos récords… y por eso Code Quest recuerda tu XP. 💾

3. La pausa hace pausa = !pausa; ¿Qué significa el signo !?

! es el "no" lógico. Voltear un boolean con x = !x es EL patrón de los interruptores: pausa, música on/off, modo oscuro… 🔀
