NIVEL 9 · LECCIÓN 2

¡Fuego! Balas como arreglo de objetos 🔫

🎯 HOY VAS A LOGRAR…

Que tu nave dispare: cada ESPACIO crea una bala nueva en un arreglo, las balas suben solas, y las que salen de la pantalla se barren con filter para que tu juego no se llene de balas fantasma. 👻🧹

🧠 EL CONCEPTO: MUCHOS OBJETOS A LA VEZ

Hasta ahora tus juegos manejaban cosas de una en una: UNA serpiente, UN tablero. Pero ¿cuántas balas hay en Space Invaders? Depende del momento: cero al empezar, tres si disparas rápido, una si acaba de salir… Cuando no sabes cuántos habrá, la respuesta siempre es la misma: un arreglo.

El arreglo balas es como la charola de un horno de galletas 🍪: cada vez que disparas, push pone una galleta nueva en la charola. El game loop las hornea a todas por igual (todas suben). Y cuando una ya no sirve (salió de la pantalla), se retira de la charola — si no, se acumulan hasta quemar el horno. 🔥

Cada bala es un objeto en el arreglo. Nace con push, sube en cada cuadro, y al cruzar el borde superior el filter la elimina de la memoria.

🧹 La regla de oro: si no barres, se llena de fantasmas

Una bala que salió de la pantalla ya no se ve… pero sigue existiendo: el game loop la sigue moviendo y dibujando (fuera de cámara) 60 veces por segundo. Dispara 500 veces y tu juego estará arrastrando 500 balas fantasma 👻 — se pone lento sin que sepas por qué. La solución es filter, que ya conoces: quédate solo con las balas que cumplen "sigo en pantalla":

balas = balas.filter(function (bala) {
  return bala.y + bala.alto > 0;   // ✅ me quedo · ❌ me barren
});

Y un detalle de cadencia: en el evento usamos !e.repeat. Si dejas ESPACIO presionado, el teclado "repite" la tecla automáticamente como cuando dejas apretada una letra — sin ese candado, tu nave se convertiría en manguera de balas. 🚿

👀 MÍRALO FUNCIONAR

Dispara con ESPACIO y muévete con ← →. Abajo a la izquierda hay un espía 🕵️: el contador de balas vivas en memoria. Dispara varias veces y obsérvalo: sube cuando disparas… y baja cuando la bala sale. Ese número bajando es el filter haciendo su chamba.

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // ============================================================
    //  LOS DATOS  (la tabla de diseño, hecha código)
    // ============================================================
    // 🚀 La nave: UNA ficha con x, y, ancho, alto y velocidad
    var nave = {
      x: 210,            // su esquina IZQUIERDA (210 + 30 = 240: al centro)
      y: 470,
      ancho: 60,
      alto: 20,
      velocidad: 6       // píxeles que avanza en cada cuadro
    };

    // 🔸 Las balas: un arreglo que empieza vacío (se llena al disparar)
    var balas = [];

    // ============================================================
    //  EL TECLADO
    // ============================================================
    // El tablero de teclas: apunta cuáles están presionadas AHORA.
    // keydown apunta true, keyup apunta false, y el game loop lo consulta.
    var teclas = {};

    document.addEventListener("keydown", function (e) {
      teclas[e.key] = true;

      // ESPACIO dispara. !e.repeat quiere decir "solo si la tecla es NUEVA":
      // si la dejas apretada, el teclado la repite solito (manguera de balas 🚿)
      if (e.key === " " && !e.repeat) disparar();

      // Que las flechas y ESPACIO no muevan la página mientras juegas
      if (e.key === " " || e.key === "ArrowLeft" || e.key === "ArrowRight" ||
          e.key === "ArrowUp" || e.key === "ArrowDown") {
        e.preventDefault();
      }
    });

    document.addEventListener("keyup", function (e) {
      teclas[e.key] = false;
    });

    // Si la ventana pierde el foco (te fuiste a otra pestaña), soltamos todas
    // las teclas: así la nave no se queda caminando sola
    window.addEventListener("blur", function () {
      teclas = {};
    });

    // ============================================================
    //  LAS REGLAS DEL MUNDO
    // ============================================================
    function moverNave() {
      if (teclas["ArrowLeft"]) {
        nave.x = nave.x - nave.velocidad;   // ← resta: hacia la izquierda
      }
      if (teclas["ArrowRight"]) {
        nave.x = nave.x + nave.velocidad;   // → suma: hacia la derecha
      }
      // Pared izquierda: si se pasó de 0, la regresamos a 0
      if (nave.x < 0) nave.x = 0;
      // Pared derecha: su esquina izquierda no puede pasar de
      // canvas.width - nave.ancho (si no, se saldría media nave)
      if (nave.x > canvas.width - nave.ancho) {
        nave.x = canvas.width - nave.ancho;
      }
    }

    // ESPACIO → nace una bala nueva en la punta del cañón
    function disparar() {
      balas.push({
        x: nave.x + nave.ancho / 2 - 3,   // centrada (la bala mide 6 de ancho)
        y: nave.y - 14,                   // justo arriba de la nave
        ancho: 6,
        alto: 14,
        velocidad: 8
      });
    }

    function moverBalas() {
      // 1) TODAS las balas suben un poquito en cada cuadro
      for (var i = 0; i < balas.length; i++) {
        balas[i].y = balas[i].y - balas[i].velocidad;
      }
      // 2) 🧹 El barrido: me quedo SOLO con las que siguen visibles
      balas = balas.filter(function (bala) {
        return bala.y + bala.alto > 0;
      });
    }

    // Todo lo que cambia en un cuadro
    function actualizar() {
      moverNave();
      moverBalas();
    }

    // ============================================================
    //  EL DIBUJO
    // ============================================================
    function dibujarNave() {
      ctx.fillStyle = "#00e5ff";
      ctx.fillRect(nave.x, nave.y + 8, nave.ancho, nave.alto - 8);    // el cuerpo
      ctx.fillRect(nave.x + nave.ancho / 2 - 5, nave.y, 10, 8);       // el cañón
    }

    function dibujarBalas() {
      ctx.fillStyle = "#ffe95c";
      for (var i = 0; i < balas.length; i++) {
        ctx.fillRect(balas[i].x, balas[i].y, balas[i].ancho, balas[i].alto);
      }
    }

    function dibujar() {
      // La goma 🧽: borrar todo y pintar de nuevo
      ctx.fillStyle = "#0a0a1f";
      ctx.fillRect(0, 0, canvas.width, canvas.height);

      dibujarBalas();
      dibujarNave();

      ctx.fillStyle = "#a3a3c8";
      ctx.font = "13px monospace";
      ctx.fillText("← → moverte · ESPACIO disparar", 12, 24);
      // El espía 🕵️: cuántas balas siguen vivas en memoria
      ctx.fillText("🕵️ balas en memoria: " + balas.length, 12, 510);
    }

    // ============================================================
    //  EL GAME LOOP: actualizar → dibujar → repetir
    // ============================================================
    // requestAnimationFrame nos llama cada vez que la pantalla se repinta y
    // nos pasa la HORA en milisegundos. Casi todas las pantallas repintan 60
    // veces por segundo, pero las "gamer" repintan 120 o más: ahí tu juego
    // correría al doble de velocidad. 😵 El remedio: el mundo avanza en
    // PASOS de 1/60 de segundo, y en cada repintado damos solo los pasos
    // que caben en el tiempo que pasó (casi siempre 1; a veces 0 o 2).
    var PASO = 1000 / 60;     // lo que dura un paso, en milisegundos
    var horaAnterior = 0;     // hasta qué hora ya avanzó el mundo

    function cuadro(hora) {
      var pasos = Math.round((hora - horaAnterior) / PASO);
      horaAnterior = horaAnterior + pasos * PASO;
      if (pasos > 5) {        // el arranque, o la pestaña estuvo dormida:
        pasos = 1;            // no intentamos recuperar el tiempo perdido
        horaAnterior = hora;
      }

      for (var i = 0; i < pasos; i++) {
        actualizar();
      }
      dibujar();
      requestAnimationFrame(cuadro);   // "llámame en el siguiente repintado"
    }

    requestAnimationFrame(cuadro);   // ¡enciende el motor!
  </script>
</body>

PISTA 1 Para que una bala SUBA, su y debe HACERSE MÁS CHICA (en canvas, el 0 está arriba). Recorre el arreglo con un for y a cada balas[i].y réstale balas[i].velocidad.
PISTA 2 El barrido es una sola instrucción: balas = balas.filter(function (bala) { … }). Adentro, return bala.y + bala.alto > 0; — o sea: "consérvame mientras mi parte de abajo siga dentro de la pantalla".
SOLUCIÓN EXPLICADA 
function moverBalas() {
  // 1) TODAS las balas suben un poquito en cada cuadro
  for (var i = 0; i < balas.length; i++) {
    balas[i].y = balas[i].y - balas[i].velocidad;
  }
  // 2) 🧹 El barrido: me quedo SOLO con las que siguen visibles.
  //    Una bala está fuera cuando hasta su borde de abajo
  //    (bala.y + bala.alto) ya cruzó el 0 de arriba.
  balas = balas.filter(function (bala) {
    return bala.y + bala.alto > 0;
  });
}
El for mueve, el filter limpia. Esta pareja (mover-y-barrer) la vas a repetir con las balas enemigas de la Lección 5 — y en cualquier juego con proyectiles, partículas o enemigos que aparecen y mueren.

❓ MINI-QUIZ

1. ¿Por qué las balas se guardan en un ARREGLO y la nave no?

Regla de diseño: cantidad fija y conocida → variables u objetos sueltos; cantidad que cambia durante el juego → arreglo. 📦📦📦

2. ¿Qué pasaría si NUNCA elimináramos las balas que salen de la pantalla?

Las balas fantasma 👻 consumen trabajo del game loop aunque no se vean. Barrer lo que ya no sirve es higiene básica de game dev — por eso existe el contador-espía en el ejemplo.

3. ¿Qué hace exactamente balas.filter(function (bala) { return bala.y + bala.alto > 0; })?

filter es un colador 🫗: pasa cada elemento por la pregunta y se queda con los que respondan true. Por eso lo reasignamos: balas = balas.filter(…).
