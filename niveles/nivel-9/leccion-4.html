Colisiones y explosiones: la matemática de los juegos 💥

🎯 HOY VAS A LOGRAR…

Escribir la función chocan(a, b) — el detector de choques que usan (con maquillaje) casi todos los videojuegos 2D del planeta — para que tus balas destruyan invasores: +10 puntos, explosión 💥 y marcador en pantalla.

🧠 EL CONCEPTO: ¿CUÁNDO SE TOCAN DOS RECTÁNGULOS?

Todo en tu juego es un rectángulo con x, y, ancho, alto (¿recuerdas la tabla de diseño? esto era a propósito 😏). La técnica se llama AABB, y su truco genial es preguntar al revés: en lugar de "¿se tocan?", pregunta "¿hay forma de que NO se toquen?".

Piensa en dos coches en una foto aérea de un estacionamiento 🚗🚙. Es seguro que NO chocan si pasa cualquiera de estas 4 cosas: uno está totalmente a la izquierda del otro, totalmente a la derecha, totalmente arriba o totalmente abajo. ¿Ninguna de las 4 se cumple? Entonces no hay escapatoria: se están tocando. 💥

Las 4 escapatorias: a totalmente a la izquierda, a la derecha, arriba o abajo de b. Si TODAS fallan, los rectángulos se superponen sí o sí.

🧮 Las 4 escapatorias, en código

function chocan(a, b) {
  var aEstaALaIzquierda = a.x + a.ancho < b.x;   // mi borde derecho ni llega a b
  var aEstaALaDerecha   = a.x > b.x + b.ancho;   // empiezo después de que b termina
  var aEstaArriba       = a.y + a.alto < b.y;    // mi parte de abajo ni llega a b
  var aEstaAbajo        = a.y > b.y + b.alto;    // empiezo debajo del final de b

  if (aEstaALaIzquierda || aEstaALaDerecha || aEstaArriba || aEstaAbajo) {
    return false;   // hay escapatoria → imposible que se toquen
  }
  return true;      // no hay escapatoria… ¡CHOCAN! 💥
}

Lo hermoso: chocan(a, b) no sabe qué es una bala ni qué es un invasor. Solo entiende rectángulos. Por eso la MISMA función servirá en la Lección 5 para "bala enemiga vs tu nave", y en cualquier juego que hagas después. Eso es una función bien diseñada: hace una cosa, y la hace para siempre. 🧩

🔍 ¿Y quién choca con quién?

revisarChoques() compara cada bala contra cada invasor (¡otra vez ciclos anidados! hoy todo se conecta). Cuando hay choque: el invasor muere (vivo = false — te dije que ese dato serviría 😉), la bala se manda a y = -100 para que el filtro de la Lección 2 la barra, se suman 10 puntos y nace una explosión con su cuenta regresiva de cuadros.

✏️ TU TURNO

En esta versión tus balas atraviesan a los invasores como fantasmas 👻, porque chocan() siempre responde false. Escribe tú la detección AABB completa (las 4 escapatorias, el || y los dos return). Sabrás que lo lograste cuando veas el primer 💥.

@@CODE:n9l4-turno@@
PISTA 1 Son 4 variables (una por escapatoria), un if con tres || ("o"), y dos return. Las fórmulas exactas están en los comentarios TODO — tu chamba es convertirlas en código y entender POR QUÉ funcionan.
PISTA 2 No olvides borrar el return false; del final. En una función, return termina la ejecución: si tu código nuevo está DESPUÉS de ese return, jamás se ejecutará. (Este es uno de los bugs más clásicos del mundo. 🐛)
SOLUCIÓN EXPLICADA 
function chocan(a, b) {
  // Las 4 formas de estar SEGUROS de que NO se tocan:
  var aEstaALaIzquierda = a.x + a.ancho < b.x;
  var aEstaALaDerecha   = a.x > b.x + b.ancho;
  var aEstaArriba       = a.y + a.alto < b.y;
  var aEstaAbajo        = a.y > b.y + b.alto;

  // ¿Alguna escapatoria? → no chocan
  if (aEstaALaIzquierda || aEstaALaDerecha || aEstaArriba || aEstaAbajo) {
    return false;
  }
  // Sin escapatoria → se superponen
  return true;
}
Léela como detective 🕵️: "¿puedo demostrar que están separados? ¿No? Entonces se tocan". Preguntar por el caso contrario hace el código más simple — un truco mental que usarás mil veces más.

❓ MINI-QUIZ

1. ¿Cuál es la idea central de la detección AABB?

Preguntar "¿hay escapatoria?" es mucho más simple que listar todas las formas de tocarse. Cuatro comparaciones y listo: por eso AABB mueve casi todos los juegos 2D. 🎮

2. Si a.x + a.ancho < b.x es verdadero, ¿qué sabemos con seguridad?

Es la escapatoria de la izquierda: si mi lado derecho (x + ancho) ni siquiera alcanza el inicio del otro (b.x), hay aire entre los dos. ✅

3. Al chocar, hacemos balas[i].y = -100; ¿Por qué funciona eso para "eliminar" la bala?

¡Reutilizamos la limpieza que YA construimos en la Lección 2! En vez de escribir otro sistema para borrar balas, la mandamos a donde el barrendero ya trabaja. Los buenos programas reusan sus piezas. 🧹
