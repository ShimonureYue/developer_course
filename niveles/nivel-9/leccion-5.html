🧠 EL CONCEPTO: RIESGO + RECOMPENSA = DIVERSIÓN

Hasta ayer, tu juego era tiro al blanco: tú disparas, ellos reciben. 🎯 Divertido… 2 minutos. Los diseñadores de juegos saben el secreto: un juego se siente VIVO cuando puedes perder. Hoy le damos dientes a los invasores.

Un buen juego es como un partidito de futbol en la calle ⚽: si el otro equipo no puede meterte gol, te aburres aunque vayas ganando 10-0. La emoción no está en ganar fácil: está en que te pueden anotar — y en que cada partido (oleada) el rival juega un poquito mejor.

Las tres piezas del "game feel" de hoy: balas enemigas que caen ☄️, corazones que se rompen 💔, y oleadas que aceleran la marcha. Perder tiene que ser posible.

☄️ El contraataque: azar bien usado

¿Cómo decide una computadora "de vez en cuando, dispara uno"? Con probabilidad, como el dado de la manzana de Snake 🎲: en cada cuadro, Math.random() saca un número entre 0 y 1; si sale menor que 0.014, un invasor vivo elegido al azar suelta una bala. 60 cuadros por segundo × probabilidad pequeñita ≈ un disparo por ahí de cada segundo. Y ojo: las balas enemigas son OTRO arreglo (balasEnemigas) con su mismo patrón mover-y-barrer — tercera vez que lo usas, ya es tuyo.

🔊 Sonidos retro con WebAudio: tu sintetizador de 8 bits

Nada de descargar mp3: vas a fabricar el sonido con código, como las consolas de los 80. El navegador trae un sintetizador escondido (AudioContext) que genera ondas. Nuestra función beep() pide una onda cuadrada (la del sonido "de maquinita" 🕹️), le pone frecuencia (aguda o grave) y duración:

function beep(frecuencia, duracion) {
  if (!audio) audio = new AudioContext();      // el sintetizador (solo 1 vez)
  var onda = audio.createOscillator();         // el generador de la onda
  var volumen = audio.createGain();            // la perilla de volumen
  onda.type = "square";                        // cuadrada = 8 bits 🕹️
  onda.frequency.value = frecuencia;           // Hz: agudo ↑ o grave ↓
  volumen.gain.value = 0.05;                   // bajito 👂
  onda.connect(volumen);                       // onda → volumen →
  volumen.connect(audio.destination);          // → tus bocinas
  onda.start();
  onda.stop(audio.currentTime + duracion);     // se apaga solo
}

beep(880, 0.08);   // ¡piu! disparo (agudo, cortito)
beep(220, 0.15);   // ¡boom! explosión (grave)
beep(110, 0.4);    // ouch… vida perdida (gravísimo, largo)

La regla del diseño sonoro arcade: agudo = bueno/pequeño, grave = malo/grande. Con una sola función y dos números tienes efectos para todo el juego.

✏️ TU TURNO

En esta versión los invasores son inofensivos 😴: contraatacar() está vacía y nunca disparan. Complétala: elige un tirador al azar entre los vivos y mete su bala al arreglo balasEnemigas. Cuando la primera bala rosa caiga hacia ti… corre. 🏃

@@CODE:n9l5-turno@@
PISTA 1 Elegir al azar de un arreglo es el truco de la manzana de Snake: vivos[Math.floor(Math.random() * vivos.length)] — Math.random() da un decimal entre 0 y 1, lo multiplicas por el tamaño del arreglo y Math.floor lo redondea hacia abajo: un índice válido.
PISTA 2 La bala enemiga es igualita a las tuyas pero nace ABAJO del tirador (y: tirador.y + tirador.alto) y su velocidad es positiva (3) porque en moverBalasEnemigas() se SUMA: cae en vez de subir.
SOLUCIÓN EXPLICADA 
function contraatacar() {
  var vivos = invasores.filter(function (inv) { return inv.vivo; });
  if (vivos.length === 0) return;   // nadie vivo, nadie dispara

  if (Math.random() < 0.01 + oleada * 0.004) {   // de vez en cuando…
    // 1) tirador al azar entre los vivos 🎲
    var tirador = vivos[Math.floor(Math.random() * vivos.length)];
    // 2) su bala nace justo debajo de él y CAE (velocidad positiva)
    balasEnemigas.push({
      x: tirador.x + tirador.ancho / 2 - 3,
      y: tirador.y + tirador.alto,
      ancho: 6,
      alto: 14,
      velocidad: 3
    });
  }
}
Fíjate en la probabilidad: 0.01 + oleada * 0.004. En la oleada 1 disparan poco; en la 5, llueven balas. UN número controla la dificultad — y tú decides su valor, porque el diseñador eres tú. 🎛️

❓ MINI-QUIZ

1. ¿Cómo logra el juego que los invasores disparen "de vez en cuando"?

Azar por cuadro = comportamiento impredecible con UNA línea. Y como la probabilidad crece con la oleada, la dificultad sube sola. 🎲

2. En beep(880, 0.08) y beep(110, 0.4), ¿qué controla el primer número?

Frecuencia = qué tan aguda es la nota; el segundo número es la duración en segundos. Regla arcade: agudo para lo bueno, grave para lo malo. 🎵

3. Al limpiar una oleada, el juego hace velocidadInvasores = velocidadInvasores + 0.5. ¿Por qué?

Igual que Snake aceleraba con cada manzana 🍎: si el juego no crece contigo, te aburre. Una suma pequeñita = curva de dificultad infinita.
