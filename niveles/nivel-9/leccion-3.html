NIVEL 9 · LECCIÓN 3

La invasión: 32 enemigos con ciclos anidados 👾

🎯 HOY VAS A LOGRAR…

Crear la formación completa de invasores (4 filas × 8 columnas = 32 enemigos) con ciclos anidados, y hacer que marchen como un solo bloque: derecha… borde… ¡TODOS bajan y dan media vuelta! 🫡

🧠 EL CONCEPTO: CICLOS ANIDADOS (¡PARA ESTO SIRVEN!)

Cuando aprendiste ciclos en Python te dijimos que servían para repetir. Hoy descubres su verdadero poder: un ciclo ADENTRO de otro genera cuadrículas enteras. ¿Escribir 32 invasores a mano? Serían como 200 líneas aburridísimas. ¿Con ciclos anidados? 6 líneas. 🤯

Un ciclo anidado funciona como acomodar sillas para un festival 🪑: el ciclo de afuera dice "vamos con la fila 0, la 1, la 2, la 3…" y el de adentro, POR CADA fila, coloca las 8 sillas una por una. Fila por fila, silla por silla: 4 × 8 = 32 sillas sin acomodar ninguna a mano.

El ciclo de afuera genera cada FILA; el de adentro coloca las 8 COLUMNAS de esa fila. La posición se calcula multiplicando: x = 40 + columna * 50, y = 50 + fila * 45.

🫡 Marchar en bloque: el truco de la banderita

El movimiento clásico de los invasores parece complicado, pero es un truco elegante de 3 pasos que se repite cada cuadro:

  1. Todos avanzan hacia el mismo lado: inv.x + velocidad * direccion (dirección 1 = derecha, -1 = izquierda).
  2. Mientras avanzan, levantamos una banderita si ALGUNO tocó la pared: tocanBorde = true.
  3. Si la banderita se levantó: TODOS bajan 18 píxeles y la dirección se voltea multiplicando por −1. Media vuelta, ¡marchen! 🎺

Fíjate que el invasor tiene un dato nuevo en su ficha: vivo: true. Todavía no sirve para nada… pero en la próxima lección, cuando tus balas empiecen a darles, será la diferencia entre dibujarse o no. Los diseñadores piensan una lección adelante. 😉

✏️ TU TURNO

La pantalla está vacía porque crearInvasores() no crea nada. 🏜️ Escribe los dos ciclos anidados que fabrican la formación de 4 filas × 8 columnas. Cuando ejecutes y aparezcan los 32 marchando, respira ese poder. 😤

@@CODE:n9l3-turno@@
PISTA 1 La estructura es: for (var fila = 0; fila < 4; fila++) { for (var columna = 0; columna < 8; columna++) { … } }. El push va en el centro, dentro de AMBOS ciclos (revisa que tus llaves { } cierren bien).
PISTA 2 El objeto que se mete al arreglo ya te lo dejamos comentado en el TODO 3: descoméntalo. Lee sus cuentas: x: 40 + columna * 50 — la columna 0 queda en 40, la 1 en 90, la 2 en 140… ¿Ves cómo el ciclo "acomoda las sillas"? 🪑
SOLUCIÓN EXPLICADA 
function crearInvasores() {
  invasores = [];
  for (var fila = 0; fila < 4; fila++) {          // filas: 0,1,2,3
    for (var columna = 0; columna < 8; columna++) { // columnas: 0…7
      invasores.push({
        x: 40 + columna * 50,   // cada columna, 50px más a la derecha
        y: 50 + fila * 45,      // cada fila, 45px más abajo
        ancho: 34,
        alto: 26,
        vivo: true              // (nos servirá en la Lección 4 💥)
      });
    }
  }
}
El ciclo de adentro corre COMPLETO (8 veces) por CADA vuelta del de afuera: fila 0 → 8 invasores, fila 1 → 8 más… total 4 × 8 = 32 objetos en el arreglo. Cuadrículas, tableros, mapas de plataformas: todo se genera así.

❓ MINI-QUIZ

1. En los ciclos anidados de crearInvasores(), ¿cuántas veces se ejecuta el push?

Los ciclos anidados MULTIPLICAN: afuera × adentro. Por eso con 2 numeritos controlas el tamaño de toda la invasión.

2. ¿Para qué sirve la variable tocanBorde en moverInvasores()?

Si cada invasor rebotara por su cuenta, la formación se desarmaría en segundos. La banderita hace que la DECISIÓN sea de todo el bloque: uno toca, todos giran. 🫡

3. Con x: 40 + columna * 50, ¿dónde queda el invasor de la columna 3?

La fórmula convierte el NÚMERO de columna en PÍXELES: 40 de margen + 50 por cada columna anterior. Mismo truco para la y con las filas. 📐
