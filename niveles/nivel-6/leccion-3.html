NIVEL 6 · LECCIÓN 3

¿Quién ganó? El detector de victorias 🏆🔍

🎯 HOY VAS A LOGRAR…

Enseñarle a tu juego a ver: detectar las 8 formas de ganar con la función checarGanador(), cantar "¡gato!" 😼 cuando hay empate, y congelar el tablero cuando la partida termina. 🧊

🧠 EL CONCEPTO

Tu Gato ya tiene memoria… pero es pésimo árbitro 😅: puedes hacer tres en línea y se queda tan tranquilo. Hoy le damos ojos. Piénsalo como humano: cuando juegas gato en papel, ¿cómo sabes que ganaste? Revisas las filas, las columnas y las diagonales. Son exactamente 8 formas de ganar, ni una más. Y como conocemos los números de las casillas (0 a 8), podemos escribir esas 8 formas… ¡como datos!

checarGanador() es como un árbitro con checklist 📋: tiene una lista con las 8 líneas posibles y, después de cada jugada, las recorre una por una preguntando "¿estas 3 casillas tienen el MISMO símbolo?". Si encuentra una, pita el silbatazo final. 🔔

Cada línea ganadora se ilumina junto a su trío de índices: las filas en cian, las columnas en magenta y las diagonales en amarillo. ¡Las reglas del gato caben en un arreglo! 📋

📦📦 Un arreglo de arreglos (¡inception!)

Un arreglo puede guardar números, textos… ¡y también OTROS arreglos! (en Python las listas también podían, ¿te acuerdas?). Así guardamos las 8 líneas ganadoras:

const COMBOS = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8],   // las 3 filas
  [0, 3, 6], [1, 4, 7], [2, 5, 8],   // las 3 columnas
  [0, 4, 8], [2, 4, 6]               // las 2 diagonales
];
// COMBOS[0] es [0, 1, 2] … y COMBOS[0][2] es el número 2 🤯

Usamos const porque las reglas del gato nunca cambian: es una caja sellada con candado. 🔒

🔍 El árbitro: checarGanador()

Ahora el for recorre el checklist. Para cada combo saca sus 3 posiciones y pregunta si las 3 casillas del tablero tienen el mismo símbolo:

function checarGanador() {
  for (let i = 0; i < COMBOS.length; i++) {
    let combo = COMBOS[i];     // por ejemplo [0, 1, 2]
    let a = combo[0];
    let b = combo[1];
    let c = combo[2];
    if (tablero[a] !== "" && tablero[a] === tablero[b] && tablero[a] === tablero[c]) {
      return tablero[a];       // "❌" o "⭕": ¡tenemos ganador! 🏆
    }
  }
  return "";                   // nadie ha ganado (todavía)
}

Dos detalles de detective 🕵️: el && significa "y" (las tres condiciones deben cumplirse, como and en Python). Y el tablero[a] !== "" es OBLIGATORIO: sin él, tres casillas vacías serían "iguales entre sí" y el juego cantaría victoria en el primer segundo. Es el bug clásico del gato. 🐛

😼 "¡Gato!" y el candado final

Faltan dos reglas. Empate: si el tablero se llenó y nadie ganó, en México se canta "¡gato!" (por eso el juego se llama así 😼). Y fin del juego: cuando alguien gana, nadie más puede mover — para eso una variable juegoTerminado que empieza en false y un candado al inicio de jugar():

function tableroLleno() {
  for (let i = 0; i < 9; i++) {
    if (tablero[i] === "") {
      return false;   // encontré un hueco: aún se puede jugar
    }
  }
  return true;        // el for terminó sin huecos: ¡lleno!
}

// y al inicio de jugar(i):
if (juegoTerminado) { return; }   // 🧊 partida congelada

PISTA 1 La estructura del árbitro es: for (let i = 0; i < COMBOS.length; i++) { … } y adentro let combo = COMBOS[i];. Recuerda que combo es un arreglito de 3 números: combo[0], combo[1] y combo[2] son POSICIONES del tablero, no símbolos. Los símbolos son tablero[combo[0]], etc.
PISTA 2 La condición completa (cópiala con calma, el && significa "y"): if (tablero[a] !== "" && tablero[a] === tablero[b] && tablero[a] === tablero[c]). ¿Por qué el !== ""? Sin él, tres casillas vacías "empatan" entre sí y ganaría nadie desde el inicio. 🐛
SOLUCIÓN COMPLETA EXPLICADA 
function checarGanador() {
  for (let i = 0; i < COMBOS.length; i++) {
    let combo = COMBOS[i];      // el checklist, línea por línea
    let a = combo[0];           // las 3 posiciones de esta línea
    let b = combo[1];
    let c = combo[2];
    if (tablero[a] !== "" && tablero[a] === tablero[b] && tablero[a] === tablero[c]) {
      return tablero[a];        // mismo símbolo ×3 → ese es el ganador
    }
  }
  return "";                    // revisé las 8 y… nada
}

function tableroLleno() {
  for (let i = 0; i < 9; i++) {
    if (tablero[i] === "") {
      return false;             // un hueco basta para seguir jugando
    }
  }
  return true;                  // 9 casillas revisadas, cero huecos
}
El patrón es idéntico en las dos: un for que busca algo y hace return en cuanto lo encuentra; si el ciclo entero termina sin encontrarlo, el return de abajo da la respuesta contraria. Ese truco de "buscar y salir temprano" lo vas a usar TODA tu vida de programador. 🔍

❓ MINI-QUIZ

1. ¿Cuántas formas de ganar hay en el gato y cómo las guardamos?

3 filas, 3 columnas y 2 diagonales = 8 líneas. Cada una es un arreglito de 3 índices, y las 8 viven juntas en COMBOS. Las reglas del juego… ¡convertidas en datos! 📋

2. ¿Para qué sirve el tablero[a] !== "" en la condición del árbitro?

Es el bug clásico del gato 🐛: "" === "" es verdadero, así que una línea vacía "empataría" consigo misma. Primero verificamos que haya un símbolo de verdad.

3. ¿Cuál es el trabajo de la variable juegoTerminado?

Es el candado final 🧊: empieza en false, se vuelve true con victoria o gato, y el if (juegoTerminado) { return; } bloquea cualquier jugada extra. En la próxima lección le pondremos el botón para descongelarlo. 🔄
