NIVEL 6 · LECCIÓN 2

El estado del juego: la memoria del Gato 🧠

🎯 HOY VAS A LOGRAR…

Darle memoria a tu tablero: guardar las 9 casillas en un arreglo, llevar el turno de ❌ y ⭕, y que cada clic pinte el símbolo correcto… sin dejar que nadie haga trampa pisando casillas ocupadas. 🚫

🧠 EL CONCEPTO

Tu tablero de la Lección 1 se ve precioso… pero tiene amnesia total 😵‍💫: si le preguntas "¿qué hay en la casilla del centro?", no tiene idea. Hoy le damos la pieza ESTADO 📦 del patrón secreto: un lugar donde el juego RECUERDE qué hay en cada casilla. ¿Y qué es perfecto para guardar 9 cositas en orden? Un arreglo. Buenas noticias: ya los conoces — las listas de Python 🐍 se llaman arreglos (arrays) en JavaScript, y se usan casi igual:

# Python (Nivel 3)
inventario = ["espada", "poción", "escudo"]
inventario[0]        # "espada" — ¡los índices empiezan en 0!

// JavaScript (hoy)
let inventario = ["espada", "poción", "escudo"];
inventario[0]        // "espada" — misma idea, otra ortografía ⚡
El estado del Gato es como una cartera de huevos 🥚 con 9 huecos numerados del 0 al 8: cada hueco puede estar vacío (""), tener un ❌ o tener un ⭕. El tablero de botones es solo la FOTO de la cartera; la cartera de verdad vive en el arreglo.

Así se ve la memoria completa del juego — un arreglo de 9 textos vacíos y una variable para saber a quién le toca:

let tablero = ["", "", "", "", "", "", "", "", ""];  // 9 casillas vacías
let turno = "❌";                                     // empieza ❌

¿Y cuál casilla es cuál? Numeramos de izquierda a derecha y de arriba a abajo, empezando en 0 (como TODO en programación):

 0 | 1 | 2
---+---+---
 3 | 4 | 5      ←  tablero[4] es el CENTRO del tablero
---+---+---
 6 | 7 | 8

Clic en el botón 4 → el símbolo se guarda en la caja 4 del arreglo. La pantalla es el espejo 🪞; la verdad vive en tablero.

🕹️ Reaccionar al clic (con regla anti-trampas)

Cuando el jugador toca la casilla i, pasan 3 cosas — y una regla de oro con if ANTES que todo:

function jugar(i) {
  if (tablero[i] !== "") {
    return;              // 🚫 casilla ocupada: ¡nadie pisa una jugada!
  }
  tablero[i] = turno;    // 1) guarda la jugada en el ESTADO
  pintar();              // 2) DIBUJA el estado nuevo en los botones
  if (turno === "❌") {  // 3) cambia el turno para el siguiente
    turno = "⭕";
  } else {
    turno = "❌";
  }
}

Sin ese primer if, ⭕ podría hacer clic encima de un ❌ y borrarlo. Las reglas de los juegos se escriben con if — igual que "¿te alcanza para la salsa?" en el Taco Clicker. 🌶️

Último truco del día: para conectar los 9 botones no escribimos 9 veces lo mismo. Les pusimos ids c0, c1, … c8 y usamos un for con el pegamento "c" + i. Gracias a let, cada botón recuerda SU número. 🔌

    // ===== 📦 ESTADO: la memoria del juego =====
    let tablero = ["", "", "", "", "", "", "", "", ""];
    let turno = "❌";

    // ===== 🖌️ DIBUJAR: del arreglo a la pantalla =====
    function pintar() {
      for (let i = 0; i < 9; i++) {
        document.getElementById("c" + i).textContent = tablero[i];
      }
    }

    // ===== 🕹️ REACCIONAR: un clic del jugador =====
    function jugar(i) {
      if (tablero[i] !== "") {
        return;              // 🚫 casilla ocupada: aquí no pasa nada
      }
      tablero[i] = turno;    // 1) guarda la jugada en el ESTADO
      pintar();              // 2) DIBUJA el estado nuevo
      if (turno === "❌") {  // 3) le toca al que sigue
        turno = "⭕";
      } else {
        turno = "❌";
      }
      document.getElementById("mensaje").textContent = "Turno de: " + turno;
    }

    // conecta los 9 botones con un ciclo 🔌
    // (gracias a let, cada botón recuerda SU número i)
    for (let i = 0; i < 9; i++) {
      document.getElementById("c" + i).addEventListener("click", function () {
        jugar(i);
      });
    }
  </script>
</body>
</html>

¿Notaste que los botones nunca se tocan directamente al jugar? El clic cambia el arreglo, y pintar() copia el arreglo a los botones. Estado por un lado, pantalla por el otro. Ese orden te va a salvar la vida en juegos más grandes. 🦺

PISTA 1 El estado son solo 2 líneas: let tablero = ["", "", "", "", "", "", "", "", ""]; (cuenta las comillas: ¡son 9 pares!) y let turno = "❌";. Y pintar() es un for (let i = 0; i < 9; i++) que copia cada tablero[i] a su botón.
PISTA 2 Dentro de jugar(i) el orden importa: primero el candado if (tablero[i] !== "") { return; }, luego tablero[i] = turno; y pintar();, y AL FINAL el cambio de turno con if (turno === "❌") { … } else { … }. Si cambias el turno antes de guardar, ¡se pintará el símbolo equivocado!
SOLUCIÓN COMPLETA EXPLICADA 
// 📦 ESTADO: la memoria
let tablero = ["", "", "", "", "", "", "", "", ""];
let turno = "❌";

// 🖌️ DIBUJAR: copia el arreglo a los 9 botones
function pintar() {
  for (let i = 0; i < 9; i++) {
    document.getElementById("c" + i).textContent = tablero[i];
  }
}

// 🕹️ REACCIONAR: la jugada
function jugar(i) {
  if (tablero[i] !== "") {
    return;                    // casilla ocupada: se acabó la función aquí
  }
  tablero[i] = turno;          // guarda en el ESTADO…
  pintar();                    // …y el espejo se actualiza
  if (turno === "❌") {        // cambia el turno
    turno = "⭕";
  } else {
    turno = "❌";
  }
  document.getElementById("mensaje").textContent = "Turno de: " + turno;
}
Fíjate en el return del candado: corta la función en seco, así que si la casilla está ocupada NADA de lo demás se ejecuta. Y el turno se cambia DESPUÉS de guardar, para que la jugada sea de quien realmente le tocaba. 🕵️

❓ MINI-QUIZ

1. En let tablero = ["", "", "", "", "", "", "", "", ""], ¿cómo llegas a la casilla del CENTRO del tablero?

Los índices van del 0 al 8, así que la quinta casilla es la número 4. 🧮 Igualito que las listas de Python: lista[0] es la primera.

2. ¿Qué logra if (tablero[i] !== "") { return; } al inicio de jugar(i)?

Es la regla anti-trampas 🚫: si la casilla ya tiene algo, el return termina la función ahí mismo y la jugada no ocurre. Las reglas de los juegos se escriben con if.

3. Las listas de Python 🐍, en JavaScript se llaman…

Misma idea, otra ortografía ⚡: let tablero = ["", "", …] y tablero[4] funcionan igual que en Python. Lo que aprendiste allá, te sirve acá.
