NIVEL 5 · LECCIÓN 3

El DOM: tocar la página con código 🌳

🎯 HOY VAS A LOGRAR…

Usar JavaScript para cambiar la página en vivo: textos, colores y estilos. Vas a construir un contador de aplausos 👏 y un botón de modo oscuro 🌙, como los de las apps de verdad.

🧠 EL CONCEPTO

Cuando el navegador lee tu HTML, arma en su memoria un mapa de toda la página: cada etiqueta se vuelve una "caja" conectada con las demás, como un árbol genealógico. Ese mapa se llama DOM (Document Object Model, o en español: "el modelo de la página"). Lo importante: JavaScript puede tocar cualquier caja del árbol y cambiarla al instante. 🪄

El DOM es como un árbol de Navidad 🎄: cada etiqueta HTML es un adorno colgado en una rama. JavaScript es tu mano: puede agarrar cualquier adorno, cambiarle el color, el texto… o ponerle luces. ✨

La página como árbol de cajas: <html> arriba y cada etiqueta colgando adentro. JavaScript puede "prender" ✨ cualquier caja: eso que parpadea es tu <h1> siendo modificado en vivo.

🧰 Tu kit de herramientas DOM

Herramienta¿Qué hace?Ejemplo
document.getElementById("x")Encuentra la caja con id="x" 🔍let titulo = document.getElementById("titulo");
.textContentLee o cambia el texto de la caja ✏️titulo.textContent = "¡Nuevo texto!";
.styleCambia el CSS de la caja 🎨titulo.style.color = "hotpink";
.classListPone o quita clases CSS 🏷️document.body.classList.toggle("oscuro");

Con .classList tienes tres jugadas: .add("clase") la pone, .remove("clase") la quita, y .toggle("clase") es el interruptor: si está, la quita; si no está, la pone. 💡 Perfecto para un modo oscuro.

👀 MÍRALO FUNCIONAR

El famoso contador de aplausos 👏 (como el de muchas apps). Cada clic cambia una variable Y actualiza el texto en pantalla. Ejecuta y aplaude sin miedo:

<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: sans-serif; text-align: center; padding-top: 20px; }
    #boton-aplauso { font-size: 2rem; padding: 10px 25px; cursor: pointer; border-radius: 12px; }
    #contador { font-size: 1.5rem; font-weight: bold; }
  </style>
</head>
<body>
  <button id="boton-aplauso">👏 Aplaudir</button>
  <p id="contador">0 aplausos</p>

  <script>
    let aplausos = 0;   // el dato vive en una variable…

    let boton = document.getElementById("boton-aplauso");
    let contador = document.getElementById("contador");

    boton.addEventListener("click", function () {
      aplausos = aplausos + 1;                        // 1) cambia el dato
      contador.textContent = aplausos + " aplausos";  // 2) actualiza la pantalla
      if (aplausos === 10) {
        contador.style.color = "hotpink";             // 3) ¡premio a los 10! 🎉
        contador.textContent = aplausos + " aplausos 🔥 ¡ERES LEYENDA!";
      }
    });
  </script>
</body>
</html>

Fíjate en el patrón de oro 🥇: 1) cambias la variable, 2) actualizas la pantalla con textContent. Ese par de pasos es el corazón de TODAS las apps (y de los juegos que vas a hacer en el Nivel 6 😉). ¿Y esa función sin nombre dentro del addEventListener? Se llama función anónima: una función exprés que escribes ahí mismo porque solo se usa en ese lugar.

✏️ TU TURNO

Construye el interruptor de modo oscuro / claro 🌙☀️. El CSS ya tiene una clase .oscuro lista; tú conecta el botón para que ponga y quite esa clase del body:

<!DOCTYPE html>
<html>
<head>
  <style>
    body { font-family: sans-serif; text-align: center; padding-top: 20px;
           background: white; color: #222; transition: 0.4s; }
    body.oscuro { background: #0a0a1a; color: #eaeaf5; }
    #interruptor { font-size: 1.2rem; padding: 10px 20px; cursor: pointer; border-radius: 12px; }
  </style>
</head>
<body>
  <h1>Mi página camaleón 🦎</h1>
  <button id="interruptor">🌙 Cambiar modo</button>

  <script>
    // TODO 1: busca el botón "interruptor" con getElementById

    // TODO 2: escúchale el clic con addEventListener

    // TODO 3: adentro, usa document.body.classList.toggle("oscuro")
  </script>
</body>
</html>
PISTA 1 Son los mismos 3 pasos del botón de la lección pasada: agarrar el botón, escuchar el clic, hacer algo. Lo único nuevo es el "hacer algo": classList.toggle.
PISTA 2 El esqueleto: document.getElementById("interruptor").addEventListener("click", function () { … }); y adentro de las llaves va el toggle sobre document.body.
SOLUCIÓN EXPLICADA 
let interruptor = document.getElementById("interruptor"); // 1) agarra el botón

interruptor.addEventListener("click", function () {       // 2) escucha el clic
  document.body.classList.toggle("oscuro");               // 3) pone/quita la clase
});
toggle = interruptor de luz 💡: primer clic pone la clase oscuro (y el CSS pinta todo oscuro), segundo clic la quita. Tú no cambias colores a mano: cambias la CLASE y el CSS hace el resto. Equipo perfecto.

❓ MINI-QUIZ

1. ¿Qué es el DOM?

El navegador convierte tu HTML en un árbol de cajas 🌳. JavaScript agarra cualquier caja y la cambia en vivo: eso es "tocar el DOM".

2. Quieres cambiar el texto de <p id="marcador"> a "10 puntos". ¿Cuál línea es correcta?

Primero encuentras la caja con getElementById, luego le cambias su textContent. Buscar ➡️ cambiar: siempre en ese orden.

3. ¿Qué hace document.body.classList.toggle("oscuro")?

toggle = interruptor de luz 💡. JS solo mueve el interruptor (la clase); el CSS decide cómo se ve cada modo.
