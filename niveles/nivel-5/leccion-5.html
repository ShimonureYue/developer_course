NIVEL 5 · LECCIÓN 5 · 👑 JEFE

Jefe final: Taco Clicker 🌮👑

🎯 HOY VAS A LOGRAR…

Construir tu primer juego web completo: un taco gigante que suma tacos con cada clic, mejoras que cuestan tacos (🌶️ salsa y 👵 abuelita taquera) y rangos de taquero. Todo con lo que YA sabes: variables, funciones, eventos, DOM e if. ¡A darle, que es taco de verdad! 🌮

🧠 EL CONCEPTO

Los juegos "clicker" (como Cookie Clicker 🍪, que millones juegan) tienen una receta sorprendentemente simple. Es el mismo patrón de tu contador de aplausos… pero con premios que hacen crecer el negocio:

Un clicker es como tu propio puesto de tacos 🌮: cada clic es un taco que vendes. Con las ganancias compras mejoras: salsa secreta para vender más por clic, o contratas a la abuelita taquera que hace tacos solita aunque tú no toques nada. Invertir para ganar más… ¡economía de taquero! 📈

El corazón del Taco Clicker: clic → la variable sube → la pantalla se actualiza. Las mejoras solo cambian QUÉ tanto sube por clic… o hacen que suba sola. 👵

⏰ La pieza nueva: setInterval

Para que la abuelita haga tacos solita necesitas un despertador que suena una y otra vez. Eso es setInterval:

setInterval(function () {
  tacos = tacos + 1;   // esto corre solo…
  pintar();
}, 1000);              // …cada 1000 milisegundos (1 segundo) ⏰

Se lee: "cada 1000 milisegundos, corre esta función". Es el mismo truco de la función sin paréntesis de los eventos: no corre YA, corre cada vez que "suena el despertador".

🗺️ El plan de batalla (5 partes)

  1. El HTML: un botón gigante 🌮, el contador de tacos y los botones de mejora.
  2. El estado: variables tacos y porClic, y una función pintar() que actualiza la pantalla.
  3. El evento: clic al taco → sube tacos → pintar().
  4. Las mejoras: 🌶️ salsa (+2 por clic, cuesta 20) y 👵 abuelita (+1 taco/segundo con setInterval, cuesta 50). ¡Con if para checar que te alcance!
  5. Los rangos: con if/else if: 🧢 aprendiz → 🔥 taquero → 👑 leyenda del pastor.

👀 MÍRALO FUNCIONAR (¡juégalo primero!)

Así se ve el jefe ya vencido 😎. Juégalo: haz muchos clics, compra la salsa cuando tengas 20 tacos y contrata a la abuelita a los 50. Luego lee el código con calma: reconocerás CADA pieza:

<!DOCTYPE html>
<html>
<head>
  <style>
    body { background: #1a0f08; color: #ffe95c; font-family: sans-serif; text-align: center; }
    #contador { font-size: 2rem; margin: 10px 0 0; }
    #rango { font-size: 1.1rem; color: #ffb86c; margin: 4px 0; }
    #taco { font-size: 5rem; background: none; border: none; cursor: pointer; transition: transform 0.05s; }
    #taco:active { transform: scale(0.85); }
    .mejora { display: block; margin: 8px auto; padding: 10px 16px; font-size: 1rem;
              border-radius: 10px; border: 2px solid #ffb86c; background: #2b1a10;
              color: #ffe95c; cursor: pointer; }
  </style>
</head>
<body>
  <h1 id="contador">0 tacos</h1>
  <p id="rango">🧢 Aprendiz de taquero</p>
  <button id="taco">🌮</button>
  <button id="salsa" class="mejora">🌶️ Salsa secreta (+2 por clic) — cuesta 20 tacos</button>
  <button id="abuelita" class="mejora">👵 Abuelita taquera (+1 taco/seg) — cuesta 50 tacos</button>

  <script>
    // ===== PARTE 2: el estado =====
    let tacos = 0;
    let porClic = 1;

    function pintar() {
      document.getElementById("contador").textContent = tacos + " tacos";
      let rango = "🧢 Aprendiz de taquero";
      if (tacos >= 500) {
        rango = "👑 Leyenda del pastor";
      } else if (tacos >= 100) {
        rango = "🔥 Taquero de verdad";
      }
      document.getElementById("rango").textContent = rango;
    }

    // ===== PARTE 3: el evento del taco =====
    document.getElementById("taco").addEventListener("click", function () {
      tacos = tacos + porClic;
      pintar();
    });

    // ===== PARTE 4a: mejora salsa 🌶️ =====
    document.getElementById("salsa").addEventListener("click", function () {
      if (tacos >= 20) {
        tacos = tacos - 20;      // pagas la mejora
        porClic = porClic + 2;   // ¡ahora cada clic vale más!
        pintar();
      } else {
        alert("Te faltan tacos 😅 La salsa cuesta 20.");
      }
    });

    // ===== PARTE 4b: mejora abuelita 👵 =====
    document.getElementById("abuelita").addEventListener("click", function () {
      if (tacos >= 50) {
        tacos = tacos - 50;
        setInterval(function () {  // el despertador ⏰
          tacos = tacos + 1;
          pintar();
        }, 1000);
      } else {
        alert("Te faltan tacos 😅 La abuelita cuesta 50.");
      }
    });
  </script>
</body>
</html>

¿Ya viste? El juego completo son como 50 líneas y conoces todas: variables, funciones, eventos, DOM, if y el nuevo setInterval. Los videojuegos no son magia: son piezas simples bien acomodadas. 🧩

PISTA 1 Empieza SOLO con las partes 2 y 3: que el taco cuente clics (es tu contador de aplausos 👏 disfrazado de taco). Cuando eso funcione, sigue con las mejoras. Los jefes se vencen por partes.
PISTA 2 Cada mejora es un addEventListener con un if adentro: if (tacos >= 20) { tacos = tacos - 20; porClic = porClic + 2; pintar(); }. Y el despertador de la abuelita: setInterval(function () { … }, 1000);
SOLUCIÓN COMPLETA EXPLICADA 
// PARTE 2: el estado del juego
let tacos = 0;      // cuántos tacos llevas
let porClic = 1;    // cuánto vale cada clic

function pintar() {
  document.getElementById("contador").textContent = tacos + " tacos";
  // PARTE 5: los rangos (de mayor a menor para que gane el más alto)
  let rango = "🧢 Aprendiz de taquero";
  if (tacos >= 500) {
    rango = "👑 Leyenda del pastor";
  } else if (tacos >= 100) {
    rango = "🔥 Taquero de verdad";
  }
  document.getElementById("rango").textContent = rango;
}

// PARTE 3: el clic principal
document.getElementById("taco").addEventListener("click", function () {
  tacos = tacos + porClic;
  pintar();
});

// PARTE 4a: salsa 🌶️ — pagas 20, ganas +2 por clic
document.getElementById("salsa").addEventListener("click", function () {
  if (tacos >= 20) {
    tacos = tacos - 20;
    porClic = porClic + 2;
    pintar();
  }
});

// PARTE 4b: abuelita 👵 — pagas 50, +1 taco cada segundo
document.getElementById("abuelita").addEventListener("click", function () {
  if (tacos >= 50) {
    tacos = tacos - 50;
    setInterval(function () {
      tacos = tacos + 1;
      pintar();
    }, 1000);
  }
});
Lo más importante: pintar() es la única que toca la pantalla. Todos los demás solo cambian variables y luego llaman a pintar(). Ese patrón (estado + una función que dibuja) es EXACTAMENTE cómo funcionan los videojuegos del Nivel 6. 🎮

❓ MINI-QUIZ

1. ¿Qué hace setInterval(miFuncion, 1000)?

Es un despertador que suena repetido ⏰: cada 1000 ms ejecuta la función. Así la abuelita 👵 hace tacos aunque nadie haga clic.

2. ¿Por qué la mejora de salsa lleva un if (tacos >= 20)?

Las reglas del juego se escriben con if: "¿puede pagar? → cobra y mejora; ¿no puede? → no pasa nada". Sin esa regla, el jugador compraría gratis. 🕵️

3. En el juego, ¿cuál es el trabajo de la función pintar()?

Estado por un lado, pantalla por el otro, y pintar() de puente 🌉. Ese patrón te lo vas a encontrar en el Gato, en Snake… y en juegos profesionales.
