Decisiones y ciclos en JS 🔁

🎯 HOY VAS A LOGRAR…

Usar if/else, for y while en JavaScript (que YA dominas en Python 💪) y hacer magia: llenar una página con 100 estrellitas ⭐ usando solo 3 líneas de código.

🧠 EL CONCEPTO

Buenas noticias: hoy NO aprendes conceptos nuevos. Decidir con if y repetir con ciclos ya lo traes en la sangre desde Python. 🐍 Solo vas a aprender cómo se "visten" en JavaScript. Vamos por partes:

🚦 if / else: mismo semáforo, otras llaves

🐍 Python⚡ JavaScript
if vidas == 0:
    print("GAME OVER")
elif vidas == 1:
    print("¡Cuidado!")
else:
    print("Vas bien")
 
if (vidas === 0) {
  console.log("GAME OVER");
} else if (vidas === 1) {
  console.log("¡Cuidado!");
} else {
  console.log("Vas bien");
}

Tres cambios: la condición va entre paréntesis, el código va entre llaves, y elif se estira a else if.

⚠️ El detalle importante: === con TRES signos

En JavaScript comparar con == (doble) es como un guardia distraído 😴: deja pasar cosas "parecidas" — para él 5 == "5" es verdadero, ¡aunque uno es número y otro es texto! === (triple) es el guardia estricto 🫡: solo dice "verdadero" si son iguales en valor Y en tipo. Regla de oro: usa siempre === (y !== para "distinto").

🔁 Ciclos: for y while

¿Qué hace?🐍 Python⚡ JavaScript
Repetir 10 veces 
for i in range(10):
    print(i)
 
for (let i = 0; i < 10; i++) {
  console.log(i);
}
Repetir mientras… 
while vidas > 0:
    vidas = vidas - 1
 
while (vidas > 0) {
  vidas = vidas - 1;
}

El for de JS parece trabalenguas pero son 3 instrucciones separadas por punto y coma, como una receta de repetición:

for (let i = 0;   i < 10;   i++) {
//   ↑ inicio     ↑ ¿sigo?    ↑ después de cada vuelta
//  "i arranca   "repite      "súmale 1 a i"
//   en 0"        mientras i
//                sea menor
//                que 10"

Y i++ es un atajo de i = i + 1. Los programadores somos fans de los atajos. 😄

El ciclo da vueltas 🔁: en cada vuelta el contador i crece y el código de adentro se ejecuta otra vez. Tú escribes 3 líneas, la computadora hace las 100 vueltas.

PISTA 1 Mira la tabla de ciclos: en Python sería for i in range(100):. Tradúcelo con la receta for (inicio; ¿sigo?; avanza).
PISTA 2 La primera línea completa es: for (let i = 0; i < 100; i++) { — adentro va el append y al final cierras la llave }.
SOLUCIÓN EXPLICADA

❓ MINI-QUIZ

1. ¿Por qué conviene usar === en vez de == en JavaScript?

== es el guardia distraído 😴 y === el estricto 🫡. Con === evitas bugs raros donde un texto se confunde con un número.

2. ¿Cuál es la traducción correcta de for i in range(5): a JavaScript?

Las 3 partes: let i = 0 (arranca en 0), i < 5 (sigue mientras sea menor que 5), i++ (suma 1 por vuelta). Recorre 0, 1, 2, 3, 4 — igual que range(5).

3. ¿Cuántas veces se ejecuta el append aquí? for (let i = 0; i < 100; i++) { document.body.append("⭐"); }

Empieza en 0 y para cuando i llega a 100 (porque 100 < 100 es falso). De 0 a 99 hay exactamente 100 vueltas. 🌟
