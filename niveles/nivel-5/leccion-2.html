NIVEL 5 · LECCIÓN 2

Funciones y eventos: tu página te escucha 👂

🎯 HOY VAS A LOGRAR…

Escribir funciones en JavaScript (spoiler: ya sabes hacerlas en Python 🧩) y crear tu primer botón que hace algo cuando le das clic, usando eventos.

🧠 EL CONCEPTO

En el Nivel 4 te volviste Maestro de funciones en Python: máquinas que reciben ingredientes y hacen su chamba. Pues en JavaScript las funciones son exactamente lo mismo… con otra ropa. 🎭

🐍 Python⚡ JavaScript
def saludar(nombre):
    print("Hola", nombre)

saludar("Kai")
 
function saludar(nombre) {
  console.log("Hola", nombre);
}

saludar("Kai");

Los cambios: def se convierte en function, los dos puntos : se convierten en llaves { }, y listo. Llamarla es idéntico: nombre + paréntesis. Misma idea, otra ortografía. (Dato pro 🕶️: en JS también existen las "funciones flecha" como const saludar = (nombre) => {…}. Las verás por ahí; por ahora function es todo lo que necesitas.)

👂 Eventos: la página está escuchando

En Python tus programas corrían de arriba a abajo y se acababan. Una página web es diferente: se queda esperando a que pase algo — un clic, una tecla, el mouse moviéndose. Cada una de esas cosas es un evento.

Un evento es como el timbre de tu casa 🔔: el timbre está ahí, esperando. Cuando alguien lo toca (el evento), tú corres a abrir (la función). addEventListener significa: "cuando suene ESTE timbre, corre ESTA función".

El dedo hace clic → el botón dispara el evento "click" → la función despierta y hace su chamba. Ese viaje completo pasa en milisegundos. ⚡

La línea mágica se lee así:

boton.addEventListener("click", saludar);
//  ↑            ↑           ↑        ↑
// quién     "escucha…"   qué evento  qué función correr

Ojo 👀: se escribe saludar sin paréntesis. No le estás diciendo "córrela YA", le estás diciendo "córrela cuando pase el clic". Es como dejarle tu número a alguien: no te llama en ese momento, te llama después. 📞

👀 MÍRALO FUNCIONAR

Primero, funciones puras en JavaScript (compáralas mentalmente con tus def de Python):

Y ahora sí… 🥁 tu primer botón vivo. Esta es una página completa: HTML + JavaScript trabajando juntos. Dale ▶ Ejecutar y luego haz clic en el botón de la vista previa:

<!DOCTYPE html>
<html>
<body>
  <h1>Mi primer botón vivo 🔴</h1>
  <button id="boton-saludo">¡Tócame!</button>

  <script>
    // 1) La función que queremos que corra
    function saludar() {
      alert("¡Hola! Me tocaste 👋😄");
    }

    // 2) Buscamos el botón por su id
    let boton = document.getElementById("boton-saludo");

    // 3) "Cuando le den clic, corre saludar" (¡sin paréntesis!)
    boton.addEventListener("click", saludar);
  </script>
</body>
</html>

Dos cosas nuevas: alert() abre una ventanita emergente (el grito del navegador 📢), y document.getElementById("boton-saludo") busca en la página la etiqueta con ese id. En la próxima lección vas a dominar ese superpoder de "agarrar" cosas de la página. 🔮

PISTA 1 La receta de una función: function festejar() { … }. Adentro va alert("tu grito");. Es tu def de Python con llaves en vez de dos puntos.
PISTA 2 El botón se llama boton-festejo en su id. Entonces: let boton = document.getElementById("boton-festejo"); y después boton.addEventListener("click", festejar); — ¡sin paréntesis en festejar!
SOLUCIÓN EXPLICADA 
function festejar() {
  alert("¡GOOOOOOL! 🎉⚽");          // 1) la función lista para correr
}

let boton = document.getElementById("boton-festejo"); // 2) agarra el botón

boton.addEventListener("click", festejar); // 3) timbre conectado 🔔
El orden importa: primero existe la función, luego encuentras el botón, y al final los conectas. Si escribieras festejar() con paréntesis, ¡el alert saldría al cargar la página en vez de esperar el clic!

❓ MINI-QUIZ

1. ¿Cómo se traduce el def saludar(): de Python a JavaScript?

def → function, y los dos puntos + sangría → llaves { }. La idea de "máquina reutilizable" es la misma. 🧩

2. En boton.addEventListener("click", festejar), ¿por qué festejar va sin paréntesis?

Con paréntesis la función corre inmediatamente. Sin paréntesis solo le "dejas el número" 📞 al evento para que la llame después.

3. ¿Qué es un evento en una página web?

La página vive esperando eventos: clics, teclas, movimientos. Con addEventListener decides qué hacer cuando ocurren. 👂
