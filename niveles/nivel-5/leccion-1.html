🧠 EL CONCEPTO

Ya construiste páginas con HTML y las vestiste con CSS. Pero seamos honestos: hasta ahora tus páginas son como un póster pegado en la pared… bonito, pero no hace nada cuando lo tocas. Hoy eso se acaba. 😎

Piensa en un robot 🤖: el HTML es su cuerpo (cabeza, brazos, botones), el CSS es su pintura (colores, brillos, estilo)… y JavaScript es su cerebro: lo que hace que se mueva, responda y tome decisiones.

HTML pone las piezas, CSS las pinta… y JavaScript las hace reaccionar. Los tres viven juntos en la misma página.

⌥ option + ⌘ comando + J (Mac)  ·  F12 o Ctrl + Shift + J (Windows)

📦 Variables y constantes… ¡ya las conoces!

¿Te acuerdas de las cajas con etiqueta de Python? En JavaScript son exactamente la misma idea, solo cambia la ropa:

  • let crea una variable: una caja que puedes cambiar. 📦
  • const crea una constante: una caja sellada con candado. 🔒
let vidas = 3;            // caja que puede cambiar
const VELOCIDAD_MAX = 10; // caja sellada 🔒

✏️ TU TURNO

Traduce este programa de Python a JavaScript. En Python sería:

# Versión Python 🐍
puntos = 0
puntos = puntos + 50
NIVEL_MAXIMO = 10
print("Puntos:", puntos)
print("Nivel máximo:", NIVEL_MAXIMO)

Escríbelo en JavaScript aquí abajo. Usa let, const y console.log:

PISTA 1 Mira la tabla comparativa de arriba. 👀 Variable en JS: let nombre = valor; — es como Python pero con let adelante y ; al final.
PISTA 2 Sumar sobre lo que ya hay funciona igualito que en Python: puntos = puntos + 50;. Y para mostrar: console.log("Puntos:", puntos);
SOLUCIÓN EXPLICADA 
let puntos = 0;               // 1) caja nueva (let = puede cambiar)
puntos = puntos + 50;         // 2) igualito que en Python
const NIVEL_MAXIMO = 10;      // 3) caja sellada (const = candado 🔒)
console.log("Puntos:", puntos);          // 4) el print() de JS
console.log("Nivel máximo:", NIVEL_MAXIMO);
Compara línea por línea con la versión Python: la lógica es idéntica, solo cambió el "vestuario" del código. 🎭

❓ MINI-QUIZ

1. De los tres lenguajes de la web, ¿cuál se encarga del comportamiento (que la página reaccione)?

HTML pone las piezas 🧱, CSS las pinta 🎨 y JavaScript las hace reaccionar ⚡. Los tres trabajan en equipo en la misma página.

2. ¿Cómo se escribe el print("Hola") de Python en JavaScript?

En JavaScript los mensajes salen en la consola (la de DevTools o la retro de tus playgrounds), por eso se llama console.log.

3. Quieres una caja que NUNCA cambie, como los puntos que da una estrella. ¿Qué usas en JavaScript?

const viene de "constante": si intentas cambiarla, JavaScript te marca error. let es para las cajas que sí cambian.
