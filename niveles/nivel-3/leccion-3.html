🧠 EL CONCEPTO

➕ Parte 1: Python es una supercalculadora

Python conoce todas las operaciones de la escuela (y más):

  • + suma  ·  - resta  ·  * multiplicación (el asterisco, no la ✕)  ·  / división (la diagonal)
  • % el módulo: te da lo que sobra de una división 🌮
  • // división entera: cuánto le toca a cada quien, sin decimales
El módulo % con tacos: tienes 7 tacos para 2 amigos. 7 // 2 = 3 → a cada quien le tocan 3 tacos. 7 % 2 = 1 → sobra 1 taco (y ya sabes lo que se arma por ese taco 😤). El % siempre te dice "¿cuánto sobró?".

⚖️ Parte 2: comparar cosas (y el clásico == vs =)

Para decidir, primero hay que comparar. Estas comparaciones dan como resultado True (cierto) o False (falso) — ¡el tipo bool de la lección pasada!

  • == ¿son iguales?  ·  != ¿son diferentes?
  • > mayor que  ·  < menor que
  • >= mayor o igual  ·  <= menor o igual

🚨 EL CLÁSICO de todos los tiempos: no confundas = con ==. Grábatelo con este ritmo:

  • = un igual = guarda ("mete esto a la caja"): edad = 13
  • == dos iguales = pregunta ("¿esto es igual a esto?"): edad == 13

Hasta los programadores con 20 años de experiencia se equivocan con esto de repente. En serio. 😅

🚦 Parte 3: decisiones con if / else

Un if es un semáforo 🚦 en el camino de tu programa: si la condición es True, el programa toma un camino; si es False (else), toma el otro. Nunca los dos.

El camino se ilumina según la respuesta: si la condición es True se ejecuta lo del if; si es False, lo del else. Tu programa deja de ser una línea recta: ¡ahora se bifurca!

➡️ La indentación: lo de adentro se recorre a la derecha

Mira bien la forma de un if:

if edad >= 12:
    print("¡Pásale!")      # ← recorrido a la derecha: está ADENTRO del if
print("Esto pasa siempre")  # ← pegado a la izquierda: está AFUERA

Esos 4 espacios se llaman indentación y en Python son LEY: lo que está adentro de la decisión se recorre a la derecha. Así Python sabe qué líneas dependen del semáforo y cuáles no. Y no olvides los dos puntos : al final de la línea del if — son como decir "entonces:".

✏️ TU TURNO: LA MONTAÑA RUSA 🎢

En la feria hay una montaña rusa con DOS requisitos: tener 12 años o más Y medir 140 cm o más. Completa el programa para que decida si puedes subir. Como todavía no conocemos trucos avanzados (vienen en la próxima lección 😉), usa un if adentro de otro if: pasas el primer filtro, y adentro te espera el segundo.

PISTA 1 La estructura es un if dentro de otro. El segundo if va recorrido 4 espacios (está adentro del primero), y lo que está adentro del segundo va recorrido 8 espacios. Cada if con su else alineado a la misma altura.
PISTA 2 El esqueleto sin condiciones: 
if ______:
    if ______:
        print("🎢 ¡Súbete! ¡Wooo!")
    else:
        print("Te falta estatura, siguiente año 📏")
else:
    print("Te falta edad, ¡pero ya merito! 🎂")
Solo te falta llenar las dos preguntas con >=.
SOLUCIÓN EXPLICADA 
edad = 13
estatura = 145

if edad >= 12:                # primer filtro: la edad
    if estatura >= 140:       # segundo filtro (adentro): la estatura
        print("🎢 ¡Súbete! ¡Wooo!")
    else:
        print("Te falta estatura, siguiente año 📏")
else:
    print("Te falta edad, ¡pero ya merito! 🎂")
Pruébala con edad = 10 (te frena el primer filtro), y con edad = 13, estatura = 130 (pasas el primero, te frena el segundo). ¡Órale, tu programa ya toma decisiones dobles! 🎉

❓ MINI-QUIZ

1. ¿Cuánto da 7 % 2 en Python?

7 tacos entre 2 amigos: a cada quien le tocan 3 (7 // 2) y sobra 1 (7 % 2). El módulo siempre responde "¿cuánto sobró?". 🌮

2. ¿Cuál es la diferencia entre = y ==?

Un igual = guardar 📦. Dos iguales = preguntar ⚖️. Usar = en un if te da SyntaxError — el error más clásico del mundo.

3. ¿Para qué se recorren a la derecha (indentan) las líneas dentro de un if?

En Python la indentación es obligatoria: lo recorrido a la derecha está "adentro" del if y solo se ejecuta si la condición es True. Si la alineación está mal → IndentationError.
