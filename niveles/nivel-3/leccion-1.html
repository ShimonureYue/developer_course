🧠 EL CONCEPTO

Hasta ahora construiste páginas con HTML y CSS. Pero hoy empieza LA PROGRAMACIÓN DE VERDAD: vas a darle órdenes a la computadora y ella va a obedecerte. 😎

Python es un lenguaje de programación. ¿Y qué tan importante es? Pues mira quién lo usa todos los días:

  • 📸 Instagram — sus servidores corren con Python
  • 🎵 Spotify — lo usa para recomendarte música
  • 🚀 la NASA — sí, la de los cohetes, lo usa para analizar datos del espacio
  • ▶️ YouTube — también nació con mucho Python adentro

Y lo mejor: Python es famoso porque se lee casi como si fuera inglés. Por eso es el lenguaje favorito para empezar. (Dato curioso: se llama Python por un grupo de comediantes ingleses, Monty Python, no por la serpiente 🐍… pero la serpiente se quedó de mascota.)

Python es como un traductor superveloz: tú escribes instrucciones en su idioma, él las traduce a "idioma computadora" y la máquina las obedece al instante. Tu primera instrucción va a ser print(), que significa: "muestra esto en la pantalla".

El viaje de tu programa: tú escribes la instrucción, Python 🐍 la traduce y el resultado aparece en la pantalla. Ese viaje pasa cada vez que presionas ▶ Ejecutar.

Una regla de oro desde hoy: los textos siempre van entre comillas. "hola" es un texto. Sin comillas, Python cree que le hablas de otra cosa (y se confunde, ya lo verás abajo 👀).

🧟 LOS ERRORES NO MUERDEN

Te voy a contar un secreto de programadores: TODOS nos equivocamos, todos los días. La diferencia entre un principiante y un pro no es equivocarse menos… es saber leer el error para arreglarlo rápido.

Vamos a romper un programa a propósito 😈. Este print quiere mostrar la palabra hola, pero se le olvidaron las comillas. Ejecútalo y mira qué pasa:

Salió un texto rojo que termina más o menos así:

NameError: name 'hola' is not defined

Así se lee un error de Python, como detective 🕵️:

  1. No entres en pánico. El rojo no significa "reprobaste", significa "te tengo una pista".
  2. Lee la ÚLTIMA línea primero: ahí está el resumen del problema.
  3. NameError = "error de nombre". Python dice: "me hablaste de algo llamado hola y yo no conozco a ningún hola". Claro: sin comillas, Python pensó que hola era el nombre de algo guardado (¡eso lo aprenderás en la próxima lección!), no un texto.
  4. La cura: ponle sus comillas → print("hola"). Arréglalo arriba y ejecuta otra vez. ✅
Un error de Python es como cuando tu mamá te dice exactamente qué hiciste mal: incómodo por dos segundos… pero es justo la información que necesitas para arreglarlo. 😅

✏️ TU TURNO

Escribe un programa que se presente por ti. Debe imprimir 3 líneas:

  1. Tu nombre (por ejemplo: Me llamo Dani)
  2. Tu comida favorita (🌮 los tacos son una respuesta muy válida)
  3. Tu videojuego favorito 🎮
PISTA 1 Necesitas tres print(), uno por línea. Recuerda: el texto va adentro de los paréntesis y entre comillas.
PISTA 2 La primera línea sería: print("Me llamo Dani") — pero con TU nombre. Las otras dos son iguales, solo cambia el texto.
SOLUCIÓN EXPLICADA 
print("Me llamo Dani")            # línea 1: tu nombre
print("Mi comida favorita: tacos al pastor 🌮")  # línea 2
print("Mi juego favorito: Minecraft 🎮")         # línea 3
Cada print() es una orden independiente: Python las ejecuta de arriba hacia abajo, una por una, como una lista de pendientes.

❓ MINI-QUIZ

1. ¿Qué hace la instrucción print("buenas")?

Aunque print significa "imprimir" en inglés, en Python quiere decir "muestra esto en la pantalla". Nada de papel. 😄

2. ¿Cuál de estas líneas está escrita CORRECTAMENTE?

Un print completo necesita sus dos cosas: paréntesis para envolver y comillas para el texto. Sin comillas → NameError. Sin paréntesis → SyntaxError.
