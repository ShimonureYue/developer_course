🎯 HOY VAS A LOGRAR…

Que TU teclado mande: escuchar las teclas con keydown y event.key, mover un personaje con las flechas ⬆️⬇️⬅️➡️, y encerrarlo con if para que no se escape de la pantalla. Hasta hoy tus animaciones se movían solas; desde hoy, obedecen. 😎

🧠 EL CONCEPTO

En el nivel 5 aprendiste eventos con clics de botones. Las teclas funcionan IGUAL, solo que en vez de escuchar un botón, escuchas el teclado completo: document.addEventListener("keydown", miFuncion). Cada vez que una tecla baja (key down = "tecla abajo"), el navegador llama a tu función y le entrega un paquete llamado evento con toda la info del golpe.

Es como el timbre de tu casa 🔔: tú no te asomas a la puerta cada segundo por si llegó alguien; el timbre te AVISA. Y en la pantallita del interfón hasta ves QUIÉN es: eso es evento.key, el nombre exacto de la tecla que tocó. "ArrowUp", "a", " " (la barra espaciadora)… cada tecla dice su nombre.

Presionas ⬆️ → el navegador dispara el evento keydown con evento.key === "ArrowUp" → tu if lo reconoce → cambia la y → y el game loop dibuja al personaje más arriba. (Recuerda: subir = restar a la y 🙃).

Los nombres de las flechas son "ArrowUp", "ArrowDown", "ArrowLeft" y "ArrowRight" (respetando mayúsculas). Dos trucos de pro:

  • Velocidad como variable: en vez de y = y - 5 escribe y = y - VELOCIDAD. Así, cambiar la agilidad de tu personaje es tocar UN solo número. 🚀
  • evento.preventDefault(): las flechas también mueven la página (scroll). Esta línea le dice al navegador "yo me encargo, no muevas nada tú". 🙅

🖱️ Importante en TODOS los ejemplos de hoy: haz clic dentro de la vista previa primero, para que escuche tu teclado. El teclado solo le habla a la zona que tiene el "foco".

👀 MÍRALO FUNCIONAR

Un cuadrito que obedece tus flechas, y de paso te muestra el nombre de la última tecla que presionaste (así puedes descubrir cómo se llama CUALQUIER tecla 🕵️). Presiona ▶ Ejecutar…

🖱️ Haz clic dentro de la vista previa primero, para que escuche tu teclado. Luego usa ⬆️⬇️⬅️➡️:

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { background: #14142e; text-align: center; color: #a3a3c8; font-family: sans-serif; }
    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; margin-top: 8px; }
  </style>
</head>
<body>
  <p>🖱️ Haz clic aquí adentro y usa las flechas ⬆️⬇️⬅️➡️</p>
  <canvas id="lienzo" width="400" height="280"></canvas>

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    var x = 180;
    var y = 120;
    var TAM = 40;
    var VELOCIDAD = 6;                 // súbele si quieres turbo 🚀
    var ultimaTecla = "(ninguna)";

    // El oído: cada tecla presionada pasa por aquí 🔔
    document.addEventListener("keydown", function (evento) {
      ultimaTecla = evento.key;

      if (evento.key === "ArrowUp")    y = y - VELOCIDAD;  // subir = restar y 🙃
      if (evento.key === "ArrowDown")  y = y + VELOCIDAD;
      if (evento.key === "ArrowLeft")  x = x - VELOCIDAD;
      if (evento.key === "ArrowRight") x = x + VELOCIDAD;

      evento.preventDefault();  // que las flechas no muevan la página
    });

    function dibujar() {
      ctx.fillStyle = "#0d0d22";
      ctx.fillRect(0, 0, canvas.width, canvas.height);

      ctx.fillStyle = "#00e5ff";
      ctx.fillRect(x, y, TAM, TAM);

      // Chismógrafo de teclas: muestra el nombre de la última 🕵️
      ctx.fillStyle = "#a3a3c8";
      ctx.font = "13px monospace";
      ctx.fillText("evento.key: " + ultimaTecla, 10, 20);

      requestAnimationFrame(dibujar);
    }

    dibujar();
  </script>
</body>
</html>

🕵️ Presiona otras teclas (letras, espacio, shift…) y mira cómo se llaman en la esquina. Ese es el nombre que usarías en tu if. Nota: por ahora el cuadrito SÍ puede fugarse del lienzo… de eso te encargas tú. 👇

PISTA 1 Los 3 if que faltan son gemelos del que ya está. Solo cambia el nombre de la tecla y la operación: izquierda resta a x, arriba resta a y, abajo suma a y. Cópialos del ejemplo de arriba si quieres: los pros también leen código ajeno. 😉
PISTA 2 Para las paredes, piensa en cada borde: si x se hizo menor que 0, regrésalo a 0. Si x se pasó de canvas.width - TAM (la pared derecha menos el ancho del cuadro), regrésalo justo ahí: if (x > canvas.width - TAM) x = canvas.width - TAM;. Arriba y abajo son iguales pero con y y canvas.height.
SOLUCIÓN EXPLICADA 
// TODO 1: las 4 direcciones completas
if (evento.key === "ArrowRight") x = x + VELOCIDAD;
if (evento.key === "ArrowLeft")  x = x - VELOCIDAD;
if (evento.key === "ArrowUp")    y = y - VELOCIDAD;  // subir = restar 🙃
if (evento.key === "ArrowDown")  y = y + VELOCIDAD;

// TODO 2: paredes invisibles 🧱
if (x < 0) x = 0;
if (x > canvas.width - TAM) x = canvas.width - TAM;
if (y < 0) y = 0;
if (y > canvas.height - TAM) y = canvas.height - TAM;
¿Por qué canvas.width - TAM? Porque x es la esquina izquierda del cuadro. Si el lienzo mide 400 y el cuadro 40, la x más lejana permitida es 360: ahí el cuadro toca la pared derecha sin salirse. Estas 4 líneas son un "clamp" (abrazadera): sujetan al valor dentro de un rango. Las verás en TODOS tus juegos. 🔒

❓ MINI-QUIZ

1. Presionas la flecha hacia arriba. ¿Qué trae evento.key?

Cada tecla dice su nombre en inglés y con mayúsculas exactas: "ArrowUp", "ArrowDown", "ArrowLeft", "ArrowRight". Si dudas del nombre de una tecla, imprímelo y espía. 🕵️

2. Quieres que tu personaje SUBA cuando presionen ⬆️. ¿Qué haces con su y?

El clásico 🙃: en canvas, arriba es MENOS y. Subir = y = y - VELOCIDAD. Si tu personaje "sube al revés", ya sabes exactamente dónde mirar.

3. ¿Para qué escribimos if (x < 0) x = 0; en el juego?

Es una pared invisible 🧱: si la posición se volvió ilegal (menor que 0), la corregimos al valor límite. Con 4 de estas, tu personaje queda bien portado dentro del lienzo.
