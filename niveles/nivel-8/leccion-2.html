NIVEL 8 · LECCIÓN 2

El game loop: 60 dibujos por segundo 🎬

🎯 HOY VAS A LOGRAR…

Descubrir el truco detrás de TODA animación (borrar + dibujar muy rápido), programar tu primer game loop con requestAnimationFrame, y hacer que un cuadrito rebote solo por la pantalla como el logo de DVD 📀.

🧠 EL CONCEPTO

Te voy a contar un secreto que arruina la magia (o la hace mejor 😏): en los videojuegos NADA se mueve. Nunca. Lo que pasa es que la pantalla se borra y se vuelve a dibujar, con todo un poquito más allá, unas 60 veces por segundo. Tu cerebro hace el resto: ve movimiento donde solo hay fotos rapidísimas.

Es un flipbook 📖: ese cuadernito con un dibujo en la esquina de cada hoja. Cada página es CASI igual a la anterior, pero el monito está un milímetro más allá. Pasas las hojas rápido con el pulgar y… ¡el monito corre! Un videojuego es un flipbook de 60 páginas por segundo, y cada página la dibuja tu código.

A ese ciclo infinito se le llama game loop (ciclo de juego), y es el corazón 💓 de todo videojuego, desde Snake hasta el shooter más pesado. Siempre tiene los mismos 3 pasos:

El game loop da vueltas sin parar: actualizar (cambiar los números: x = x + velocidad) → dibujar (borrar todo y pintar de nuevo) → esperar un instante → repetir. 💓

¿Y cómo se hace ese ciclo en JavaScript? Con requestAnimationFrame(miFuncion), que significa: "Navegador, justo antes de pintar el siguiente cuadro, llama a miFuncion". Si adentro de miFuncion vuelves a pedir requestAnimationFrame(miFuncion)… ya armaste el ciclo infinito. 🔁

Y el movimiento es de risa: si en cada vuelta haces x = x + 3, el cuadrito aparece 3 píxeles más allá en cada cuadro. 60 cuadros después, avanzó 180 píxeles. ¡Eso ES moverse! Y para rebotar, solo necesitas un if: "si tocas el borde, voltea la velocidad" (vx = -vx).

👀 MÍRALO FUNCIONAR: EL PROTECTOR DE PANTALLA DVD 📀

El clásico de clásicos: un logo que rebota eternamente por la pantalla (y toda la humanidad esperando que pegue justo en la esquina 🙏). Presiona ▶ Ejecutar y luego experimenta: sube la velocidad a vx = 8, agranda el cuadro, o comenta la línea que borra el fondo para ver qué pasa (spoiler: arte accidental 🎨):

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { background: #14142e; text-align: center; }
    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; margin-top: 10px; }
  </style>
</head>
<body>
  <canvas id="lienzo" width="400" height="260"></canvas>

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // El estado del "juego": dónde está y qué tan rápido va
    var x = 50;
    var y = 80;
    var vx = 3;      // velocidad horizontal (píxeles por cuadro)
    var vy = 2;      // velocidad vertical
    var TAM = 46;    // tamaño del cuadro

    // PASO 1: actualizar (mover y rebotar)
    function actualizar() {
      x = x + vx;
      y = y + vy;

      // ¿Tocó el borde izquierdo o derecho? ¡Voltea la velocidad!
      if (x < 0 || x + TAM > canvas.width) vx = -vx;
      // ¿Tocó arriba o abajo?
      if (y < 0 || y + TAM > canvas.height) vy = -vy;
    }

    // PASO 2: dibujar (borrar TODO y pintar de nuevo)
    function dibujar() {
      ctx.fillStyle = "#0d0d22";
      ctx.fillRect(0, 0, canvas.width, canvas.height);  // ¡la goma! 🧽

      ctx.fillStyle = "#ff4dd8";
      ctx.fillRect(x, y, TAM, TAM);
      ctx.fillStyle = "#0d0d22";
      ctx.font = "bold 13px monospace";
      ctx.fillText("DVD", x + 9, y + 28);
    }

    // PASO 3: el ciclo que nunca termina 🔁
    function cicloDeJuego() {
      actualizar();
      dibujar();
      requestAnimationFrame(cicloDeJuego);  // "llámame en el siguiente cuadro"
    }

    cicloDeJuego();  // ¡enciende el motor!
  </script>
</body>
</html>

🧪 Experimento: cambia el color de fondo de la "goma" por "rgba(13, 13, 34, 0.15)" (una goma medio transparente)… y el cuadro dejará una estela fantasma. 👻

✏️ TU TURNO: HAZLO REBOTAR

Aquí tienes un cuadrito con game loop… pero sin rebotes: avanza a la derecha y se fuga del lienzo para siempre 🏃💨. Tu misión: completa los TODO para que rebote en los 4 bordes, como el DVD.

    var vy = 0;   // TODO 1: ponle velocidad vertical (prueba con 2)
    var TAM = 40;

    function actualizar() {
      x = x + vx;
      y = y + vy;

      // TODO 2: rebote horizontal — si x < 0 o si x + TAM > canvas.width,
      //         voltea la velocidad: vx = -vx;

      // TODO 3: rebote vertical — lo mismo pero con y, vy y canvas.height
    }

PISTA 1 Mira el ejemplo del DVD de arriba: el rebote horizontal es UNA línea con un if. La condición pregunta si se pasó del borde izquierdo (x < 0) o del derecho (x + TAM > canvas.width). El "o" en JavaScript es ||.
PISTA 2 if (x < 0 || x + TAM > canvas.width) vx = -vx; — eso resuelve el TODO 2. Para el TODO 3, cambia x → y, vx → vy y canvas.width → canvas.height. Y no olvides el TODO 1: con vy = 0 jamás rebotará arriba/abajo porque nunca sube ni baja.
SOLUCIÓN EXPLICADA 
var vy = 2;   // TODO 1: ahora también se mueve en vertical

function actualizar() {
  x = x + vx;
  y = y + vy;

  // TODO 2: si toca izquierda o derecha, la velocidad se voltea
  if (x < 0 || x + TAM > canvas.width) vx = -vx;

  // TODO 3: igual pero en vertical
  if (y < 0 || y + TAM > canvas.height) vy = -vy;
}
¿Por qué x + TAM y no solo x? Porque x es la esquina IZQUIERDA del cuadro: su lado derecho está en x + TAM. Si comparas solo x, el cuadro se entierra en la pared antes de rebotar. Y vx = -vx es el truco estrella: 3 se vuelve -3 (ahora va a la izquierda), y -3 se vuelve 3 (de regreso). ↔️

❓ MINI-QUIZ

1. ¿Cuál es el truco detrás de toda animación en canvas?

Como un flipbook 📖: nada se mueve de verdad, son "fotos" casi iguales pasando rapidísimo. Tu cerebro inventa el movimiento.

2. ¿Qué hace requestAnimationFrame(cicloDeJuego)?

Es una cita con el navegador: "avísame antes de pintar el siguiente cuadro". Si adentro vuelves a pedir otra cita, se forma el ciclo infinito del game loop. 🔁

3. Si un cuadro va a la derecha con vx = 4 y hacemos vx = -vx, ¿qué pasa?

Velocidad negativa = misma rapidez, dirección contraria. Voltear el signo es la forma más simple (y más usada) de rebotar. ↔️
