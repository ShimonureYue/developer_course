NIVEL 8 · LECCIÓN 1

Tu lienzo de píxeles 🖌️

🎯 HOY VAS A LOGRAR…

Dibujar con código sobre un <canvas>: rectángulos con fillRect, colores con fillStyle, círculos con arc… y entender el sistema de coordenadas de los videojuegos (spoiler: la Y está al revés que en mate 🙃).

🧠 EL CONCEPTO

Todo lo que has hecho en la web hasta ahora usa piezas prefabricadas: botones, párrafos, tablas. Pero un videojuego no está hecho de botones: está hecho de dibujos que cambian muy rápido. Para eso existe <canvas>, una etiqueta de HTML que es literalmente eso: un lienzo en blanco donde tu JavaScript dibuja lo que quiera.

Un canvas es como una hoja cuadriculada gigante 📐: cada cuadrito (píxel) tiene su dirección, como en Batalla Naval 🚢 — columna x y fila y. Tú le das órdenes al pincel: "píntame un rectángulo verde en la casilla (40, 60)". El pincel obedece. Siempre.

Para dibujar necesitas 2 pasos y 3 herramientas:

  1. Agarrar los pinceles: var ctx = canvas.getContext("2d"); — ctx (de "contexto") es tu caja de pinceles 🖌️.
  2. Elegir color: ctx.fillStyle = "#39ff8e"; — el pincel se queda con ese color hasta que lo cambies.
  3. Pintar: ctx.fillRect(x, y, ancho, alto); pinta un rectángulo relleno, y ctx.arc(...) dibuja círculos.

Pero OJO 👀, aquí viene lo más importante de la lección. En la clase de mate, la Y crece hacia arriba. En canvas (y en casi TODOS los videojuegos), el punto (0,0) está en la esquina superior IZQUIERDA y la Y crece hacia ABAJO. ¡Al revés que en mate! Es como leer: empiezas arriba a la izquierda y bajas.

El punto (150, 100) está a 150 píxeles a la derecha y 100 píxeles hacia abajo desde la esquina superior izquierda. Grábatelo: más Y = más abajo. Te va a salvar mil veces. 🧠

Y una cosa más: el pincel pinta en orden, como calcomanías. Lo que dibujes después queda encima de lo que dibujaste antes. Por eso los juegos pintan primero el fondo y al final al personaje. 🎨

👀 MÍRALO FUNCIONAR

Aquí está un canvas con las 3 herramientas en acción. Presiona ▶ Ejecutar y luego juega: cambia números, cambia colores, rompe cosas (romper es aprender 😏). Por ejemplo: ¿qué pasa si al círculo le pones y = 50? ¿Sube o baja?

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { background: #14142e; text-align: center; }
    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; margin-top: 10px; }
  </style>
</head>
<body>
  <canvas id="lienzo" width="400" height="300"></canvas>

  <script>
    // 1) Agarrar el lienzo y los pinceles
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // 2) Un rectángulo cian: fillRect(x, y, ancho, alto)
    ctx.fillStyle = "#00e5ff";
    ctx.fillRect(40, 40, 120, 80);

    // 3) Otro rosa, MÁS ABAJO (más y = más abajo, ¿recuerdas?)
    ctx.fillStyle = "#ff4dd8";
    ctx.fillRect(40, 160, 120, 80);

    // 4) Un círculo amarillo: arc(x, y, radio, 0, Math.PI * 2)
    //    Math.PI * 2 = "dale la vuelta completa"
    ctx.beginPath();
    ctx.arc(290, 100, 50, 0, Math.PI * 2);
    ctx.fillStyle = "#ffe95c";
    ctx.fill();

    // 5) Un cuadrito encima del círculo: lo de después queda ENCIMA 🎨
    ctx.fillStyle = "#0a0a1a";
    ctx.fillRect(270, 80, 15, 15);
    ctx.fillRect(305, 80, 15, 15);

    // 6) Hasta puedes escribir texto
    ctx.fillStyle = "#39ff8e";
    ctx.font = "20px monospace";
    ctx.fillText("¡Hola, canvas!", 220, 200);
  </script>
</body>
</html>

🔍 Fíjate: el círculo con ojitos quedó porque el orden importa — primero el círculo amarillo, luego los cuadritos oscuros encima.

✏️ TU TURNO: TU PERSONAJE PIXELADO

Vas a dibujar una carita de creeper 🟩 (o el personaje pixelado que tú quieras) usando puros rectángulos. Ya te dejé la cara verde lista; tú completa los ojos y la boca. Guíate con las coordenadas del comentario: la cara va de (120, 60) a (280, 220).

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { background: #14142e; text-align: center; }
    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; margin-top: 10px; }
  </style>
</head>
<body>
  <canvas id="lienzo" width="400" height="280"></canvas>

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // La cara: un cuadrado verde de 160x160 que empieza en (120, 60)
    ctx.fillStyle = "#39ff8e";
    ctx.fillRect(120, 60, 160, 160);

    // TODO 1: los ojos 👀 — dos cuadrados oscuros (color "#0a0a1a")
    //         de 40x40. Sugerencia: uno en (140, 100) y otro en (220, 100).

    // TODO 2: la boca 😮 — el creeper tiene una boca en forma de "n" al revés:
    //         un rectángulo de 40x60 en (180, 140)
    //         + uno de 20x40 en (160, 160)
    //         + uno de 20x40 en (220, 160).

    // TODO 3 (toque final): dale tu firma con ctx.fillText() donde tú quieras.
  </script>
</body>
</html>
PISTA 1 Cada rectángulo son 2 líneas: primero el color con ctx.fillStyle = "#0a0a1a"; y luego ctx.fillRect(x, y, ancho, alto);. Como los dos ojos son del mismo color, ¡puedes poner el color una sola vez y pintar los dos!
PISTA 2 El primer ojo es ctx.fillRect(140, 100, 40, 40);. El segundo es igual pero empieza en x = 220. La boca son 3 rectángulos con las medidas exactas que dice el TODO 2 — cópialas tal cual y luego ajusta a tu gusto.
SOLUCIÓN EXPLICADA 
// Los ojos: mismo color, dos rectángulos
ctx.fillStyle = "#0a0a1a";
ctx.fillRect(140, 100, 40, 40);   // ojo izquierdo
ctx.fillRect(220, 100, 40, 40);   // ojo derecho

// La boca: 3 piezas que juntas forman la "n" invertida
ctx.fillRect(180, 140, 40, 60);   // centro (más alto)
ctx.fillRect(160, 160, 20, 40);   // pata izquierda
ctx.fillRect(220, 160, 20, 40);   // pata derecha

// La firma
ctx.fillStyle = "#ffe95c";
ctx.font = "16px monospace";
ctx.fillText("hecho por mí 😎", 130, 255);
Fíjate cómo TODO son coordenadas: los ojos están a la misma altura (y = 100) pero en distinta columna (x = 140 y x = 220). Los personajes pixelados son puro Batalla Naval. 🚢

❓ MINI-QUIZ

1. En un canvas, ¿dónde está el punto (0, 0)?

El origen está arriba a la izquierda, y la Y crece hacia ABAJO. Es al revés que en la clase de mate, pero igual que leer un libro: empiezas arriba y vas bajando. 📖

2. ¿Qué dibuja ctx.fillRect(50, 80, 100, 30)?

El orden es fillRect(x, y, ancho, alto): los primeros dos números dicen DÓNDE empieza (su esquina superior izquierda) y los otros dos CUÁNTO mide. 📐

3. Si dibujas un círculo amarillo y DESPUÉS un cuadrado rojo encima, ¿qué se ve?

El canvas pinta como calcomanías: en orden. Por eso los juegos dibujan primero el fondo y al final al personaje. 🎨
