NIVEL 8 · LECCIÓN 5 · 👑 JEFE

Jefe: Snake completo 👑🐍

🎯 EL JEFE DE ESTE NIVEL

Convertir tu serpiente viva en un JUEGO completo: morir al chocar con la pared o contigo mismo 💀, puntaje 🍎, velocidad que aumenta con cada manzana 🚀, pantalla de GAME OVER con tecla para reiniciar 🔄… y un RÉCORD que sobrevive gracias a localStorage (¡nivel 7 en acción! 💾). Al vencer a este jefe, habrás programado el mismo juego que venía en millones de celulares. De cero. Tú solo. 😤

🧠 EL PLAN DE BATALLA

¿Qué le falta a la serpiente de la lección pasada para ser un juego de verdad? Una sola cosa: que puedas perder.

Un videojuego sin game over es como jugar a las escondidas sin que nadie la traiga 🙈: técnicamente funciona, pero no emociona. El peligro (chocar 💀) más el premio (tu récord 🏆) son los que convierten tu demo en JUEGO. Hoy le metemos los dos.

Cada paso de la serpiente ahora pasa por una aduana de dos preguntas ANTES de avanzar:

La aduana de cada paso: si la cabeza nueva se sale del tablero 🧱 o cae en una celda del propio cuerpo 🐍 → gameOver(). Si no, la vida sigue: avanza, y si hay manzana, punto y crecimiento. 🍎

Tus 5 misiones de jefe, una por una:

  1. 💀 Muerte por pared: adiós modo fantasma. Si cabeza.x < 0 || cabeza.x >= COLUMNAS || cabeza.y < 0 || cabeza.y >= FILAS → gameOver().
  2. 💀 Muerte por mordida: recorre el arreglo con un for comparando cada segmento con la cabeza nueva. ¿Misma x Y misma y que alguno? Te mordiste. 🐍
  3. 🍎 Puntaje: una variable puntos que sube con cada manzana y se muestra en la página.
  4. 🚀 Velocidad: cada manzana resta milisegundos al ritmo. Truco: setInterval no se puede "editar" en caliente — se apaga con clearInterval(temporizador) y se enciende otro más rápido.
  5. 💾 Récord: puro nivel 7 — al morir, si puntos > record, guárdalo con localStorage.setItem("snake-record", ...). Al abrir el juego, léelo con getItem (ojo: te lo da como TEXTO, conviértelo con parseInt).

Y el toque final: la pantalla de GAME OVER es solo un rectángulo medio transparente encima del juego + textos con fillText. La tecla R llama a iniciar(), que regresa todo a su estado inicial. Fin del plan. A pelear. ⚔️

🔍 Tres retoques que verás en el código respecto a la lección 4: la función actualizar() ahora se llama paso() (es un paso de la serpiente, y al final ella misma llama a dibujar()); las flechas ya no cambian direccion al instante, sino que dejan su pedido en proximaDireccion y paso() lo aplica — si no, dos flechas muy rápidas (⬆️ y luego ⬅️) te darían la vuelta sobre tu propio cuello antes de avanzar, y ahora eso mata 💀; y la serpiente espera quieta a que pulses la primera flecha, para que no te estrelles antes de estar listo.

    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; }

<body>

  <canvas id="lienzo" width="400" height="400"></canvas>
  <p>🖱️ Haz clic aquí adentro · flechas para manejar · R para reiniciar</p>

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");
    var marcador = document.getElementById("marcador");

    var CELDA = 20;
    var COLUMNAS = canvas.width / CELDA;
    var FILAS = canvas.height / CELDA;

    var serpiente, direccion, proximaDireccion, manzana;
    var puntos, velocidad, vivo, enMarcha, temporizador;

    // 💾 MISIÓN 5: el récord vive en localStorage (¡nivel 7 aplicado!)
    // getItem devuelve TEXTO (o null la primera vez) → parseInt lo vuelve número
    var record = parseInt(localStorage.getItem("snake-record") || "0", 10);

    function iniciar() {
      serpiente = [ { x: 10, y: 10 }, { x: 9, y: 10 }, { x: 8, y: 10 } ];
      direccion = { x: 1, y: 0 };        // hacia dónde va AHORA
      proximaDireccion = direccion;      // hacia dónde irá en el SIGUIENTE paso
      puntos = 0;
      velocidad = 150;              // ms entre pasos: menos = más rápido
      vivo = true;
      enMarcha = false;             // quieta hasta que pulses una flecha 🕹️
      nuevaManzana();
      clearInterval(temporizador);  // apaga el reloj anterior (si había)
      pintarMarcador();
      dibujar();
    }

    // 🍎 Manzana educada: sortea celdas hasta que caiga en una LIBRE
    // (si naciera debajo de la serpiente, ni la verías)
    function nuevaManzana() {
      var ocupada = true;
      while (ocupada) {
        manzana = {
          x: Math.floor(Math.random() * COLUMNAS),
          y: Math.floor(Math.random() * FILAS)
        };
        ocupada = false;
        for (var i = 0; i < serpiente.length; i++) {
          if (serpiente[i].x === manzana.x && serpiente[i].y === manzana.y) {
            ocupada = true;   // cayó sobre la serpiente: otra vuelta al while
          }
        }
      }
    }

    document.addEventListener("keydown", function (evento) {
      // Las flechas ya no cambian "direccion" al instante: dejan un PEDIDO en
      // proximaDireccion, y paso() lo aplica cuando le toca. Así, dos flechas
      // rapidísimas ya no pueden darte la vuelta sobre tu propio cuello.
      if (evento.key === "ArrowUp"    && direccion.y !== 1)  proximaDireccion = { x: 0, y: -1 };
      if (evento.key === "ArrowDown"  && direccion.y !== -1) proximaDireccion = { x: 0, y: 1 };
      if (evento.key === "ArrowLeft"  && direccion.x !== 1)  proximaDireccion = { x: -1, y: 0 };
      if (evento.key === "ArrowRight" && direccion.x !== -1) proximaDireccion = { x: 1, y: 0 };

      if (evento.key === "ArrowUp" || evento.key === "ArrowDown" ||
          evento.key === "ArrowLeft" || evento.key === "ArrowRight") {
        evento.preventDefault();       // solo las flechas: que no muevan la página
        if (vivo && !enMarcha) {       // ¡la primera flecha arranca el reloj! ⏱️
          enMarcha = true;
          temporizador = setInterval(paso, velocidad);
        }
      }

      if (!vivo && (evento.key === "r" || evento.key === "R")) iniciar();  // 🔄
    });

    function paso() {
      if (!vivo) return;   // muerta no camina 💀

      direccion = proximaDireccion;   // ahora sí: aplica el giro que pediste

      var cabeza = {
        x: serpiente[0].x + direccion.x,
        y: serpiente[0].y + direccion.y
      };

      // 💀 MISIÓN 1: ¿chocó con la pared?
      if (cabeza.x < 0 || cabeza.x >= COLUMNAS ||
          cabeza.y < 0 || cabeza.y >= FILAS) {
        return gameOver();
      }

      // ¿En este paso come? Lo anotamos en una variable (true o false)
      var comio = (cabeza.x === manzana.x && cabeza.y === manzana.y);

      // Si NO comió, sale la cola (si comió, se queda: así crece 🐍).
      // Va ANTES de revisar la mordida: la celda que la cola deja libre
      // sí se puede pisar (perseguir tu propia cola es legal 😉)
      if (!comio) {
        serpiente.pop();
      }

      // 💀 MISIÓN 2: ¿se mordió? (compara la cabeza con CADA segmento)
      for (var i = 0; i < serpiente.length; i++) {
        if (serpiente[i].x === cabeza.x && serpiente[i].y === cabeza.y) {
          return gameOver();
        }
      }

      serpiente.unshift(cabeza);

      if (comio) {
        puntos = puntos + 1;               // 🍎 MISIÓN 3: ¡punto!
        nuevaManzana();
        if (velocidad > 60) {              // 🚀 MISIÓN 4: acelerar
          velocidad = velocidad - 5;
          clearInterval(temporizador);     // reloj viejo fuera…
          temporizador = setInterval(paso, velocidad);  // …reloj más rápido dentro
        }
        pintarMarcador();
      }

      dibujar();
    }

    function gameOver() {
      vivo = false;

      // 💾 MISIÓN 5: ¿nuevo récord? ¡Al cajón del navegador!
      if (puntos > record) {
        record = puntos;
        localStorage.setItem("snake-record", String(record));
      }
      pintarMarcador();
      dibujar();

      // La pantalla de la derrota: una cortina oscura + letrero
      ctx.fillStyle = "rgba(10, 10, 26, 0.78)";
      ctx.fillRect(0, 0, canvas.width, canvas.height);
      ctx.textAlign = "center";
      ctx.fillStyle = "#ff5c7a";
      ctx.font = "bold 36px monospace";
      ctx.fillText("GAME OVER", canvas.width / 2, 175);
      ctx.fillStyle = "#eaeaf5";
      ctx.font = "17px monospace";
      ctx.fillText("🍎 " + puntos + "   🏆 récord: " + record, canvas.width / 2, 215);
      ctx.fillText("presiona R para reintentar", canvas.width / 2, 245);
      ctx.textAlign = "left";   // regresar el pincel a la normalidad
    }

    function pintarMarcador() {
      marcador.textContent = "🍎 " + puntos + "  ·  🏆 Récord: " + record;
    }

    function dibujar() {
      ctx.fillStyle = "#0d0d22";
      ctx.fillRect(0, 0, canvas.width, canvas.height);

      ctx.fillStyle = "#ff5c7a";
      ctx.fillRect(manzana.x * CELDA, manzana.y * CELDA, CELDA - 1, CELDA - 1);

      for (var i = 0; i < serpiente.length; i++) {
        ctx.fillStyle = (i === 0) ? "#ffe95c" : "#39ff8e";
        ctx.fillRect(serpiente[i].x * CELDA, serpiente[i].y * CELDA, CELDA - 1, CELDA - 1);
      }

      // Antes de la primera flecha: un letrero de espera
      if (vivo && !enMarcha) {
        ctx.textAlign = "center";
        ctx.fillStyle = "#eaeaf5";
        ctx.font = "17px monospace";
        ctx.fillText("pulsa una flecha para empezar", canvas.width / 2, 150);
        ctx.textAlign = "left";
      }
    }

    iniciar();   // deja todo listo… y espera tu primera flecha
  </script>
</body>
</html>

PISTA 1 Misión 1: las 4 condiciones de pared van en UN solo if unidas con || ("o"): salirse por CUALQUIER lado mata. El return antes de gameOver() es importante: corta el paso ahí mismo, para que una serpiente muerta no siga avanzando.
PISTA 2 Misión 2: es el mismo patrón de "buscar en un arreglo" que usaste en la tabla de récords del nivel 7: for (var i = 0; i < serpiente.length; i++) y adentro un if que compara serpiente[i].x === cabeza.x && serpiente[i].y === cabeza.y. Misión 5: son 2 líneas dentro de un if (puntos > record) — mira cómo se LEE el récord arriba y haz el viaje de regreso con setItem.
SOLUCIÓN EXPLICADA 
// MISIÓN 1 💀: pared = muerte (borra los 4 if del modo fantasma)
if (cabeza.x < 0 || cabeza.x >= COLUMNAS ||
    cabeza.y < 0 || cabeza.y >= FILAS) {
  return gameOver();
}

// MISIÓN 2 💀: ¿la cabeza nueva cae sobre el cuerpo?
for (var i = 0; i < serpiente.length; i++) {
  if (serpiente[i].x === cabeza.x && serpiente[i].y === cabeza.y) {
    return gameOver();
  }
}

// MISIÓN 5 💾 (dentro de gameOver):
if (puntos > record) {
  record = puntos;
  localStorage.setItem("snake-record", String(record));

Detalles finos: la muerte se revisa con la cabeza nueva ANTES del unshift — preguntamos "¿PUEDO pisar esa celda?" antes de pisarla. El for de la mordida compara contra TODO el cuerpo que queda (la cola ya salió con el pop de arriba, por eso su celda sí se puede pisar); con que UN segmento coincida en x y en y, adiós 💀. Y el récord es el mismo viaje del nivel 7: getItem al nacer (texto → parseInt), setItem al morir con gloria. Por eso tu récord sigue ahí mañana. 🏆

❓ MINI-QUIZ

1. ¿Cómo sabe el juego que la serpiente se mordió a sí misma?

Nada de magia: es una búsqueda en un arreglo, como buscar una ficha en la tabla de récords del nivel 7. Coincidencia exacta de celda = mordida. 🐍💥

2. ¿Por qué para acelerar el juego hacemos clearInterval y luego otro setInterval?

El intervalo es como un metrónomo de cuerda: no le puedes cambiar la velocidad andando. Se detiene (clearInterval) y se arranca otro con menos milisegundos. 🚀

3. ¿Por qué el récord sigue ahí aunque cierres el navegador?

Las variables mueren con la pestaña; localStorage es el cajón permanente del navegador (nivel 7 💾). setItem al morir, getItem + parseInt al nacer, y tu gloria es eterna. 🏆
