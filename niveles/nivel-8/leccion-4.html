NIVEL 8 · LECCIÓN 4

Snake I: la serpiente viva 🐍

🎯 HOY VAS A LOGRAR…

Construir el corazón de Snake: un campo en cuadrícula, una serpiente que es un arreglo de segmentos, movimiento con unshift + pop, control con flechas (sin reversazos 🚫), y una manzana 🍎 que la hace crecer. Hoy la serpiente cobra vida; en la próxima lección, el juego completo.

🧠 EL CONCEPTO

Idea 1: piensa en CELDAS, no en píxeles. Snake no se mueve suavecito: salta de casilla en casilla, como en un tablero. Así que dividimos el lienzo en celdas de 20 píxeles (var CELDA = 20;): un canvas de 400x400 se convierte en un tablero de 20 columnas por 20 filas. Desde ahora, la posición de la serpiente es su CELDA — la celda (5, 3) — y solo al dibujar la convertimos a píxeles multiplicando: x * CELDA = 100. Comparar celdas es exacto y facilito: ¿la cabeza está en la misma celda que la manzana? === y ya. 🎯

Idea 2: la serpiente es un ARREGLO de segmentos. ¿Recuerdas los objetos del nivel 7? Cada pedacito de serpiente es una ficha { x: 10, y: 10 }, y la serpiente completa es un arreglo de fichas donde serpiente[0] es la CABEZA.

La serpiente avanza como una fila de conga 💃🕺: para "moverse", alguien nuevo se forma ADELANTE (la cabeza nueva: unshift) y el del FINAL se sale de la fila (la cola: pop). Nadie más se mueve, pero la fila completa avanzó un paso. Y si hay pastel 🍰 (una manzana), el del final NO se sale ese turno… y la fila crece.

Un paso de Snake = unshift mete una cabeza nueva al inicio del arreglo y pop quita la cola del final. Si comió 🍎, ese turno NO hay pop… y la serpiente mide un segmento más. 💃

Idea 3: la dirección también es una ficha. var direccion = { x: 1, y: 0 }; significa "una celda a la derecha por paso". La cabeza nueva siempre nace en serpiente[0].x + direccion.x. Con las flechas cambias la dirección… con UNA regla sagrada: prohibida la reversa instantánea 🚫. Si vas a la derecha y presionas izquierda, chocarías con tu propio cuello. Por eso cada if revisa la dirección actual antes de aceptar.

Idea 4: el ritmo con setInterval. A 60 cuadros por segundo, Snake sería injugable 😵. Aquí conviene más setInterval(paso, 150): "ejecuta paso cada 150 milisegundos". Fácil de razonar (un paso = un salto de celda) y fácil de acelerar después: menos milisegundos = más difícil. 😏

👀 MÍRALO FUNCIONAR: LA SERPIENTE RESPIRA

Snake parcial pero VIVO: se mueve, obedece tus flechas, come y crece. Todavía no puede morir (por ahora atraviesa las paredes como fantasma 👻 — el game over llega en la próxima lección). Presiona ▶ Ejecutar y…

🖱️ Haz clic dentro de la vista previa primero, para que escuche tu teclado. Luego maneja con ⬆️⬇️⬅️➡️ y ve por la manzana:

<!DOCTYPE html>
<html>
<head>
  <meta charset="UTF-8">
  <style>
    body { background: #14142e; text-align: center; color: #a3a3c8; font-family: sans-serif; }
    canvas { background: #0d0d22; border: 3px solid #39ff8e; border-radius: 8px; margin-top: 8px; }
  </style>
</head>
<body>
  <p>🖱️ Haz clic aquí adentro y maneja con las flechas ⬆️⬇️⬅️➡️</p>
  <canvas id="lienzo" width="400" height="400"></canvas>

  <script>
    var canvas = document.getElementById("lienzo");
    var ctx = canvas.getContext("2d");

    // El tablero: celdas de 20 px → 20 columnas x 20 filas
    var CELDA = 20;
    var COLUMNAS = canvas.width / CELDA;   // 20
    var FILAS = canvas.height / CELDA;     // 20

    // La serpiente: arreglo de fichas {x, y} EN CELDAS. [0] es la cabeza.
    var serpiente = [
      { x: 10, y: 10 },
      { x: 9,  y: 10 },
      { x: 8,  y: 10 }
    ];
    var direccion = { x: 1, y: 0 };        // arranca hacia la derecha
    var manzana = { x: 15, y: 10 };

    // Control 🎮 (con la regla sagrada: nada de reversa instantánea 🚫)
    document.addEventListener("keydown", function (evento) {
      if (evento.key === "ArrowUp"    && direccion.y !== 1)  direccion = { x: 0, y: -1 };
      if (evento.key === "ArrowDown"  && direccion.y !== -1) direccion = { x: 0, y: 1 };
      if (evento.key === "ArrowLeft"  && direccion.x !== 1)  direccion = { x: -1, y: 0 };
      if (evento.key === "ArrowRight" && direccion.x !== -1) direccion = { x: 1, y: 0 };
      evento.preventDefault();
    });

    // Una manzana nueva en una celda al azar 🍎
    function nuevaManzana() {
      manzana = {
        x: Math.floor(Math.random() * COLUMNAS),
        y: Math.floor(Math.random() * FILAS)
      };
    }

    function actualizar() {
      // 1) ¿Dónde nace la cabeza nueva? Una celda en la dirección actual
      var cabeza = {
        x: serpiente[0].x + direccion.x,
        y: serpiente[0].y + direccion.y
      };

      // Por ahora: modo fantasma 👻, atraviesa las paredes
      // (en la próxima lección esto se convierte en GAME OVER 💀)
      if (cabeza.x < 0) cabeza.x = COLUMNAS - 1;
      if (cabeza.x >= COLUMNAS) cabeza.x = 0;
      if (cabeza.y < 0) cabeza.y = FILAS - 1;
      if (cabeza.y >= FILAS) cabeza.y = 0;

      // 2) La cabeza nueva entra al inicio del arreglo (la conga se forma 💃)
      serpiente.unshift(cabeza);

      // 3) ¿La cabeza cayó en la manzana?
      if (cabeza.x === manzana.x && cabeza.y === manzana.y) {
        nuevaManzana();       // comió: manzana nueva y NO quitamos cola → crece 🐍
      } else {
        serpiente.pop();      // no comió: sale la cola y mide lo mismo
      }
    }

    function dibujar() {
      // Borrar todo
      ctx.fillStyle = "#0d0d22";
      ctx.fillRect(0, 0, canvas.width, canvas.height);

      // La manzana (celda → píxeles: multiplicar por CELDA)
      ctx.fillStyle = "#ff5c7a";
      ctx.fillRect(manzana.x * CELDA, manzana.y * CELDA, CELDA - 1, CELDA - 1);

      // La serpiente, segmento por segmento (cabeza amarilla)
      for (var i = 0; i < serpiente.length; i++) {
        ctx.fillStyle = (i === 0) ? "#ffe95c" : "#39ff8e";
        ctx.fillRect(serpiente[i].x * CELDA, serpiente[i].y * CELDA, CELDA - 1, CELDA - 1);
      }
    }

    // El ritmo del juego: un paso cada 150 milisegundos ⏱️
    setInterval(function () {
      actualizar();
      dibujar();
    }, 150);
  </script>
</body>
</html>

🔍 Fíjate en el CELDA - 1 al dibujar: ese píxel de separación hace que se noten los segmentos, como cuentas de un collar. Y prueba: come 5 manzanas y observa cómo la fila crece.

✏️ TU TURNO: DALE VIDA A TU PROPIA SERPIENTE

Esta serpiente está a medias: solo sabe girar hacia arriba y abajo 😬, y pasa sobre la manzana como si no existiera. Completa los TODO para que quede como la del ejemplo. Recuerda: 🖱️ haz clic dentro de la vista previa primero, para que escuche tu teclado.

PISTA 1 Los dos if que faltan son gemelos de los que ya están, pero horizontales: cambian direccion a { x: -1, y: 0 } (izquierda) o { x: 1, y: 0 } (derecha), y su guardia anti-reversa revisa direccion.x en lugar de direccion.y.
PISTA 2 Para el TODO 2 necesitas un if / else: si la cabeza está en la celda de la manzana → nuevaManzana(); (y NADA más); else → serpiente.pop();. Ojo: borra el serpiente.pop(); suelto que está abajo del comentario, o tu serpiente jamás crecerá.
SOLUCIÓN EXPLICADA 
// TODO 1: las direcciones horizontales, con guardia anti-reversa 🚫
if (evento.key === "ArrowLeft"  && direccion.x !== 1)  direccion = { x: -1, y: 0 };
if (evento.key === "ArrowRight" && direccion.x !== -1) direccion = { x: 1, y: 0 };

// TODO 2: comer o avanzar (dentro de actualizar, después del unshift)
if (cabeza.x === manzana.x && cabeza.y === manzana.y) {
  nuevaManzana();      // comió 🍎: no hay pop → crece un segmento
} else {
  serpiente.pop();     // no comió: la cola sale y mide igual
}
La guardia direccion.x !== 1 significa: "acepta ir a la izquierda SOLO si no vas ya a la derecha". Sin ella, un reversazo te haría chocar con tu propio cuello (en la próxima lección, eso mata 💀). Y el crecimiento es pura elegancia: crecer NO es agregar un segmento extra… es simplemente no quitar la cola ese turno. La cabeza nueva ya lo agregó. 🤯

🚑 ¿ATORADO? ASÍ TE DESATORAS

  1. ¿No responde el teclado? Clic dentro de la vista previa primero. 🖱️
  2. ¿La serpiente crece sin parar? Se te quedó un pop() fuera del else… o no hay ningún pop(). Debe salir cola en TODOS los pasos excepto cuando come.
  3. ¿No crece nunca? Entonces el pop() se ejecuta siempre: revisa que esté en la rama else.
  4. Vuelve al diagrama de la conga 💃 y repasa: unshift adelante, pop atrás.

❓ MINI-QUIZ

1. La serpiente está en la celda (5, 3) y CELDA = 20. ¿En qué píxel se dibuja?

La lógica del juego vive en celdas y SOLO al dibujar se multiplica: x * CELDA. Así comparar posiciones (¿cabeza === manzana?) es exacto, sin decimales ni "casi toca". 🎯

2. ¿Cómo avanza la serpiente en cada paso?

La conga 💃: nadie "camina", solo se forma uno adelante y se sale el del final. Por eso la serpiente puede dar vueltas: cada segmento se queda quieto donde nació.

3. ¿Qué hace crecer a la serpiente cuando come una manzana?

Crecer = saltarse el pop() un turno. El unshift de siempre agrega la cabeza, la cola se queda… y el arreglo mide uno más. Elegancia pura. ✨
