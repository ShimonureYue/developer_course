🧠 EL PLAN DE BATALLA

Este jefe no te pide nada nuevo: te pide criterio de diseñador. Los diseñadores de verdad no eligen colores al azar: eligen una paleta (un equipo de 4-5 colores que combinan) y la usan en TODA la página. Eso es lo que hace que un diseño se vea profesional y no como piñata. 🪅

Darle un tema a tu página es como elegir la skin de tu personaje 🎮: el personaje (tu HTML) es el mismo, pero la skin (tu CSS) lo transforma por completo. Hoy tu tarjeta se gana su skin legendaria.

El MISMO HTML de tu tarjeta, antes y después del CSS. Ni una etiqueta cambió: todo el poder está en el <style>. 🪄

La estrategia del jefe, en 4 movimientos: 1️⃣ pinta el body (fondo + letra), 2️⃣ convierte tu contenido en UNA tarjeta (una caja .tarjeta con padding, borde, esquinas y sombra), 3️⃣ pinta títulos y textos con tu paleta, 4️⃣ agrega la magia (:hover + transition). Aquí está una tarjeta de gamer con su HTML listo (¡cámbialo por TUS datos — o pega tu tarjeta del Nivel 1!) y un <style> con los 4 movimientos como TODOs. Elige tu paleta de la tabla de arriba y ¡a vestir a tu campeón! ⚔️

PISTA 1 Movimiento por movimiento, ejecutando cada vez. El TODO 1 son 3 prendas para el body: background-color: …;, color: …; y font-family: Arial;. Copia los códigos hex de tu paleta TAL CUAL, con todo y #.
PISTA 2 La tarjeta es puro repaso de la Lección 2: .tarjeta { padding: 24px; border: 3px solid #00e5ff; border-radius: 18px; box-shadow: 0 0 30px #00e5ff; max-width: 420px; margin: 30px auto; } (con TU color de acento). Y recuerda: .avatar:hover se escribe pegadito, sin espacios.
SOLUCIÓN EXPLICADA (tema retro neón) 
/* 1️⃣ el escenario */
body {
  background-color: #0a0a1a;   /* fondo de mi paleta */
  color: #eaeaf5;              /* color de texto */
  font-family: Arial;
}

/* 2️⃣ la tarjeta (modelo de caja completo) */
.tarjeta {
  background-color: #12081f;
  padding: 24px;               /* aire adentro */
  border: 3px solid #00e5ff;   /* acento */
  border-radius: 18px;         /* esquinas suaves */
  box-shadow: 0 0 30px #00e5ff;/* resplandor neón */
  max-width: 420px;
  margin: 30px auto;           /* auto = centrada ↔ */
}

/* 3️⃣ la paleta en los textos */
h1 { color: #ff4dd8; }
h2 { color: #00e5ff; }
a  { color: #00e5ff; }

/* 4️⃣ la magia */
.avatar {
  display: flex;
  justify-content: center;     /* avatar al centro */
  font-size: 80px;
  transition: all 0.4s;        /* cambios suavecitos */
}
.avatar:hover { transform: scale(1.2); }  /* ¡crece al tocarlo! */
Si tu tarjeta tiene fondo con tema, caja con resplandor, textos con paleta y un avatar que reacciona… el jefe cayó y tu tarjeta tiene skin legendaria. 👑🎨 Cambia el HTML por tus datos reales y presúmela.

❓ MINI-QUIZ

1. ¿Por qué los diseñadores eligen una PALETA en vez de usar 20 colores al azar?

Pocos colores + bien repetidos = identidad visual. Muchos colores al azar = piñata 🪅. Por eso las marcas famosas se reconocen solo por sus colores.

2. ¿Qué hace margin: 30px auto; en tu .tarjeta?

auto en los lados dice "repártanse el espacio sobrante mitad y mitad" → la caja queda centrada. Es el hermano del truco flexbox para centrar. 🎯

3. Tu .avatar:hover no funciona. ¿Cuál es el error más probable?

El 90% de los "no funciona" en CSS son de dedo 🖐️: .avatar :hover (espacio de más), class="Avatar" (mayúscula distinta) o una } olvidada que rompe todo lo que sigue. Revisa con calma, línea por línea.
