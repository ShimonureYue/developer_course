NIVEL 2 · LECCIÓN 1

¿Qué es CSS? 🎨✨

🎯 HOY VAS A LOGRAR…

Escribir tus primeras reglas de CSS: entender la receta selector { propiedad: valor; }, ponerla dentro de <style>, y cambiar colores, fondos y tamaños de letra — incluso con códigos secretos hexadecimales como #ff4dd8. 🕵️

🧠 EL CONCEPTO

Tus páginas del Nivel 1 funcionan… pero se ven en blanco y negro, con la letra de siempre. Eso es porque HTML solo dice QUÉ hay en la página (un título, un párrafo, una lista), pero no dice CÓMO se ve. Para eso existe CSS: el lenguaje de los estilos.

HTML es el esqueleto 🦴 y CSS es la ropa 👕. El esqueleto pone la estructura: cabeza, brazos, piernas. La ropa decide el estilo: ¿jersey de fútbol, sudadera negra o traje de luchador con capa? La MISMA página HTML puede verse totalmente diferente con solo cambiarle el CSS.

Y las "prendas" se reparten con una receta de 3 partes que vas a escribir mil veces en tu vida. Apréndetela como si fuera un paso de baile:

h1 {                    ← SELECTOR: "¿a quién le pongo la ropa?" (a todos los h1)
  color: hotpink;       ← PROPIEDAD: valor;  → "¿qué prenda? ¿de qué tipo?"
}                       ← llaves { } = la bolsa con la ropa
  • El selector apunta a las etiquetas que quieres vestir: h1, p, body (¡el body es la página entera!).
  • Cada propiedad es un tipo de prenda: color (color del texto), background-color (color del fondo), font-size (tamaño de letra), font-family (tipo de letra).
  • Después de cada valor va un punto y coma ; — es la "puntada" que cierra cada prenda. Si lo olvidas, la que sigue no funciona. 🪡

El mismo <h1>, antes y después de que la regla h1 { color: #ff4dd8; } le pone la ropa. CSS busca a TODOS los que coincidan con el selector y los viste igualito.

¿Y dónde se escribe el CSS? Por ahora, en una etiqueta <style> dentro del <head> (el cerebro 🧠 de tu página, ¿te acuerdas?). Ahí adentro ya no escribes HTML: escribes puro CSS.

¿Y los colores? Hay dos formas de pedirlos:

  • Por nombre (en inglés): red, hotpink, gold, black… fácil pero limitado, como pedir "un refresco".
  • Por código hexadecimal 🕵️: un "código secreto" de 6 caracteres como #ff4dd8. Son 3 parejas: ff-4d-d8 = cuánto Rojo, cuánto Verde y cuánto Azul lleva la mezcla (RGB). 00 es nada y ff es el máximo. Así, #ff0000 = puro rojo, #000000 = negro (nada de nada) y #ffffff = blanco (todo al máximo). Con este código puedes pedir 16 millones de colores exactos — por eso lo usan los diseñadores pro.

✏️ TU TURNO

Te toca ser el estilista 💇: la página ya tiene su HTML listo, pero el <style> está vacío. Completa los 3 TODOs para vestirla.

PISTA 1 La receta siempre es la misma: selector { propiedad: valor; }. Para el TODO 1 el selector es body, la propiedad es background-color y el valor es #1a1a38. No olvides las llaves ni el punto y coma. 🪡
PISTA 2 Dentro de unas mismas llaves puedes poner VARIAS prendas, una por línea: h1 { color: #ffe95c; font-size: 42px; }. Cada una con su ; al final.
SOLUCIÓN EXPLICADA 
body {
  background-color: #1a1a38;   /* 1) fondo oscuro para TODA la página */
}

h1 {
  color: #ffe95c;              /* 2) título amarillo eléctrico… */
  font-size: 42px;             /*    …y más grande */
}

p {
  color: hotpink;              /* 3) TODOS los párrafos se pintan a la vez */
}
Fíjate en el superpoder 🦸: escribiste UNA regla para p y se vistieron LOS DOS párrafos. Con CSS vistes a todo un ejército con una sola orden.

❓ MINI-QUIZ

1. En la regla p { color: gold; }, ¿qué es p?

La receta es selector { propiedad: valor; }: el selector elige a quién, la propiedad qué prenda (color) y el valor cuál (gold). 👕

2. ¿Dónde va la etiqueta <style> con tu CSS?

El head guarda la información que no se "ve" pero manda: el título de la pestaña y ahora también tus estilos. 🧠

3. El código secreto #ff0000 es…

Las 3 parejas son Rojo-G(verde)-B(azul): ff = máximo, 00 = nada. #ff0000 = pura luz roja. 🔴
