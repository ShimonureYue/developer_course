NIVEL 2 · LECCIÓN 2

El modelo de caja 📦🎂

🎯 HOY VAS A LOGRAR…

Descubrir el secreto #1 del diseño web: TODO en una página es una caja — y controlar sus 3 capas con padding, border y margin, más dos trucos de lujo: border-radius y box-shadow. ✨

🧠 EL CONCEPTO

Haz clic derecho en CUALQUIER página web y elige "Inspeccionar": vas a ver que cada título, cada foto, cada botón… es un rectángulo. La web entera son cajas dentro de cajas dentro de cajas. 🤯 Y toda caja tiene 3 capas alrededor de su contenido, que se entienden perfecto con una torta de cumpleaños:

Piensa en una torta en su caja de regalo 🎂: el contenido es la torta; el padding es el espacio de aire entre la torta y la caja (para que no se embarre el betún); el border es la caja/el papel de regalo que se ve por fuera; y el margin es el espacio personal ENTRE tu caja y las demás — como en el metro 🚇: nadie quiere ir pegado al de al lado.

Las 3 capas de TODA caja web, de adentro hacia afuera: padding (aire interno 💨), border (el papel visible 🎁) y margin (espacio personal 🚇). Grábatelo: es EL diagrama del diseño web.

En código, cada capa es una propiedad (los tamaños van en píxeles, px):

.tarjeta {
  padding: 20px;                 /* aire entre el texto y el borde */
  border: 4px solid #ff4dd8;     /* grosor + estilo + color del borde */
  margin: 30px;                  /* espacio personal hacia afuera */
  border-radius: 16px;           /* 🍬 esquinas redonditas */
  box-shadow: 0 0 20px #ff4dd8;  /* ✨ resplandor/sombra alrededor */
}
  • border: 4px solid #ff4dd8; pide 3 datos juntos: qué tan gruesa la línea, de qué tipo (solid = continua, dashed = punteada) y su color.
  • border-radius redondea esquinas: poquito (8px) = tarjeta elegante; mucho (50%) = ¡círculo completo!
  • box-shadow: 0 0 20px color; dibuja una sombra: los dos primeros números la mueven (derecha y abajo) y el tercero la difumina. Con 0 0 y un color neón… obtienes el famoso brillo de letrero 🌆.

Un detalle más: viste en la lección pasada selectores como h1 o p. Aquí aparece .tarjeta (con punto): es un selector de clase. Le pones class="tarjeta" a cualquier etiqueta HTML, y la regla .tarjeta { … } viste SOLO a las que traigan ese gafete. Así puedes vestir diferente a dos <div> distintos. 🎫 (Un <div> es una caja genérica sin sabor: la usamos para agrupar cosas.)

👀 MÍRALO FUNCIONAR

Dos cajas con el MISMO texto: una "cruda" y una con las 3 capas + esquinas + resplandor. Ejecuta y luego experimenta: cambia el padding a 40px, el border-radius a 50px, el color de la sombra… ¡rompe todo, para eso está! 🔨

Cosas para notar 🔍: el padding empuja el borde hacia afuera del texto; el margin empuja a las otras cajas. Si el texto se ve apretado → falta padding. Si dos cajas se ven amontonadas → falta margin. Esa es la regla de oro. 🥇

✏️ TU TURNO

Aquí hay 3 "gafetes de jugador" amontonados y sin gracia. Rescátalos completando los TODOs del CSS: dale a .gafete sus 3 capas y sus trucos de lujo. 🛠️

PISTA 1 Recuerda la torta 🎂: de adentro hacia afuera es padding → border → margin. Cada línea es propiedad: valor;, por ejemplo: padding: 16px;. Ejecuta después de CADA una para ver qué cambia.
PISTA 2 El borde pide sus 3 datos juntos: border: 3px solid #00e5ff;. Y la sombra neón: box-shadow: 0 0 15px #00e5ff; (cero movida a los lados, cero abajo, 15px de difuminado, color cian).
SOLUCIÓN EXPLICADA 
.gafete {
  background-color: #1a1a38;
  padding: 16px;                 /* 1) aire: el texto ya no va pegado */
  border: 3px solid #00e5ff;     /* 2) papel de regalo cian */
  margin: 14px;                  /* 3) espacio personal entre gafetes */
  border-radius: 12px;           /* 4a) esquinas redonditas */
  box-shadow: 0 0 15px #00e5ff;  /* 4b) resplandor de letrero neón */
}
Una sola regla .gafete… ¡y los TRES gafetes se vistieron igual! Ese es el poder de las clases: un gafete, mil jugadores. 🎫✨

❓ MINI-QUIZ

1. El texto de tu tarjeta se ve PEGADO al borde. ¿Qué le falta?

Apretado por DENTRO = padding. Amontonado por FUERA con otras cajas = margin. La regla de oro del diseño. 🥇

2. ¿Qué hace border-radius: 50%; en una caja cuadrada?

Redondear las esquinas al 50% de una caja cuadrada la vuelve círculo: así se hacen los avatares de perfil de todas las apps. 📸

3. En border: 4px solid #ff4dd8;, ¿qué significa solid?

El borde pide 3 datos: grosor (4px), estilo de línea (solid continua, dashed punteada, dotted de puntitos) y color. 🎁
