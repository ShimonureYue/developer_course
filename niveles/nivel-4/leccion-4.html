🧠 EL CONCEPTO

¿Cómo se construye un juego "grande" sin volverse loco? Los profesionales tienen un truco milenario: divide y vencerás. Nadie programa "el juego": se programan piezas chiquitas (funciones) que hacen UNA cosa bien, y luego un ciclo principal las conecta.

Un juego grande es como una cocina de restaurante 🍽️: hay una receta para el guiso, otra para la salsa, otra para las tortillas… y un chef (tu ciclo while) que las va llamando en orden, plato tras plato, hasta que termina el servicio. Cada receta se puede probar y arreglar POR SEPARADO.

Tres piezas, cada una con UN trabajo, conectadas al ciclo principal. Si la pista sale mal, sabes EXACTO a qué máquina abrirle el cofre: a dar_pista. Eso es lo que te regalan las funciones: orden y lugares chiquitos donde buscar los bugs. 🔍

🎲 Herramienta nueva para el arsenal: random.randint

Ya conoces random.choice(lista), la tómbola que saca un elemento al azar. Su primo random.randint(1, 20) te da un número entero al azar entre 1 y 20 — y ojo, aquí el 20 SÍ entra (no como en range 😄). Perfecto para pensar números secretos.

import random

random.choice(["piedra", "papel", "tijera"])  # un elemento al azar 🎰
random.randint(1, 20)                         # un entero del 1 al 20 🎲

👀 MÍRALO FUNCIONAR: EL VOLADO 🪙

Antes de los dos jefes, un calentamiento: un volado construido con el patrón exacto que vas a usar — funciones arriba, juego abajo. Ejecútalo un par de veces y fíjate cómo cada función hace UNA sola cosa:

¿Ves la jugada? Las funciones retornan valores, y el juego los guarda y compara. Ese mismo esqueleto, con más piezas, es un juego completo. Ahora sí: 👑

✏️ JUEGO 1: ADIVINA EL NÚMERO 🎯

La consola piensa un número secreto del 1 al 20 y tú lo cazas con pistas de "más arriba / más abajo", mientras el juego cuenta tus intentos. El plan de batalla, pieza por pieza (así se comen los jefes: a mordidas 🍕):

  1. Pieza 1 — generar_secreto(): RETORNA random.randint(1, 20). La fábrica de secretos. 🎲
  2. Pieza 2 — pedir_intento(): RETORNA int(input(...)). La ventanilla de intentos. 🗣️
  3. Pieza 3 — dar_pista(intento, secreto): compara y RETORNA (¡no imprime!) "MÁS ARRIBA ⬆️", "MÁS ABAJO ⬇️" o "¡GANASTE! 🎉". El juez. ⚖️
  4. Pieza 4 — el ciclo principal: pide intentos y da pistas while intento != secreto, contando los intentos con un contador. 🔁
PISTA 1 Las piezas 1 y 2 son recetas de UNA línea, calcadas del volado: 
def generar_secreto():
    return random.randint(1, 20)

def pedir_intento():
    return int(input("Tu número (1-20): "))
El int(...) es clave: input te da TEXTO, y para comparar con < y > necesitas número.
PISTA 2 El juez es un if/elif/else con un return en cada camino: 
def dar_pista(intento, secreto):
    if intento < secreto:
        return "MÁS ARRIBA ⬆️"
    elif intento > secreto:
        return "MÁS ABAJO ⬇️"
    else:
        return "¡GANASTE! 🎉"
Y el ciclo es como el del oráculo 🔮: primer intento ANTES del while, siguiente intento ADENTRO (regla anti-ciclo-infinito), y el contador intentos = intentos + 1 en cada vuelta.
SOLUCIÓN COMPLETA EXPLICADA 
import random

def generar_secreto():                     # PIEZA 1: la fábrica 🎲
    return random.randint(1, 20)

def pedir_intento():                       # PIEZA 2: la ventanilla 🗣️
    return int(input("Tu número (1-20): "))

def dar_pista(intento, secreto):           # PIEZA 3: el juez ⚖️
    if intento < secreto:
        return "MÁS ARRIBA ⬆️"
    elif intento > secreto:
        return "MÁS ABAJO ⬇️"
    else:
        return "¡GANASTE! 🎉"

# PIEZA 4: el ciclo principal 🔁
print("🎮 ADIVINA EL NÚMERO (del 1 al 20) 🎮")
secreto = generar_secreto()
intento = pedir_intento()                  # primer intento, ANTES del ciclo
intentos = 1

while intento != secreto:                  # mientras no le atines...
    print(dar_pista(intento, secreto))     # el juez retorna, tú imprimes
    intento = pedir_intento()              # nuevo intento, ADENTRO
    intentos = intentos + 1                # el contador de la lección 5

print(dar_pista(intento, secreto))         # el "¡GANASTE! 🎉" final
print("Lo lograste en", intentos, "intentos 🏆")
Cópiala al editor y ¡a jugar! Fíjate en la línea print(dar_pista(intento, secreto)): como el juez RETORNA la pista, el ciclo decide qué hacer con ella. Con un print adentro del juez esto sería mucho menos flexible — por eso los pros retornan. 😎

✏️ JUEGO 2: PIEDRA, PAPEL O TIJERA ✂️

El clásico de los recreos, contra la computadora y al mejor de 3 (el primero que gane 2 rondas se lleva el duelo). Las piezas:

  1. Pieza 1 — jugada_computadora(): RETORNA random.choice(["piedra", "papel", "tijera"]). 🤖
  2. Pieza 2 — decidir_ganador(jugador, compu): RETORNA "empate", "jugador" o "compu". Recuerda las reglas: piedra rompe tijera, papel envuelve piedra, tijera corta papel. ⚖️
  3. Pieza 3 — el marcador: dos contadores (puntos_jugador, puntos_compu) y un while que sigue mientras NADIE llegue a 2. 🏆
PISTA 1 El juez se ve larguísimo pero es puro if + return. Y aquí un truco elegante: como return TERMINA la función, si ninguna condición de "jugador gana" se cumplió y no fue empate… lo único que queda es que ganó la compu: 
def decidir_ganador(jugador, compu):
    if jugador == compu:
        return "empate"
    if jugador == "piedra" and compu == "tijera":
        return "jugador"
    if jugador == "papel" and compu == "piedra":
        return "jugador"
    if jugador == "tijera" and compu == "papel":
        return "jugador"
    return "compu"        # si llegamos aquí, no ganaste 😅
PISTA 2 El duelo: la condición while puntos_jugador < 2 and puntos_compu < 2: significa "mientras NADIE haya llegado a 2". Adentro, después de obtener resultado, reparte el punto: 
if resultado == "jugador":
    puntos_jugador = puntos_jugador + 1
    print("¡Punto para ti! 🎉")
elif resultado == "compu":
    puntos_compu = puntos_compu + 1
    print("Punto para la compu 🤖")
else:
    print("Empate 😐")
Y al salir del ciclo, quien tenga más puntos es el campeón (un if/else final).
SOLUCIÓN COMPLETA EXPLICADA 
import random

def jugada_computadora():                  # PIEZA 1 🤖
    return random.choice(["piedra", "papel", "tijera"])

def decidir_ganador(jugador, compu):       # PIEZA 2 ⚖️
    if jugador == compu:
        return "empate"
    if jugador == "piedra" and compu == "tijera":
        return "jugador"
    if jugador == "papel" and compu == "piedra":
        return "jugador"
    if jugador == "tijera" and compu == "papel":
        return "jugador"
    return "compu"

# PIEZA 3: el duelo al mejor de 3 🏆
print("✂️ PIEDRA, PAPEL O TIJERA — al mejor de 3 ✂️")
puntos_jugador = 0
puntos_compu = 0

while puntos_jugador < 2 and puntos_compu < 2:
    jugador = input("piedra, papel o tijera: ")
    compu = jugada_computadora()
    print("La compu sacó:", compu)

    resultado = decidir_ganador(jugador, compu)

    if resultado == "jugador":
        puntos_jugador = puntos_jugador + 1
        print("¡Punto para ti! 🎉")
    elif resultado == "compu":
        puntos_compu = puntos_compu + 1
        print("Punto para la compu 🤖")
    else:
        print("Empate 😐")

    print("MARCADOR → tú:", puntos_jugador, "| compu:", puntos_compu)

if puntos_jugador > puntos_compu:
    print("👑 ¡CAMPEÓN! Ganaste el duelo")
else:
    print("🤖 La compu ganó esta vez... ¡revancha!")
Cópiala al editor, ejecútala y échate el duelo. 🎮 Y date cuenta de la joya: decidir_ganador RETORNA quién ganó, y el ciclo decide qué hacer con eso (sumar puntos, anunciar). El juez juzga, el chef cocina: cada pieza con su chamba. Acabas de programar como programan los profesionales. 👑

🚑 ¿ATORADO? ASÍ TE DESATORAS

  1. ¿ValueError: invalid literal for int()? Escribiste letras cuando el juego pedía un número: int("hola") no existe. Dale números al 🎯.
  2. ¿NameError con una de tus funciones? O la llamaste antes de definirla (los def van ARRIBA del ciclo principal) o el nombre no coincide letra por letra.
  3. ¿La compu "hace trampa" y siempre gana? Revisa el juez: los textos deben coincidir EXACTO — "piedra" en minúsculas, sin espacios. Escribe tu jugada igualito.
  4. ¿Página congelada? Ciclo infinito 😅: en el juego 1 te faltó pedir el intento ADENTRO del while; en el 2, sumar los puntos. ⌘R y a revisar.
  5. ¿Guardaste una pista y salió None? Tu juez tiene un print donde debía haber un return — el error clásico #1 de la lección 3. 🪟

❓ MINI-QUIZ

1. ¿Por qué conviene armar un juego con varias funciones chiquitas en vez de un solo bloque gigante de código?

Divide y vencerás 🍕: si la pista sale mal, abres SOLO dar_pista; si la compu juega raro, SOLO jugada_computadora. En un bloque gigante, el bug se esconde en cualquier parte.

2. dar_pista(intento, secreto) RETORNA la pista en vez de imprimirla. ¿Qué gana el juego con eso?

El juez entrega su veredicto 🤲 y el chef decide. Hoy lo imprimes; mañana podrías guardarlo en una lista de pistas o usarlo para dar puntos. Con un print adentro, la función decide por ti y adiós flexibilidad.

3. ¿Qué te da random.randint(1, 20)?

Es el primo de random.choice: randint da ENTEROS entre los dos números… y a diferencia de range(1, 20), aquí el 20 SÍ puede salir. 🎲
