🔄 Python ↔ JavaScript: el traductor

Ya sabes Python, así que JS es 80% traducción. Compara:

IdeaPython 🐍JavaScript ⚡
Mostrar algoprint("hola")console.log("hola");
Variablevidas = 3let vidas = 3;
ConstanteMAX = 5 (convención)const MAX = 5; (el lenguaje la protege)
Comentario# nota// nota
¿Es igual?=====
Verdadero / falsoTrue / Falsetrue / false (minúsculas)
Y / O / NOand / or / not&& / || / !
Decisiónif x > 5: … elif … else:if (x > 5) { } … else if … else { }
Repetir 5 vecesfor i in range(5):for (let i = 0; i < 5; i++) { }
Mientraswhile vidas > 0:while (vidas > 0) { }
