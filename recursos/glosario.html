GLOSARIO

¿Una palabra te sonó a hechizo de mago? 🧙 Aquí están todas, en español sencillo y con una analogía para que se te quede. En orden alfabético.

🗺️ Algoritmo

Una lista de pasos exactos y en orden para lograr algo. Los programas son algoritmos escritos en un lenguaje que la compu entiende.

una receta de cocina: pasos claros, en orden, sin saltarse ninguno.

🍳 Backend

La parte de un sistema que trabaja "detrás del telón", en un servidor: guarda datos, revisa contraseñas, hace cuentas.

la cocina de un restaurante: no la ves, pero ahí se prepara todo.

🗄️ Base de datos

Un programa especializado en guardar MUCHA información ordenada, para encontrarla y actualizarla rapidísimo.

un archivero gigante con todo etiquetado y en su lugar.

✅ Booleano

Un tipo de dato que solo puede valer dos cosas: verdadero (true) o falso (false).

un interruptor de luz: prendido o apagado, sin puntos medios.

🐛 Bug

Un error en un programa que hace que se comporte raro o truene. Encontrarlos y arreglarlos se llama "debuggear". TODOS los programadores tienen bugs.

una piedrita en el zapato: chiquita, molesta, y no descansas hasta sacarla.

🖼️ Canvas

Una etiqueta de HTML (<canvas>) que es un lienzo donde JavaScript puede dibujar píxel por píxel. Ahí viven Snake y Space Invaders.

una hoja en blanco donde tu código pinta lo que quiera.

🚚 CDN

Red de servidores repartidos por el mundo que entregan archivos (como librerías de código) al navegador de forma rápida.

una red de repartidores: siempre te atiende el que está más cerca de tu casa.

🔁 Ciclo

Instrucción que repite un bloque de código varias veces (for, while) sin copiar y pegar.

dar vueltas a la pista: la misma ruta, las veces que haga falta.

🐑 Clonar

Descargar una copia completa de un repositorio (con toda su historia) a tu computadora, usando git.

fotocopiar el cuaderno completo de un compañero, no solo una página.

💥 Colisión

Cuando dos objetos de un juego se tocan: la bala y el invasor, la serpiente y la manzana. Detectarlas es matemáticas de rectángulos.

los carritos chocones: el juego "sabe" exactamente cuándo se tocaron.

🖥️ Consola

Pantalla de texto donde los programas escriben mensajes y errores. Python tiene la suya y el navegador también (en DevTools).

un walkie-talkie con tu programa: por ahí te cuenta qué está pasando.

🗿 Constante

Un valor con nombre que NO cambia durante el programa. En JS se crea con const; en Python se escribe en MAYÚSCULAS.

tu fecha de nacimiento: tiene nombre, tiene valor, y no cambia jamás.

🎨 CSS

El lenguaje de los estilos: colores, tamaños, tipografías, posiciones. Le da el "look" a lo que HTML estructura.

la ropa y el peinado de la página: la misma persona, otro estilo.

🚀 Deploy

Publicar tu proyecto en internet para que cualquiera lo use (por ejemplo, subirlo a GitHub Pages).

el estreno de una película: pasó de tu compu al mundo real.

🔬 DevTools

Las herramientas secretas del navegador (clic derecho → Inspeccionar): consola, inspector de HTML/CSS y más. Los detectives de la web viven ahí.

los rayos X del navegador: ves los huesos de cualquier página.

🌳 DOM

El "árbol" de todos los elementos de la página que el navegador arma al leer tu HTML. JavaScript lo puede leer y modificar en vivo.

el árbol genealógico de la página: body es el abuelo y cada etiqueta, un descendiente.

✍️ Editor

El programa donde escribes código, con colores, autocompletado y avisos de errores. En este curso usamos VS Code.

el cuaderno profesional del programador, con superpoderes.

🔔 Evento

Algo que sucede en la página: un clic, una tecla, el paso del tiempo. Tu código puede "escucharlos" con addEventListener y reaccionar.

el timbre de tu casa: cuando suena (evento), alguien va a abrir (tu función).

🎭 Frontend

La parte de un sistema que el usuario VE y toca: la página, los botones, los colores. Se hace con HTML, CSS y JavaScript.

el comedor del restaurante: mesas bonitas, menú, meseros… lo que el cliente vive.

🤖 Función

Un bloque de código con nombre que puedes ejecutar las veces que quieras. Recibe datos (parámetros) y puede devolver un resultado (return).

una licuadora: le metes ingredientes, aprietas el botón y te da el licuado.

🔄 Game loop

El ciclo que hace vivir a un videojuego: muchas veces por segundo actualiza el mundo (mover, chocar) y lo vuelve a dibujar.

los cuadros de una caricatura: muchas fotos rapidito parecen movimiento.

📸 Git

Sistema de control de versiones: toma "fotos" (commits) de tu código para que puedas viajar en el tiempo si algo sale mal.

los puntos de guardado de un videojuego, pero para tu código.

☁️ GitHub

Sitio web donde guardas tus repositorios de git en la nube, colaboras con otros y hasta publicas páginas gratis (GitHub Pages).

una red social de código: tu perfil, tus proyectos y los de millones más.

🧱 HTML

El lenguaje de la ESTRUCTURA de las páginas web: títulos, párrafos, imágenes, enlaces. Todo sitio del mundo empieza aquí.

los cimientos y paredes de una casa: primero la estructura, luego la decoración.

📐 Indentación

Los espacios al inicio de una línea de código. En Python son OBLIGATORIOS: le dicen qué está dentro de qué.

la sangría de un esquema: lo que va "más adentro" pertenece a lo de arriba.

📦 JSON

Un formato de texto para guardar y enviar datos: {"nombre": "Ana", "puntos": 120}. Lo entienden casi todos los lenguajes.

empacar tus cosas en cajas etiquetadas para una mudanza: fácil de guardar, fácil de desempacar.

💾 localStorage

La memoria del navegador: guarda textos con clave y valor, y ahí siguen aunque cierres la pestaña. Así guardan récord tus juegos (y este curso tu XP).

un cajón secreto del navegador: lo que dejas ahí, ahí sigue mañana.

🏗️ Motor de juegos

Programa con herramientas ya construidas para crear juegos: física, sonido, escenas. Godot es el que te espera al final del curso.

una cocina industrial: los hornos ya están, tú pones la receta.

🌐 Navegador

El programa que descarga páginas y las convierte en algo que ves: lee HTML, aplica CSS y ejecuta JavaScript. Chrome, Safari, Firefox…

un traductor simultáneo: recibe código y te muestra una página bonita.

🎁 Parámetro

El dato que una función espera recibir para trabajar. Cuando la llamas, le pasas los valores (argumentos).

los espacios en blanco de una invitación: "Querido ____": tú decides el nombre en cada copia.

🔲 Píxel

El puntito de color más pequeño de la pantalla. Todo lo que ves (y todo lo que dibujas en canvas) está hecho de miles de ellos.

las cuentas de un collar de chaquira: de cerca son puntitos, de lejos, un dibujo.

📇 Registro

UNA fila de una tabla de base de datos: todos los datos de una cosa (un jugador, un producto).

una ficha de la biblioteca: una tarjeta = un libro con todos sus datos.

📁 Repositorio

La carpeta de un proyecto administrada por git, con todos sus archivos y toda su historia de cambios.

la carpeta del proyecto… con máquina del tiempo incluida.

📤 Return

La instrucción con la que una función DEVUELVE su resultado y termina. Sin return, la función hace cosas pero no te entrega nada.

la ventanilla de entrega del ticket: pediste, y por ahí te dan tu platillo.

🏢 Servidor

Una computadora (normalmente lejana y siempre encendida) que atiende peticiones: "dame esta página", "guarda este dato".

la matriz de una pizzería: tú pides desde tu casa y ella responde a miles a la vez.

✏️ Sintaxis

Las reglas de escritura de un lenguaje de programación: dónde van los dos puntos, las llaves, los paréntesis. Un error de sintaxis = la compu no te entiende.

la ortografía y gramática de un idioma, pero sin perdón: una coma mal y no compila.

🧍 Sprite

La imagen 2D de un personaje u objeto de un juego: la nave, el invasor, la moneda. Puede tener varios cuadros para animarse.

las calcomanías de un álbum: figuras recortadas que pegas y mueves por la escena.

🔍 SQL

El lenguaje para hablar con bases de datos: pedir, filtrar y ordenar información con frases como SELECT * FROM jugadores.

hacerle preguntas MUY precisas a un bibliotecario: "dame todos los libros de 1990, ordenados por autor".

🧵 String

Una cadena de texto: letras, números y símbolos entre comillas. "hola", "3 tacos" y "" son strings.

cuentas de letras ensartadas en un hilo, una tras otra: por eso "cadena".

📊 Tabla

En una base de datos, la estructura que organiza la información en filas (registros) y columnas (datos). Como una hoja de cálculo.

la lista de asistencia del salón: una fila por alumno, una columna por dato.

📦 Variable

Una caja con nombre donde guardas un valor que puede cambiar: vidas = 3, y más tarde vidas = 2.

un locker con etiqueta: sabes cómo se llama, y puedes cambiar lo que hay dentro.
