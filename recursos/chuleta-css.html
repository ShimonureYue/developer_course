CHULETA DE CSS

Todo lo que aprendes en el Nivel 2, en una sola hoja.

📐 La sintaxis (siempre es igual)

selector {
  propiedad: valor;   /* cada regla termina en ; */
}

Y se conecta al HTML con esta línea dentro del <head>: <link rel="stylesheet" href="estilos.css">

🎯 Selectores: ¿a quién le pego el estilo?

Selector¿A quién elige?Mini-ejemplo
pTODAS las etiquetas de ese tipop { color: red; }
.tarjetaTodo lo que tenga class="tarjeta".tarjeta { padding: 20px; }
#logoEL elemento con id="logo" (solo hay uno)#logo { width: 100px; }
p, h1Varios a la vez, separados por comap, h1 { margin: 0; }

🌈 Color y texto

Propiedad¿Qué hace?Mini-ejemplo
colorColor del textocolor: #00e5ff;
background-colorColor del fondobackground-color: black;
font-familyEl tipo de letrafont-family: 'Nunito', sans-serif;
font-sizeTamaño de la letrafont-size: 24px;
font-weightGrosor: bold = negritasfont-weight: bold;
text-alignAlineación: left, center, righttext-align: center;

📦 El modelo de caja (todo elemento es una caja)

De adentro hacia afuera: contenido → padding → border → margin.

Propiedad¿Qué hace?Mini-ejemplo
width / heightAncho y alto de la cajawidth: 300px;
paddingAire ADENTRO, entre el borde y el contenidopadding: 20px;
borderEl borde: grosor, estilo y colorborder: 2px solid cyan;
marginAire AFUERA, que separa de otras cajasmargin: 16px;

✨ Esquinas, sombras y neón

Propiedad¿Qué hace?Mini-ejemplo
border-radiusRedondea las esquinasborder-radius: 12px;
box-shadowSombra de la caja (x, y, difuminado, color). ¡Con colores brillantes se ve neón!box-shadow: 0 0 20px cyan;
text-shadowSombra del textotext-shadow: 0 0 10px lime;

🧲 Flexbox básico: acomodar cosas en fila

Propiedad¿Qué hace?Mini-ejemplo
display: flexConvierte la caja en "acomodadora" de sus hijosdisplay: flex;
justify-contentReparte a lo LARGO: center, space-between…justify-content: center;
align-itemsAlinea a lo ANCHO (vertical en una fila)align-items: center;
gapEspacio entre los hijosgap: 16px;

🪄 Magia: hover y transiciones

Sintaxis¿Qué hace?Mini-ejemplo
selector:hoverEstilos SOLO cuando el mouse está encima.btn:hover { background: lime; }
transitionQue el cambio sea suave, no de golpetransition: background 0.3s;
cursor: pointerEl cursor se vuelve manita 👆cursor: pointer;

🚑 Si el estilo no aparece…

  • ¿Pusiste el ; al final y cerraste la llave }?
  • ¿El <link> apunta al archivo correcto? Revisa el nombre EXACTO.
  • ¿Escribiste la clase igual en los dos lados? .tarjeta en CSS necesita class="tarjeta" en HTML.
